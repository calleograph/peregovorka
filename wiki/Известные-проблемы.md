# Известные проблемы

> Относится к версии 0.50.0 · проверено 2026-10-29 · уровень проверки: 1–3 (`PROJECT.md`, `HISTORY.md`, сверка с кодом; дефекты 0.49.x, исправленные в 0.50.0, воспроизведены на тестовом экземпляре) · тип страницы: справочник

Страница перечисляет ограничения продукта, нерешённые вопросы и недавно исправленные дефекты эксплуатации. Что не подтверждено на реальной инфраструктуре — на странице [[Границы проверки|Границы-проверки]].

## Ограничения продукта

| Проблема | Что известно |
| --- | --- |
| Единого входа (SSO) в Outlook нет | требует Microsoft Entra ID |
| WebAuthn и ключи доступа не реализованы | доступны одноразовые коды TOTP |
| Приложение для Windows не подписано сертификатом издателя | установщики 1.3.1 — предварительный выпуск; Windows показывает SmartScreen; корпоративный канал обновлений с подписью — в «Подпись и корпоративные сборки» |
| Приложение для Android — предварительный выпуск | 0.1.1 подписан временным ключом: первая версия с постоянным ключом ставится после удаления прежней; нет уведомлений, демонстрации своего экрана, версии для iOS ([[Как установить приложение для Android|Как-установить-приложение-для-Android]]) |
| TURN на 443 не настраивается | клиенты, которым разрешён только исходящий 443/tcp через прокси, к медиа не подключатся ([[Руководство системного администратора|Руководство-системного-администратора]], раздел 2) |
| Высокая доступность | один экземпляр на одном сервере; резервный сервер и автоматическое переключение не реализованы |
| Медиа больше одного узла LiveKit | кластер LiveKit установщиком не настраивается, не испытан |
| Внешние хранилища | SMB и папка (в том числе смонтированный NFS); S3 не реализован |
| Принудительная общая сцена и серверное «один показывающий» | не реализованы (есть настройка комнаты «один показ одновременно») |
| Метрики Prometheus самой Peregovorka, сквозные тесты интерфейса в CI | не реализованы (метрики LiveKit читаются страницей «Производительность») |
| Файл записи при скачивании по публичному API | читается целиком в память; для гигабайтных записей потоковой отдачи нет |
| Журнал в SIEM | прямой выгрузки в syslog/SIEM нет; журнал событий можно дублировать в файловое хранилище |

- **Календарь Outlook:** повторение из Peregovorka — день, неделя, месяц по числу; серии и обычные события Outlook из Peregovorka не меняются; читается только основной календарь ящика; на настоящих Exchange и Microsoft 365 не проверено ([[Как подключить календарь Exchange|Как-подключить-календарь-Exchange]]).
- **Восстановление материалов:** паспорта пишутся для встреч, завершённых с 0.40.0; старые каталоги восстанавливаются только в изолированную область ([[Как восстановить материалы после переноса|Как-восстановить-материалы-после-переноса]]).
- **Сетевая доступность:** проверка «с сервера» не подтверждает доступ из интернета; UDP снаружи без клиента проверить нельзя.

## Нерешённые вопросы

| Вопрос | Состояние |
| --- | --- |
| Микрофон в приложении для Windows сбоит чаще, чем в Edge | **причина не установлена**; страница и код захвата одинаковые; в 0.49.9 добавлены восстановление микрофона, «Подробная проверка микрофона» для сравнения, запись сбоев звуковой службы в журнал клиента; нужны отчёты проверки из Edge и из клиента на одном компьютере |
| Приложение для Android сворачивается при входе в конференцию | на эмуляторах Android 10, 14, 16 не воспроизводится; устранены возможные причины в коде; нужен журнал `adb logcat -s PGLIFE PGCALL` с устройства |
| Причина 5-секундной паузы входа в комнату | подтверждено логами: 404 на `/rtc/v1` и откат на `/rtc` у устаревшего LiveKit; замер после обновления LiveKit на сервере не выполнен |
| `Attempted to drop unknown FFI handle` в ASR | причина не подтверждена; порядок закрытия потоков исправлен; нужен повторный тест на сервере |
| Значки комнат и диктовка в приложении Windows | у разработчика не воспроизведено; нужна запись из журнала приложения с вашего компьютера |
| Отсрочки обновления компонентов | список и сроки — [DEPENDENCIES.md](https://github.com/calleograph/peregovorka/blob/main/docs/DEPENDENCIES.md) (LiveKit Server, LiveKit Python SDK, llama.cpp, draw.io, PostgreSQL 18, Redis 8 и другие) |
| Сценарии стенда | `scenario_upcoming` и часть `scenario_chats` не пройдены на стенде разработчика; связь с изменениями не выяснена |

## Исправлено в 0.50.0 (дефекты эксплуатации, найдены при проверке документации)

| Дефект в 0.49.x | Последствие | Что делать на 0.49.x до обновления |
| --- | --- | --- |
| `scripts/restore.sh` останавливал `backend`, `asr`, `web`, восстанавливал базу и не мог запустить их снова: в `.env` тег образов `dev`, а образы собраны с тегом коммита | после восстановления приложение не работает, контейнеры удалены | после `restore.sh` выполнить `IMAGE_TAG=$(git rev-parse --short=12 HEAD) scripts/ctl.sh start` |
| `scripts/ctl.sh start`, `sip.sh enable`, `video.sh enable` — та же причина: «No such image …:dev» | правка `.env` не применяется, телефония и видеозапись не включаются | то же: `IMAGE_TAG=$(git rev-parse --short=12 HEAD)` перед командой |
| `scripts/diag.sh` не создавал пакет: в выводе `docker compose config` оставались пароль Redis (элемент команды и `REDISCLI_AUTH`) и имя ключа LiveKit API | диагностический пакет не собирается ни на одной установке с паролем Redis | «Администрирование → Обзор → Скачать диагностический отчёт» |
| `smoke-test.sh` считал не подключённый каталог LDAP ошибкой | установка без LDAP всегда получала `Smoke test: INTEGRATION` (код 3), в том числе в итоге обновления | не считать «LDAP/LDAPS FAIL» ошибкой, если каталог не подключался |
| `backup.sh --with-recordings` не включал вложения чата, аватарки, оформление и сертификаты CA; дамп не проверялся на читаемость | при переносе терялись вложения чата | копировать `DATA_ROOT/{chat-files,avatars,branding,ca}` вручную |
| ASR: чтение команд диктовки обрывалось каждые 5 с (`TimeoutError` в журнале каждые 6 с), команда, пришедшая в паузу после сбоя, терялась | диктовка в чате иногда не запускалась | повторить диктовку |
