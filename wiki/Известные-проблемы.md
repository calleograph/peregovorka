# Известные проблемы

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1 (`PROJECT.md`, `HISTORY.md`, сверка с кодом) · тип страницы: справочник

Страница перечисляет ограничения, нерешённые вопросы и расхождения в документах репозитория. Что не подтверждено на реальной инфраструктуре — на странице [[Границы проверки|Границы-проверки]].

## Ограничения продукта

| Проблема | Что известно |
| --- | --- |
| Видеозапись встречи не реализована | пункт «Аудио и видео» в настройках комнаты недоступен, API отвечает 409 |
| Единого входа (SSO) в Outlook нет | требует Microsoft Entra ID |
| WebAuthn и ключи доступа не реализованы | доступны одноразовые коды TOTP |
| Приложение для Windows не подписано | установщики 1.2.0 без сертификата издателя и без ключа обновлений; автообновление не работает; Windows показывает SmartScreen |
| Принудительная общая сцена | «участник не может смотреть своё» не реализовано: личная раскладка важнее |
| Серверное принуждение «один показывающий» | не реализовано |
| Метрики Prometheus и сквозные тесты интерфейса (Playwright) в CI | не реализованы |
| Квантованная модель GGUF | снята, функция выбора модели оставлена для будущих моделей |
| Файл записи при скачивании по публичному API | читается целиком в память; для гигабайтных записей потоковой отдачи нет |

## Нерешённые вопросы

| Вопрос | Состояние |
| --- | --- |
| Причина 5-секундной паузы входа в комнату | подтверждено логами: 404 на `/rtc/v1` и откат на `/rtc`; связь «404 → около 5 секунд» — гипотеза; замер времени входа после обновления LiveKit не выполнен |
| `Attempted to drop unknown FFI handle` в ASR | причина не подтверждена; порядок закрытия потоков исправлен; нужен повторный тест на сервере; предупреждение не считать безобидным |
| Не показываются загруженные значки комнат в приложении Windows | у разработчика не воспроизведено; добавлены запасной значок и запись `page.image_failed` в журнал приложения; нужна запись из журнала с вашего компьютера |
| Диктовка в приложении Windows | вероятная причина обрыва (событие смены устройств) исправлена в 1.1.2 без подтверждения на Windows; занятый или недоступный ASR в клиенте не проверялся |
| Существующий профиль с отключённым автозапуском | проверен только модульным тестом |
| Отсрочки обновления компонентов | LiveKit Server v1.13.11 (DEP-9, до 2026-11-01), llama.cpp (DEP-1, до 2026-11-16), draw.io v32.6 (DEP-8, до 2026-11-06), PostgreSQL 18, Redis 8, Node 26, Python 3.15 и другие; список — `docs/DEPENDENCIES.md` |
| Сценарии стенда | `scenario_upcoming` (создание встречи через API надстройки падает на стенде) и часть `scenario_chats` не пройдены; связь с изменениями не выяснена |

## Устаревшие утверждения в документах репозитория

Расхождения найдены при подготовке вики сверкой с кодом. Правильные значения приведены в вики; документы репозитория требуют правки.

| Документ | Утверждение в документе | Что в коде или на практике |
| --- | --- | --- |
| `DEPLOYMENT.md`, раздел 4 | защита от блокировок AD: «по умолчанию `LOGIN_MAX_FAILURES_PER_USER` = 3» | по умолчанию 20 (`backend/app/config.py`, `.env.example`) |
| `ARCHITECTURE.md` §3.1 | порог неудач «по умолчанию 3» | то же: 20 |
| `ARCHITECTURE.md` §1 | «локальных пользователей нет» | есть один локальный аварийный администратор (с 0.3.0) |
| `DEPLOYMENT.md`, шапка | скрипты «ещё не запускались на реальном Ubuntu с Docker» | установка и обновление выполнялись на серверах владельца; полный прогон установки на чистой ВМ в тестовой среде не выполнялся |
| `README.md`, `docs/INTERNALS.md` | «20 ГБ диска» | `preflight.sh` требует не менее 30 ГБ свободно (`MIN_FREE_DISK_GB`) |
| `docs/INTERNALS.md` §«Качество» | «backend — 257, ASR — 63, frontend — 123, shell — 300 тестов» | на 2026-10-25: backend 1208, frontend 466, shell 561, ASR 74 (сбор) |
| `docs/COLLABORATION.md` | draw.io `v32.3.0` | в `frontend/Dockerfile` закреплён `v32.5.5` |
| `docs/ROOMS_AND_ROLES.md` | «красная» кнопка гостевой ссылки рядом с карточкой | с оформления «Стекло» (0.39.1) гостевая ссылка — в меню «⋯» карточки («Скопировать гостевую ссылку») |
| `docs/PERFORMANCE.md` §7 | `worker_connections` у nginx контейнера `web` в образ не вшито | `frontend/Dockerfile` ставит `worker_connections 8192` и `worker_rlimit_nofile 32768` |
| `docs/INSTALL_AND_UPDATE.md`, п. 3.3 | автообновление: «ждать окна без встреч (1–12 часов)» | `backend/app/services/settings.py`: по умолчанию 6 часов, допустимо 1–23 |
| `docs/OUTLOOK_ADDIN.md` | «Не реализовано: NTLM/Kerberos для EWS» | `PROJECT.md` п. 0i описывает их реализацию в 0.27.0; нужна сверка; настоящий Exchange не проверялся |
| `PROJECT.md` §6 (таблицы тестов) | «backend 1145, ASR 63, frontend 428, shell 547» на 0.33.0 | значения устарели: см. выше |
