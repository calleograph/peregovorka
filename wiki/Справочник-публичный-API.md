# Справочник: публичный API

*Для кого: разработчик интеграции.*

Базовый адрес: `https://<сервер>/api/public/v1`. Версия одна. По умолчанию API выключен, управление: **Администрирование → Интеграции → Публичный API**. Пошаговая инструкция: [Как использовать публичный API](Как-использовать-публичный-API).

Описание OpenAPI 3.1: `/api/public/v1/openapi.json`. Справочная страница: `/api/public/v1/docs`. Оба адреса открываются без ключа. Спецификация строится сервером из самого кода, поэтому при расхождении верьте ей.

## Авторизация

Заголовок `Authorization: Bearer pgk_<8 символов>_<43 символа>`. Ключ принадлежит интеграции (сервисной учётной записи). У интеграции задаются права, область комнат и, по желанию, разрешённые адреса.

## Методы

| Метод и путь | Право | Класс | Назначение |
| --- | --- | --- | --- |
| `GET /me` | любое | чтение | интеграция, права, область комнат, срок ключа |
| `GET /rooms`, `GET /rooms/{room_id}` | `rooms:read` | чтение | список и карточка комнат |
| `GET /meetings` | `meetings:read` | чтение | список встреч, новые первыми; отбор `room_id`, `state` (`active`, `ended`), `started_after`, `started_before` |
| `GET /meetings/{meeting_id}` | `meetings:read` | чтение | карточка встречи |
| `GET /meetings/{meeting_id}/participants` | `meetings:read` | чтение | участники: имя, тип (`user`, `guest`, `phone`), должность, подразделение, время, число входов; без e-mail и телефона |
| `POST /meetings/{meeting_id}/end` | `meetings:end` | изменения | завершить идущую встречу для всех; в аудите автор `api:<интеграция>` |
| `GET /meetings/{meeting_id}/transcript` | `transcripts:read` | чтение | стенограмма: JSON с курсором или `format=txt`, `md`, `vtt`, `srt` |
| `GET /meetings/{meeting_id}/documents` | `protocols:read`, `summaries:read` или `transcripts:read` | чтение | протоколы, резюме, сохранённые стенограммы |
| `GET /meetings/{meeting_id}/documents/{document_id}` | по виду документа | чтение | документ: JSON или `format=md`, `txt`, `html` |
| `GET /meetings/{meeting_id}/map` | `maps:read` | чтение | карта разговора |
| `GET /meetings/{meeting_id}/recordings` | `recordings:read` | чтение | сведения об аудиозаписях участников, без скачивания |
| `GET /meetings/{meeting_id}/messages` | `messages:read` | чтение | сообщения чата встречи |
| `POST /meetings/{meeting_id}/documents` | `protocols:generate` или `summaries:generate` | генерация | задача: `kind` (`protocol` или `summary`), необязательная `instruction` до 20 000 символов; ответ `202` |
| `POST /meetings/{meeting_id}/map` | `maps:generate` | генерация | задача построения карты; ответ `202` |
| `GET /jobs`, `GET /jobs/{job_id}` | `jobs:read` | чтение | свои задачи и их состояние |
| `POST /jobs/{job_id}/cancel` | `jobs:read` | чтение | отменить ожидающую задачу |
| `POST /meetings/{meeting_id}/recordings/{recording_id}/download-url` | `recordings:download` | скачивание | короткоживущая ссылка на запись |
| `GET /downloads/{token}` | без ключа | — | скачать запись `audio/wav` по ссылке; права интеграции проверяются при каждом использовании |

Изменение и удаление встреч, протоколов и записей не предусмотрено. Через API отдаются только аудиозаписи участников, а общая запись и видео не отдаются. Подписки на события создаёт только администратор в интерфейсе.

## Права

| Право | Что разрешает |
| --- | --- |
| `rooms:read` | список и карточки комнат |
| `meetings:read` | список и карточки встреч, участники и их подключения |
| `meetings:end` | завершить идущую встречу |
| `transcripts:read` | стенограмма |
| `protocols:read` | читать и выгружать протоколы |
| `summaries:read` | читать и выгружать резюме |
| `maps:read` | читать карты разговора |
| `recordings:read` | сведения об аудиозаписях |
| `messages:read` | сообщения чата встречи |
| `protocols:generate` | формирование протоколов, нагружает языковую модель |
| `summaries:generate` | формирование резюме, нагружает языковую модель |
| `maps:generate` | формирование карты, нагружает языковую модель |
| `jobs:read` | состояние и отмена своих задач |
| `recordings:download` | короткоживущие ссылки на аудиозаписи |

Выдавайте минимум. Комната вне области и любой вложенный объект отвечают `404 not_found`, как несуществующие. Чужая задача тоже неотличима от несуществующей.

## Идентификаторы

| Префикс | Объект |
| --- | --- |
| `rom_` | комната |
| `mtg_` | встреча |
| `pro_` | документ |
| `map_` | карта |
| `rec_` | запись |
| `usr_`, `gst_` | участник |
| `job_` | задача |
| `msg_` | сообщение чата, значение числовое |
| `evt_` | событие webhook |

Идентификатор другого типа или «голый» UUID не принимается, ответ `404`.

## Ошибки

Форма всегда `{"error": {"code": …, "message": …, "request_id": …}}`. В каждом ответе есть заголовок `X-Request-ID`.

| HTTP | `code` | Когда |
| --- | --- | --- |
| 400 | `invalid_cursor` | курсор повреждён или от другой выборки |
| 400 | `invalid_idempotency_key` | ключ не из 1–64 символов `A-Za-z0-9_.:-` |
| 401 | `unauthorized` | нет ключа |
| 401 | `invalid_api_key` | ключ неверен |
| 401 | `key_revoked`, `key_expired` | ключ отозван или истёк; сообщается только при верном секрете |
| 403 | `client_disabled` | интеграция отключена |
| 403 | `ip_not_allowed` | адрес не разрешён |
| 403 | `insufficient_scope` | не хватает права, см. поле `required_scope` |
| 404 | `not_found` | нет объекта, он вне области или такого метода нет |
| 409 | `not_ready` | документ ещё формируется |
| 409 | `meeting_not_ended`, `llm_not_configured`, `anonymizer_not_configured`, `no_materials` | задачу поставить нельзя |
| 409 | `idempotency_conflict` | тот же ключ для другого запроса |
| 409 | `idempotency_in_progress` | первый запрос с этим ключом ещё идёт |
| 409 | `not_cancellable` | отменить можно только ожидающую задачу |
| 410 | `link_expired`, `file_missing` | срок ссылки истёк или файл удалён из хранилища |
| 413 | `too_large` | стенограмма больше 20 000 реплик для `md`, `vtt`, `srt` |
| 422 | `validation_error` | неверные параметры, см. `error.fields` |
| 429 | `rate_limited` | превышен лимит |
| 429 | `too_many_jobs` | у интеграции 5 незавершённых задач |
| 500 | `internal_error` | сообщите администратору `request_id` |
| 503 | `api_disabled` | API выключен |

## Лимиты и постраничный вывод

Окно одна минута, отдельно на каждую интеграцию и класс запросов.

| Класс | По умолчанию, запросов в минуту | Пределы настройки |
| --- | --- | --- |
| чтение | 600 | 1–100 000 |
| изменения | 120 | 1–100 000 |
| генерация | 10 | 1–10 000 |
| скачивание | 30 | 1–10 000 |

Заголовки ответа: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, `X-RateLimit-Class`. При `429` есть `Retry-After`. Лимиты защищают сервер от перегрузки и не означают, что сервер выдержит такой поток. Если Redis недоступен, лимит не применяется, API продолжает работать.

Страницы: `limit` (по умолчанию 50, наибольшее значение задаёт **Наибольший размер страницы списка**, по умолчанию 200) и `after` (значение `next_cursor`). Курсор привязан к позиции в выборке, поэтому новые встречи не дают повторов и пропусков.

## Фоновые задачи

Состояния: `queued → processing → completed | failed | cancelled`. По умолчанию выполняется одна задача одновременно, настройка **Одновременно выполняемых задач генерации**, 1–4. Языковая модель не должна мешать звонкам. На интеграцию не более 5 незавершённых задач. Условия проверяются при постановке. Задачи, прерванные перезапуском сервера, получают ошибку, повторить их может клиент.

При `completed` поле `result` содержит `document_id` или `map_id`.

## Идемпотентность

`Idempotency-Key` (1–64 символа) действует в пределах интеграции 24 часа, настройка **Хранить ключи идемпотентности**, 1–168 часов. Повтор того же запроса возвращает прежний ответ с заголовком `Idempotent-Replay: true`, вторая задача не создаётся. Тот же ключ с другим телом даёт `409 idempotency_conflict`. Если запрос завершился ошибкой, повтор с тем же ключом допустим.

## Ссылки на скачивание

Ссылка действует 300 секунд, настройка **Срок действия ссылки на запись**, 30–3600 секунд. Ключ для неё не нужен, поэтому относитесь к ссылке как к секрету. Значение `url` относительное, дополните его адресом сервера. Выдача ссылки пишется в аудит.

## События

Подписки, заголовки, подпись, повторы и пример проверки: [Как использовать webhook](Как-использовать-webhook). События: `meeting.started`, `meeting.ended`, `document.ready`, `document.failed`, `job.completed`, `job.failed`, `webhook.test`.

## Безопасность

- Ключ хранится только как SHA-256 секрета, сравнение идёт за постоянное время. Ответ для неверного и несуществующего ключа одинаков.
- Журнал обращений хранит метод, шаблон пути, статус, время, адрес и код ошибки, без заголовков и тел.
- CORS не включён: API рассчитан на вызовы с сервера, а не из браузера.
- Запуск задач, завершение встречи и выдача ссылок пишутся в [журнал аудита](Справочник-журнал-аудита-и-события).
- Адрес клиента берётся с учётом настроек доверенных прокси, см. [Как настроить reverse proxy и HTTPS](Как-настроить-reverse-proxy-и-HTTPS).
