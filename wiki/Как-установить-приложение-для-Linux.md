# Как установить приложение для Linux

*Для кого: сотрудник с компьютером Ubuntu 22.04/24.04 или Debian 12/13 (x86_64); администратор, который ставит приложение на много компьютеров.*

**Что получится:** приложение Peregovorka установлено из репозитория APT и дальше обновляется вместе с системой; вы вошли в одну или несколько организаций.
Это то же приложение, что и для Windows: встречи, чаты, история, уведомления, трей. Подробное руководство с диагностикой — [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md).

## Что нужно заранее

- Ubuntu 22.04 или 24.04, Debian 12 или 13, процессор x86_64. Производные системы (Linux Mint, Pop!_OS и другие) должны работать, но отдельно не проверялись.
- Права администратора (`sudo`; в Debian без настроенного sudo — `su -`).
- Адрес сервера организации (тот же, что в браузере) и учётная запись. Сервер Peregovorka 0.37.0 или новее.

## Установка

1. Откройте терминал и выполните:

   ```bash
   curl -fsSL https://calleograph.github.io/peregovorka-apt/install.sh | sudo sh
   ```

   Сценарий проверит систему, скачает ключ репозитория и сверит его отпечаток, подключит репозиторий и установит приложение.
   Ожидаемый результат: последняя строка — «установлено: X.Y.Z».

   Другие способы — пакет `.deb` со [страницы выпусков](https://github.com/calleograph/peregovorka/releases?q=desktop-v) (`sudo apt install ./peregovorka_X.Y.Z_amd64.deb`)
   или ручное подключение репозитория с проверкой отпечатка — на [странице установки](https://calleograph.github.io/peregovorka-apt/).

2. Запустите «Peregovorka» из меню приложений (или командой `peregovorka`), введите адрес сервера и войдите, как в браузере.

   Ожидаемый результат: открывается интерфейс организации; слева — значки организаций.

Пароль приложение не хранит: вход запоминается токеном устройства в связке ключей рабочего стола (GNOME Keyring, KWallet). Если связки ключей нет
(например, в минимальной среде без неё), вход придётся повторять после каждого запуска.

## Обновление

Новые версии приходят вместе с обновлениями системы: «Обновление программ» или

```bash
sudo apt update && sudo apt upgrade
```

Если приложение было открыто, оно сообщит «Peregovorka обновлена» и предложит перезапуститься («Настройки → Обновления» → «Перезапустить»; во время встречи — после неё).

## Показ экрана

В X11 приложение показывает своё окно выбора экрана или окна. В Wayland (по умолчанию в Ubuntu 22.04+ и Debian 12+ с GNOME) экран или окно выбирается в системном окне — так требует Wayland. Звук компьютера при показе экрана в Linux не передаётся.

## Удаление

| Что | Команда |
| --- | --- |
| Только приложение | `sudo apt remove peregovorka` |
| Приложение, репозиторий и ключ | `sudo apt purge peregovorka` |
| Свои данные (организации, настройки) | `rm -rf ~/.config/Peregovorka` |

## Типичные ошибки

| Симптом | Что делать |
| --- | --- |
| `apt update` пишет об ошибке подписи (NO_PUBKEY, «not signed») | переустановите ключ (команда установки из шага 1); не отключайте проверку подписи |
| Нет значка в трее в GNOME | включите расширение «AppIndicator and KStatusNotifierItem Support» (в Ubuntu включено) или закрывайте окно кнопкой «Выйти» |
| «Сертификат не доверен» при подключении к серверу | корневой сертификат внутреннего центра сертификации нужно добавить в хранилище NSS пользователя — инструкция для администратора в [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md) |
| Новая версия работает хуже | `sudo apt install peregovorka=X.Y.Z --allow-downgrades` — вернуть прежнюю |

## Для администратора

Политики (серверы организаций, разрешённые домены, автозапуск) — файл `/etc/peregovorka/policy.json`; автоматические обновления через `unattended-upgrades` — по вашему решению;
зеркало репозитория для сети без интернета, развёртывание на много компьютеров — [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md), раздел «Для администраторов».
