# Как установить приложение для Linux

*Для кого: сотрудник с компьютером на Ubuntu или Debian и администратор, который ставит приложение на много компьютеров.*

## Зачем это нужно

Это то же приложение, что и для Windows: встречи, чаты, история, уведомления рабочего стола, значок в трее. Оно ставится из репозитория APT и обновляется вместе с системой. Сравнение с браузером: [Веб-версия и приложения](Веб-версия-и-приложения).

## Когда пригодится

Вы работаете в Linux и хотите получать уведомления и держать Peregovorka в отдельном окне.

## Что потребуется

- Ubuntu 22.04 или 24.04, Debian 12 или 13.
- Процессор x86_64 или ARM64. На ARM проверены установка, запуск и обновление, а звонки не проверялись.
- Права администратора: `sudo`, а в Debian без настроенного sudo команда `su -`.
- Адрес сервера организации и учётная запись.
- Сервер Peregovorka 0.37.0 или новее.

Производные системы, например Linux Mint и Pop!_OS, отдельно не проверялись.

## Где найти

Команда установки приведена ниже. Другие способы описаны на [странице установки](https://calleograph.github.io/peregovorka-apt/).

## Как это сделать

1. Откройте терминал и выполните:

   ```bash
   curl -fsSL https://calleograph.github.io/peregovorka-apt/install.sh | sudo sh
   ```

   Сценарий проверит систему, скачает ключ репозитория, сверит его отпечаток, подключит репозиторий и установит приложение.

   Результат: последняя строка выглядит как «установлено: X.Y.Z».

2. Запустите **Peregovorka** из меню приложений или командой `peregovorka`.
3. На экране **Добро пожаловать в Peregovorka** нажмите **Добавить организацию**.
4. Введите **Адрес сервера Peregovorka** и нажмите **Проверить подключение**.
5. Нажмите **Продолжить** и войдите на странице сервера: [Как войти в систему](Как-войти-в-систему).

Другой способ установки: пакет `.deb` со [страницы выпусков](https://github.com/calleograph/peregovorka/releases?q=desktop-v).

```bash
sudo apt install ./peregovorka_X.Y.Z_amd64.deb
```

## Что получится

Открывается интерфейс организации, слева видны значки организаций. Работа с организациями, треем и настройками такая же, как в [приложении для Windows](Как-установить-приложение-для-Windows#работа-в-приложении).

Пароль приложение не хранит. Вход запоминается токеном устройства в связке ключей рабочего стола: GNOME Keyring или KWallet. Без связки ключей вход придётся повторять после каждого запуска.

## Обновление и удаление

Новые версии приходят вместе с обновлениями системы:

```bash
sudo apt update && sudo apt upgrade
```

Если приложение было открыто, оно сообщит **Peregovorka обновлена**. Откройте **Настройки → Обновления** и нажмите **Перезапустить**. Во время встречи сделайте это после её окончания.

| Что удалить | Команда |
| --- | --- |
| Только приложение | `sudo apt remove peregovorka` |
| Приложение, репозиторий и ключ | `sudo apt purge peregovorka` |
| Свои данные: организации и настройки | `rm -rf ~/.config/Peregovorka` |

## Показ экрана

В X11 приложение показывает своё окно выбора экрана или окна. В Wayland экран или окно выбирается в системном окне. Wayland используется по умолчанию в Ubuntu 22.04 и новее и в Debian 12 и новее с GNOME. Звук компьютера при показе экрана в Linux не передаётся.

## Если не получается

| Симптом | Что сделать |
| --- | --- |
| `apt update` пишет об ошибке подписи (`NO_PUBKEY`, «not signed») | переустановите ключ командой из шага 1. Не отключайте проверку подписи |
| Нет значка в трее в GNOME | включите расширение «AppIndicator and KStatusNotifierItem Support». В Ubuntu оно включено. Либо закрывайте окно через **Выйти из приложения** |
| **Сертификат не доверен** | корневой сертификат центра сертификации нужно добавить в хранилище NSS пользователя: [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md) |
| Вход не сохраняется | в **Настройки → Диагностика** посмотрите **Хранилище входа**. Нужна связка ключей рабочего стола |
| Показ экрана не начинается в Wayland | приложение объяснит причину. Проверьте системный портал рабочего стола: [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md) |
| Новая версия работает хуже | верните прежнюю: `sudo apt install peregovorka=X.Y.Z --allow-downgrades` |

Другие сообщения при подключении те же, что в [приложении для Windows](Как-установить-приложение-для-Windows#если-не-получается).

## Для администратора

Политики (серверы организаций, разрешённые домены, автозапуск) задаются в файле `/etc/peregovorka/policy.json`. Автоматические обновления через `unattended-upgrades` включаются по вашему решению. Зеркало репозитория для сети без интернета и установка на много компьютеров описаны в [docs/LINUX.md](https://github.com/calleograph/peregovorka/blob/main/docs/LINUX.md), раздел «Для администраторов».
