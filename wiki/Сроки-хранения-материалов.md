# Сроки хранения материалов

*Для кого: администратор сервера, руководители комнат.*

## Зачем это нужно

Срок хранения определяет, когда сервер удалит материалы встреч. Записи занимают много места, а текст может содержать чувствительные сведения. Для каждого вида материалов срок задаётся отдельно: для всего сервера и при необходимости для одной комнаты.

## Когда пригодится

- Нужно уложиться в политику хранения организации.
- Диск заполняется записями.
- Одной комнате нужен особый срок, например для совещаний по договорам.

## Что потребуется

- Менять сроки может только администратор сервера.
- Руководитель комнаты видит действующие сроки: **Настройки комнаты… → Материалы**.

## Сроки по умолчанию

| Материалы | Срок | От какого момента |
| --- | --- | --- |
| Текст: стенограммы, протоколы, резюме, чат встречи, доска | бессрочно | от окончания встречи |
| Аудиозаписи: файлы участников и общая аудиозапись | 60 дней | от создания записи |
| Видеозаписи, **в том числе записи эфиров** | 30 дней | от создания записи |

Политика одна для всех типов комнат: обычных, презентационных, трансляционных, временных и созданных из календаря.

Значение **пусто** означает «бессрочно». Значение `0` означает «удалить после обработки»: материалы удаляются при первой очистке, когда с окончания встречи или создания записи прошло 15 минут. Сформировать протокол позже будет не из чего, поэтому выбирайте `0` для текста только осознанно.

## Где найти

- Для сервера: **Администрирование → Система → Общие настройки → Сроки хранения материалов**.
- Для комнаты: **Администрирование → Комнаты и пользователи → Комнаты и доступ → Изменить → вкладка Материалы**.

## Как это сделать

### Изменить общий срок

1. Откройте **Администрирование → Система → Общие настройки**.
2. В разделе **Сроки хранения материалов** заполните поля: **Текст: стенограммы, протоколы, чат, доска**, **Аудиозаписи**, **Видеозаписи, в том числе записи эфиров**.
3. Сохраните настройки.

Комнаты без своего срока следуют общему: изменение сразу действует на них.

### Задать срок одной комнате

1. Откройте комнату: **Комнаты и доступ → Изменить**.
2. На вкладке **Материалы** в блоке **Хранение** для нужного вида выберите **Свой срок комнаты**.
3. Введите число дней. Пусто означает «бессрочно».
4. Сохраните. Чтобы вернуть общий срок, выберите **Общий срок сервера**.

## Что получится

Раз в час фоновая задача удаляет просроченные материалы. В журнал сервера пишется строка «Очистка по срокам хранения» с числом удалённого.

**Что удаляется:**

- реплики стенограммы, протоколы, резюме, сообщения чата встречи вместе с вложениями, схема доски;
- вопросы зрителей эфира и почта гостей (по сроку текста);
- файлы записей: и локальные, и в подключённом хранилище.

**Что не удаляется:**

- сама встреча: в **Истории** остаются комната, время и участники;
- **карта разговора**: срок хранения текста её не затрагивает, хотя она содержит темы и цитаты. Удалить её может только удаление встречи целиком;
- **копии текстовых документов в хранилище документов встреч** (`protocol.txt`, `official-protocol.md`, `summary.md`): срок хранения удаляет текст в базе, а файлы в хранилище остаются. Если организации нужно их удалять, настройте очистку на стороне хранилища;
- видеозапись, которую ещё пишет служба записи;
- аудио, из которого ещё собирается общая запись: оно удалится при следующей очистке.

### Если хранилище недоступно

Запись не исчезает из учёта. Она остаётся в состоянии **удаляется**, а удаление повторяется само, пока файл не будет удалён и проверен. Подробнее: [Решение проблем файловых хранилищ](Решение-проблем-файловых-хранилищ). Так же удаляются записи вручную, вместе со встречей и вместе с комнатой.

Если на сервере SMB включена своя корзина (у Samba модуль `recycle`, у NAS «Корзина»), удалённые файлы попадают в неё и хранятся по правилам этого сервера. Чтобы срок соблюдался полностью, настройте очистку корзины или отключите её для этой папки.

### Срок ссылки на запись эфира и срок хранения файла

Это разные сроки. Ссылка зрителя действует, например, 5 дней после окончания эфира ([Запись трансляции](Запись-трансляции)), а сам файл хранится по сроку видео. Истечение или закрытие ссылки файл не удаляет. Если файл удалён раньше, чем истекла ссылка, зритель видит «Запись удалена и больше недоступна.»

### Обновление со старых версий

При обновлении до 0.54.0 настройки перенесены бережно:

- срок, который был **явно задан** у комнаты (отличается от прежних значений 365 дней для текста и 30 для аудио), сохранился как **Свой срок комнаты**;
- комнаты с прежними значениями или без срока перешли на общие сроки;
- срок видео из настроек видеозаписи перенесён в общий срок видео.

**Во время обновления ничего не удаляется.** Общие сроки начинают работать не раньше чем через 7 дней после него: поле **Общие сроки начинают удалять материалы с** в том же разделе. Чтобы начать раньше, очистите поле. Чтобы позже, укажите дату в формате `2026-11-07T12:00:00+00:00`. Свои сроки комнат действуют без паузы.

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Старые материалы не удаляются | действует дата в поле **Общие сроки начинают удалять материалы с**, или у комнаты свой срок | проверьте поле и вкладку **Материалы** комнаты |
| Руководитель не может изменить срок | менять может только администратор сервера | обратитесь к администратору |
| Запись долго в состоянии **удаляется** | хранилище недоступно | восстановите связь, удаление продолжится само |
| Файл после удаления всё ещё в SMB | сработала корзина на сервере хранения | настройте её очистку |
| В хранилище остались `official-protocol.md` и другие копии | срок их не удаляет | удалите на стороне хранилища |
| Запись эфира исчезла раньше срока ссылки | истёк срок хранения видео | увеличьте срок видео |
