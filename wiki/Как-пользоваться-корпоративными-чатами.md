# Как пользоваться корпоративными чатами

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 2–3 (автотесты; живой сценарий и два экземпляра backend на стенде; диктовка — на подставном распознавании) · тип страницы: практическое руководство

Результат: вы переписываетесь с коллегами вне встреч, ищете сообщения, отправляете файлы и диктуете текст голосом. Для кого: сотрудник. Чаты работают в браузере и в приложении для Windows. Подробности для администратора — раздел «Настройки» ниже.

## Что нужно заранее

- Вы вошли доменной учётной записью.
- Администратор включил чаты («Администрирование → Хранение и журналы → Корпоративные чаты»).

## Открыть чаты

Нажмите «Чаты» в левой панели. Окно открывается поверх текущей страницы: встреча и текущий раздел не прерываются. Окно можно перетаскивать за заголовок, менять размер за угол, разворачивать двойным щелчком; закрывает его крестик в правом верхнем углу. Окно остаётся в пределах экрана; на узких экранах (меньше 640 px) показывается одна панель, на телефоне — во весь экран.

## Начать переписку

1. Нажмите «Новый чат».
2. Найдите сотрудника: поиск идёт по справочнику (кто уже входил) и по корпоративному каталогу. Отключённые учётные записи не показываются; группа каталога раскрывается в участников.
3. Выберите человека. Личная переписка с ним одна: повторное «написать» открывает существующую.

Группа: название, изображение (256×256), добавление и исключение участников, администраторы группы (последнего снять нельзя), выход. Предел участников задаёт администратор.

## Работать с сообщениями

| Действие | Как |
| --- | --- |
| Ответить с цитатой, скопировать, переслать | меню сообщения (правая кнопка или «⋮»); пересылка — в другую вашу переписку, вложения не копируются |
| Изменить, удалить своё | меню сообщения; проверяет сервер |
| Реакция | одна на сообщение; повтор той же снимает, другая заменяет |
| Упомянуть | «@Имя» в группе; упомянутому приходит уведомление даже из чата без уведомлений |
| Разметка | жирный `**`, курсив `_`, `код`, блок кода; ссылки только http и https; HTML не интерпретируется |
| Статусы доставки | «отправляется», «не отправлено (Повторить)», «доставлено ✓», «прочитано ✓✓» |

Новые сообщения приходят без перезагрузки, на всех ваших устройствах. История подгружается страницами по 50 при прокрутке вверх.

## Организовать переписки

Личные папки, закрепление, архив, отключение уведомлений, очистка истории «у себя» и удаление из списка — в контекстном меню или «⋮». Это ваши личные настройки: у собеседников ничего не меняется. Удаление папки переписки не удаляет.

## Найти сообщение

Слева — поиск по названиям и по содержимому всех ваших переписок. Внутри переписки — слова и «фразы в кавычках», подсветка, «N из M», переход к предыдущему и следующему совпадению, фильтр по автору и периоду.

## Отправить файл

Кнопка прикрепления, перетаскивание или вставка скриншота (Ctrl+V). Тип файла проверяется по содержимому; исполняемые файлы (`exe`, `bat`, `cmd`, `js`, `html`, `svg`, `lnk` и другие «активные» расширения) запрещены всегда. По умолчанию до 25 МБ и 5 файлов в сообщении. Если хранилище вложений недоступно, вы увидите «хранилище вложений недоступно». Файл получает только участник переписки.

## Продиктовать текст

1. Нажмите кнопку микрофона в поле ввода.
2. Говорите: распознанный текст появляется у курсора, набранное вручную сохраняется.
3. «Стоп» завершает диктовку, «Отмена» отбрасывает, «Остановить и отправить» отправляет сообщение после окончательного ответа распознавания.

Диктовку обслуживает та же служба распознавания, что и встречи, но без LiveKit. Встречи важнее: при загруженной очереди диктовка сообщает «распознавание занято». Звук не сохраняется. Во время встречи участники слышат диктовку, если у вас включён микрофон встречи. Если распознавание недоступно, кнопка неактивна.

## Уведомления и присутствие

Счётчик непрочитанных стоит на кнопке «Чаты» (без переписок с отключёнными уведомлениями). «В сети» показывается, только если вкладка открыта и вы действовали за последние 3 минуты; статус можно скрыть. Администратор может выключить присутствие целиком.

## Настройки для администратора

«Администрирование → Хранение и журналы → Корпоративные чаты»: включение, срок хранения переписки (дней; 0 — без срока; очистка раз в час пачками по 500), длина сообщения, число участников в группе, сообщений в минуту, присутствие, диктовка (включена ли, длительность, одновременных на сервер). Вложения — «Хранилище вложений чата». Тексты переписки в технические журналы не пишутся; в аудит попадают создание и изменение групп, роли, удаление сообщения (без текста), скачивание документа, изменение настроек.

## Типичные ошибки

| Симптом | Причина |
| --- | --- |
| Кнопка диктовки неактивна | служба распознавания недоступна или диктовка выключена |
| «Распознавание занято» | очередь распознавания занята встречами |
| Вложение не принимается | запрещённый тип, превышен размер или число файлов, хранилище недоступно |
| Сотрудника нет в поиске | учётная запись отключена |
