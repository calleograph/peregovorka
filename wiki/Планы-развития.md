# Планы развития

*Для кого: владелец системы, администратор, разработчик.*

**Здесь описаны только планы. Ничто из перечисленного не работает.** Список отражает записи разработчиков на 2026-11-07, а не обязательства по срокам: сроков в документах проекта нет.

## Запланировано

| Что | Состояние | Откуда известно |
| --- | --- | --- |
| Нагрузочные испытания: встречи, камеры, показ экрана, запись, распознавание, эфиры, затем смешанная нагрузка на целевом сервере | предложен проект: [Матрица нагрузочных испытаний](Матрица-нагрузочных-испытаний), ступени и пороги не утверждены. До смешанного прогона вместимость не заявляется | аудит числовых заявлений |
| Настоящая проверка на сервере: замеры входа, показ экрана 20–30 минут, приёмочный сценарий; затем фиксация системных требований | не выполнена | `PROJECT.md`, `docs/ACCEPTANCE_TEST.md` |
| Карты эволюции темы, карта проекта, слой знаний, глобальный поиск по темам и решениям | этапы 2–5 «Карт и знаний» не начаты, сделана только карта одной встречи | `docs/MAPS_AND_KNOWLEDGE.md` |
| Метрики Prometheus приложения и сквозные тесты интерфейса в CI | не сделаны, живые сценарии запускаются отдельно | `PROJECT.md` |
| Единая самодиагностика «установка, прокси, Origin, LiveKit, обновление» с сохранением отчёта | не сделана | `PROJECT.md` |
| Создание комнаты ключом публичного API | не сделано: нужна новая область прав и привязка создателя | `docs/PEER_ROOMS.md` |
| Подпись установщиков Windows сертификатом удостоверяющего центра | сертификата нет, установщики не подписаны. Ключ обновлений настроен | `docs/DESKTOP_SIGNING.md` |
| Удаление `legacy/php/` | по решению владельца | `PROJECT.md` |
