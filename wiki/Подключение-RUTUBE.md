# Подключение RUTUBE

*Для кого: владелец комнаты.*

**Что получится:** эфир Peregovorka идёт на RUTUBE (в том числе приватно, по прямой ссылке).

## Что нужно заранее

- Аккаунт RUTUBE с каналом и доступом к трансляциям. По справке RUTUBE для трансляций нужна подтверждённая учётная запись (номер телефона).
- Ключ потока действует недолго: по официальной справке **не более 24 часов с начала трансляции**. Для следующего мероприятия создайте новую трансляцию и замените ключ в Peregovorka.

## Шаги

1. В студии RUTUBE создайте трансляцию. Для закрытого показа выберите доступ «Приватная трансляция» / «Доступ по прямой ссылке» (формулировки интерфейса меняются — следуйте справке).
2. Скопируйте «Сервер» и «Ключ потока».
3. В Peregovorka: **Настройки комнаты → Трансляция → Внешние площадки → Добавить площадку → RUTUBE**; вставьте сервер и ключ, ссылку на просмотр на RUTUBE (необязательно). Параметры не зашиты в приложение: используется то, что дала площадка.
4. Начните эфир в Peregovorka, затем запустите трансляцию в студии RUTUBE (кнопка «Запустить трансляцию»).

## Приватность

Приватный эфир RUTUBE открывается только по прямой ссылке. Пароль зрителя Peregovorka эту ссылку **не защищает** — читайте [Особенности доступа через внешние видеоплощадки](Особенности-доступа-через-внешние-видеоплощадки).

Официальные справки: [Трансляции на RUTUBE](https://rutube.ru/info/broadcast/), [одновременная трансляция на разных площадках](https://rutube.ru/info/broadcastx2/).

## Что не проверено

Подключение к настоящей площадке этим выпуском не проверялось: у разработчика нет тестового аккаунта и ключа. Универсальный механизм RTMP проверен на контролируемом приёмнике (несколько площадок одновременно, отказ одной, подключение и отключение на лету). Параметры площадки меняются — сверяйтесь с её справкой, ссылка ниже.
