# Системные требования

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1 (код `scripts/preflight.sh`, `scripts/lib/prereqlib.sh`) и 0 (документы) · тип страницы: справочник

## Сервер

| Параметр | Требование | Что происходит при нарушении | Источник |
| --- | --- | --- | --- |
| Операционная система | Ubuntu 24.04 (рекомендуется); допустимы Ubuntu 22.04 и новее, Debian 12 и новее; архитектура x86_64 | установщик отказывается на неподдерживаемой системе до любых изменений | `prereqlib.sh` |
| Процессор | от 4 vCPU | меньше 4 ядер — предупреждение `preflight.sh` (для ASR рекомендовано не меньше 4); другая архитектура, не x86_64, — тоже предупреждение | `preflight.sh` (У1) |
| Память | от 8 ГБ | меньше 8 ГБ — предупреждение, меньше 75 % от 8 ГБ — отказ `preflight.sh` | `preflight.sh` (У1) |
| Диск | не менее 30 ГБ свободно в `DATA_ROOT` | меньше — отказ `preflight.sh` (переменная `MIN_FREE_DISK_GB`) | `preflight.sh` (У1) |
| Права | root или `sudo` | скрипт перезапускается через `sudo` | `install.sh` |
| GPU | не обязателен; для CUDA нужен `compose.gpu.yml` и NVIDIA Container Toolkit | по умолчанию `ASR_DEVICE=cpu` | `.env.example` |

Диск расходуется на образы Docker, модель распознавания (около 1–2 ГБ), локальную языковую модель (около 1,3 ГБ) и записи встреч.

> В `README.md` и `docs/INTERNALS.md` указано «20 ГБ диска»; `preflight.sh` требует 30 ГБ. Правильное значение — 30 ГБ (расхождение зафиксировано на странице [[Известные проблемы|Известные-проблемы]]).

## Программное обеспечение

В режиме `standalone` установщик ставит всё сам: Docker Engine, Compose, Buildx, nginx, git, curl, openssl и системные утилиты (`apt install`, без `apt upgrade`). В режиме `shared-host` Docker и Compose нужно поставить заранее; `scripts/prereq.sh --check --profile shared-host` покажет недостающее.

Стек приложения (внутри контейнеров): Python 3.12, FastAPI, PostgreSQL 16, Redis 7, LiveKit Server v1.13.10 (закреплён), Node.js 24 при сборке интерфейса. Источник — `docs/INTERNALS.md`, `.env.example`, `backend/app/components.json`.

## Сеть

| Что | Требование |
| --- | --- |
| Адрес | DNS-имя сервера (например, `meet.example.org`) и сертификат HTTPS; без HTTPS браузер не даёт микрофон и экран |
| Участникам | `443/tcp` и порты звонков: `LIVEKIT_UDP_PORT/udp` и `LIVEKIT_TCP_PORT/tcp` (значения в `.env`) — напрямую на адрес `LIVEKIT_NODE_IP` |
| Серверу при установке | доступ к GitHub, PyPI, npm, Docker Hub, источнику моделей GigaAM и Hugging Face |
| Серверу в работе | LDAPS до контроллеров домена; доступ к внешней LLM, обезличивателю, SMTP и SMB — только если вы их подключили |

Полный перечень портов — [[Справочник: порты и сеть|Справочник-порты-и-сеть]].

## Клиенты

| Клиент | Требование |
| --- | --- |
| Браузер | актуальные Chrome и Edge (основная проверка); Firefox и Safari не проверялись ([[Границы проверки|Границы-проверки]]); для шумоподавления нужны AudioWorklet и WebAssembly |
| Приложение для Windows | Windows 10 или 11, x64; сервер Peregovorka 0.37.0 или новее; прокси — как в Windows |
| Телефон | мобильные браузеры проверены эмуляцией экрана 390×844; физические телефоны не проверялись |

## Нагрузка

Ориентир для 2000 одновременно активных пользователей по результатам замеров: сервер приложения 8 vCPU и 16 ГБ памяти, `BACKEND_WORKERS=4`, PostgreSQL на SSD; медиасервер LiveKit рассчитывается отдельно ([[Производительность и масштабирование|Производительность-и-масштабирование]]).
