# Возможности

> Относится к версии 0.40.0 · проверено 2026-10-26 · уровень проверки: указан в каждой строке · тип страницы: справочник

Страница перечисляет функции и честно показывает, насколько каждая проверена. Расшифровка статусов и уровней — [[Как читать эту вики|Как-читать-эту-вики]]. Границы проверки собраны на странице [[Границы проверки|Границы-проверки]].

Короткие обозначения: **У3** — проверено запуском на стенде разработчика (настоящие LiveKit, браузеры, backend; внешние системы подставные); **У2** — проверено автоматическими тестами; **У1** — подтверждено чтением кода или документов.

## Интеграции

| Интеграция | Статус | Уровень | Граница проверки |
| --- | --- | --- | --- |
| Active Directory (LDAPS и STARTTLS) | реализовано | У2–У3 | подставной каталог; подтверждающей записи о проверке на настоящем AD в репозитории нет |
| Bitrix24 (профиль сотрудника, только чтение) | реализовано | У2 | подставной портал |
| SMTP / Exchange | реализовано | У2 | подставной сервер |
| SMB и локальный каталог (хранилища) | реализовано | У2 | настоящий SMB-ресурс не испытывался |

| Массовые трансляции: трансляционная комната, ссылка зрителя, HLS через nginx, пароли выступающих и зрителей, отзыв ссылок | реализовано, по умолчанию выключено | У3 | проверено на настоящем Egress, nginx и Chromium с синтетическими участниками; WebKit на устройстве, живые люди и большие аудитории не проверялись — [[Массовые трансляции|Массовые-трансляции]] |
| Надстройка Microsoft Outlook (две ссылки в приглашении, гостевая ссылка с отзывом и перевыпуском) | реализовано, по умолчанию выключено | У3 | поддельный Office.js; настоящие Outlook и Exchange не проверялись; единого входа нет |

| Публичный API и события (webhooks) | реализовано, по умолчанию выключено | У3 | настоящий получатель событий за корпоративным УЦ не проверялся |
