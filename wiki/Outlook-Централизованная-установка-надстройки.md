# Централизованная установка надстройки администратором Exchange

> Относится к версии 0.41.0 · проверено 2026-10-26 · уровень проверки: 3 на подставных Graph и EWS и в браузере; **настоящие Exchange, Microsoft 365 и Outlook не проверялись** · тип страницы: практическое руководство

Результат: кнопка «Добавить конференцию» появилась у нужных сотрудников без их участия. Для кого: администратор Exchange. Шаги в консоли Exchange **не проверялись на настоящем сервере**: сверяйте их со справкой Microsoft для вашей версии.

## Что понадобится

- Включённая интеграция и публичный HTTPS-адрес ([[Как подключить надстройку Outlook|Как-подключить-надстройку-Outlook]]).
- Манифест из «Администрирование → Интеграции → Microsoft Outlook» (кнопка «Скачать манифест») либо пакет со скриптами установки.
- Права администратора организации Exchange.

## Exchange Server 2016 / 2019

1. В консоли администрирования Exchange откройте раздел управления надстройками организации и добавьте надстройку **из файла**, указав скачанный манифест. Название и расположение раздела проверьте по справке Microsoft для вашей версии; общий принцип описан в [руководстве для Exchange 2013](https://learn.microsoft.com/ru-ru/exchange/install-or-remove-outlook-add-ins-exchange-2013-help#install-an-add-in-for-outlook) — **это инструкция для Exchange Server 2013, а не универсальная для всех выпусков**.
2. Выберите, кому надстройка доступна: всем или выбранным пользователям; включите «Обязательная» только если кнопка должна быть у всех без возможности отключить.
3. Либо через PowerShell: командлет `New-App` с параметром `-FileData` (см. [New-App](https://learn.microsoft.com/en-us/powershell/module/exchange/new-app), проверьте блок «Applies to» для своей версии). Скрипты `Install-OutlookAddin.ps1` и `Test-OutlookAddin.ps1` из пакета Peregovorka используют те же командлеты; прочитайте их перед запуском и запустите сначала на тестовом ящике.
4. Подождите: клиенты получают список надстроек не сразу (до нескольких часов); перезапустите Outlook.

## Microsoft 365

Администратор открывает «Централизованное развёртывание» в Центре администрирования Microsoft 365 и загружает манифест: [руководство Microsoft](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-deployment-of-add-ins) и [надстройки в Exchange Online](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/add-ins-for-outlook/add-ins-for-outlook).

## Проверить результат

1. В классическом Outlook создайте собрание: на ленте должна быть кнопка «Добавить конференцию». Нажмите её: откроется боковая панель Peregovorka.
2. В Outlook в браузере откройте то же; при первом запуске подтвердите доверие к домену Outlook (см. [[Диагностика типичных ошибок|Outlook-Диагностика-типичных-ошибок]]).
3. В «Интеграции → Microsoft Outlook → Проверки» все строки должны быть зелёными или нейтральными; журнал Outlook показывает запуск панели.

## Обновление и удаление

Манифест содержит постоянный идентификатор для адреса сервера: после смены адреса надстройку нужно установить заново. Обновление Peregovorka само обновляет страницы надстройки; манифест меняется, только если вы изменили «Источник библиотеки Office.js».
