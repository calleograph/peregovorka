# Глоссарий

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1 · тип страницы: справочник

| Термин | Значение |
| --- | --- |
| Active Directory (AD) | каталог пользователей и групп Microsoft; Peregovorka входит в него по LDAPS |
| ALTCHA | формат вычислительной проверки (доказательство работы), на нём построена локальная CAPTCHA |
| ASR | автоматическое распознавание речи; здесь — служба `asr` на GigaAM |
| `APP_MASTER_KEY` | ключ шифрования секретов в базе; хранится в `.env` |
| Backend | серверная часть на FastAPI: вход, права, API, фоновые задачи |
| CA | удостоверяющий центр, выдаёт сертификаты; корневые сертификаты нужны для LDAPS и SMTP |
| `DATA_ROOT` | каталог постоянных данных на сервере (база, записи, модели) |
| DPAPI | защита данных Windows; под ней хранится токен устройства приложения |
| E2EE | сквозное шифрование звука и видео между устройствами участников |
| GigaAM | модель распознавания русской речи (v3 e2e RNNT) |
| Гость | участник по гостевой ссылке без учётной записи, с минимальными правами |
| ICE | механизм установления медиасоединения WebRTC |
| LDAPS | LDAP поверх TLS, порт 636 |
| LiveKit | сервер звонков (SFU): передача звука и видео |
| `llm-local` | контейнер встроенной языковой модели Qwen3 1.7B на llama.cpp |
| Обезличивание | замена персональных данных в тексте перед отправкой внешней модели |
| Организатор встречи | тот, кто начал встречу |
| Origin | заголовок браузера с адресом страницы; сервер сверяет его со списком разрешённых |
| `.pgcfg` | шифрованный архив настроек для переноса на другой сервер |
| Презентационная комната | комната, где выступают руководители и те, кому дали слово, а зрители смотрят |
| Профиль установки | `standalone` (выделенный сервер) или `shared-host` (общий сервер) |
| RNNoise | нейросеть шумоподавления, работает в браузере |
| Руководитель комнаты | сотрудник или группа из списка «Руководители» комнаты |
| SFU | медиасервер, пересылающий потоки участникам без смешивания |
| SIP | протокол телефонии; подключение к АТС |
| SMB | сетевая файловая шара Windows |
| Слово | право выступающего в презентационной комнате, выдаётся руководителем |
| TOTP | одноразовые коды по времени (RFC 6238) для двухфакторной защиты |
| VAD | определение речи; режет звук на сегменты |
| Webhook (событие) | HTTPS-запрос на ваш адрес при событии системы, с подписью |
| Помощник обновлений | служба `scripts/updater.sh` на хосте, выполняет обновление из браузера |
