# Глоссарий

*Для кого: все читатели вики.*

Здесь простые определения терминов, расшифровка сокращений и ссылка на инструкцию, где термин встречается на практике.

## Сокращения и английские названия

| Термин | Что это | Как с этим работать |
| --- | --- | --- |
| Active Directory (AD) | служба каталога Microsoft: список сотрудников и групп. Peregovorka проверяет в нём логин и пароль | [Как войти в систему](Как-войти-в-систему), [Как подключить Active Directory](Как-подключить-Active-Directory) |
| ALTCHA | проверка «я не робот»: браузер решает небольшую задачу, внешний сервис не нужен | [Как настроить безопасность входа](Как-настроить-безопасность-входа) |
| API | Application Programming Interface, программный интерфейс: способ, которым другие программы обращаются к системе | [Как использовать публичный API](Как-использовать-публичный-API) |
| `APP_MASTER_KEY` | главный ключ шифрования секретов в базе, хранится в `.env`. Без него сохранённые пароли не прочитать | [Резервное копирование и аварийное восстановление](Резервное-копирование-и-аварийное-восстановление) |
| ASR | Automatic Speech Recognition, автоматическое распознавание речи. Служба `asr` превращает голос в текст на вашем сервере | [Как получить стенограмму](Как-получить-стенограмму), [Как настроить распознавание речи](Как-настроить-распознавание-речи) |
| Backend | серверная часть: вход, права, API, фоновые задачи | [Как устроена Peregovorka](Как-устроена-Peregovorka) |
| CA | Certificate Authority, удостоверяющий центр: выдаёт сертификаты. Корневые сертификаты нужны, чтобы доверять каталогу и почте | [Как настроить сертификаты](Как-настроить-сертификаты) |
| CDN | Content Delivery Network, сеть доставки: отдельные серверы раздают эфир зрителям вместо основного сервера | [Как смотреть трансляцию](Как-смотреть-трансляцию), [Узлы CDN](Узлы-CDN) |
| CGNAT | NAT на стороне провайдера: у вашего маршрутизатора нет своего внешнего адреса, поэтому проброс портов не поможет | [Решение проблем: звонки и сеть](Решение-проблем-звонков-и-сети) |
| `DATA_ROOT` | каталог постоянных данных на сервере: база, записи, модели | [Как перенести данные между хранилищами](Как-перенести-данные-между-хранилищами), [Развёртывание](Архитектура-Развёртывание) |
| DMZ | демилитаризованная зона: отдельный сегмент сети между интернетом и внутренней сетью | [Публикация во внешний контур](Архитектура-Публикация-во-внешний-контур) |
| DNS | Domain Name System: связывает имя сервера с его адресом | [Как настроить сертификаты](Как-настроить-сертификаты) |
| DPAPI | Data Protection API: защита данных Windows, под ней хранится токен устройства приложения | [Как установить приложение для Windows](Как-установить-приложение-для-Windows) |
| DTLS-SRTP | шифрование звука и видео на пути между устройством и сервером звонков. Работает всегда | [Шифрование](Шифрование) |
| E2EE | End-to-End Encryption, сквозное шифрование: сервер пересылает звук и видео, но не может их прочитать | [Настройки комнаты](Настройки-комнаты), [Шифрование](Шифрование) |
| Egress | служба записи и эфира. Внутри неё браузер смотрит комнату и кодирует картинку | [Как настроить видеозапись и трансляции на сервере](Как-настроить-видеозапись-и-трансляции-на-сервере), [Запись трансляции](Запись-трансляции) |
| GigaAM | модель распознавания русской речи | [Как настроить распознавание речи](Как-настроить-распознавание-речи) |
| H.264 | способ сжатия видео. В нём записаны файлы MP4 и эфиры | [Качество эфира](Качество-эфира) |
| HLS | HTTP Live Streaming: видео нарезается на короткие файлы, плеер скачивает их по очереди. Работает через обычный HTTPS, задержка несколько секунд | [Как смотреть трансляцию](Как-смотреть-трансляцию), [Трансляция по ссылке и внешние площадки](Трансляция-по-ссылке-и-внешние-площадки) |
| ICE | Interactive Connectivity Establishment: способ, которым устройство и сервер звонков находят рабочий путь для звука и видео | [Как настроить LiveKit](Как-настроить-LiveKit) |
| LDAP, LDAPS | протокол обращения к каталогу пользователей. LDAPS: то же поверх TLS, порт 636 | [Как подключить Active Directory](Как-подключить-Active-Directory) |
| LiveKit | сервер звонков, передаёт звук, видео и показ экрана | [Как войти во встречу](Как-войти-во-встречу), [Как настроить LiveKit](Как-настроить-LiveKit) |
| LL-HLS | Low-Latency HLS, HLS с низкой задержкой: те же файлы, но плеер получает их маленькими частями. Задержка около 3 секунд на тестовой машине, без учёта вашей сети | [Как смотреть трансляцию](Как-смотреть-трансляцию), [Качество эфира](Качество-эфира) |
| LLM | Large Language Model, языковая модель: нейросеть, которая пишет протокол и резюме по тексту. Подключается по API | [Как выбрать языковую модель](Как-выбрать-языковую-модель), [Как настроить языковые модели](Как-настроить-языковые-модели) |
| MediaMTX | необязательная служба, которая делает LL-HLS из внутреннего потока эфира | [Как настроить видеозапись и трансляции на сервере](Как-настроить-видеозапись-и-трансляции-на-сервере) |
| MP4 | обычный файл видео. В нём сохраняются видеозапись встречи и запись эфира | [Где найти материалы встречи](Где-найти-материалы-встречи) |
| NAT | Network Address Translation: маршрутизатор скрывает адреса внутренней сети за одним внешним адресом | [Как настроить LiveKit](Как-настроить-LiveKit), [Сетевые потоки](Архитектура-Сетевые-потоки) |
| NER | Named Entity Recognition, распознавание именованных сущностей: находит в тексте имена людей и организаций для обезличивания | [Как работает обезличивание](Как-работает-обезличивание) |
| OCR | Optical Character Recognition, распознавание текста на картинках. В Peregovorka его нет: текст на изображениях не обезличивается | [Как работает обезличивание](Как-работает-обезличивание) |
| Origin (заголовок) | заголовок браузера с адресом страницы. Сервер сверяет его со списком разрешённых | [Как настроить reverse proxy и HTTPS](Как-настроить-reverse-proxy-и-HTTPS) |
| `.pgcfg` | зашифрованный архив настроек для переноса на другой сервер | [Как сделать резервную копию и перенести сервер](Как-сделать-резервную-копию-и-перенести-сервер) |
| RNNoise | нейросеть шумоподавления, работает прямо в браузере | [Как настроить устройства](Как-настроить-устройства) |
| RTMP, RTMPS | Real-Time Messaging Protocol: способ передать поток на видеоплощадку. RTMPS: то же с шифрованием TLS | [RTMP и RTMPS простыми словами](RTMP-и-RTMPS-простыми-словами), [Трансляция по ссылке и внешние площадки](Трансляция-по-ссылке-и-внешние-площадки) |
| RTP | Real-time Transport Protocol: передача звука в телефонии | [Как подключить SIP-телефонию](Как-подключить-SIP-телефонию) |
| SFU | Selective Forwarding Unit, медиасервер: пересылает потоки участникам, не смешивая их | [Как войти во встречу](Как-войти-во-встречу) |
| SIP | Session Initiation Protocol: протокол телефонии, через него подключается АТС | [Как подключить SIP-телефонию](Как-подключить-SIP-телефонию) |
| SMB | сетевая папка Windows и хранилищ NAS | [Подключение внешних хранилищ](Подключение-внешних-хранилищ) |
| SMTP | Simple Mail Transfer Protocol: протокол отправки почты | [Как подключить почту](Как-подключить-почту) |
| STUN | Session Traversal Utilities for NAT: внешний сервер сообщает вашему серверу его публичный адрес | [Как настроить LiveKit](Как-настроить-LiveKit), [Сетевые потоки](Архитектура-Сетевые-потоки#stun-turn-и-nat) |
| TLS | Transport Layer Security: шифрование соединения, то, что делает адрес `https://` | [Как настроить сертификаты](Как-настроить-сертификаты) |
| TOTP | Time-based One-Time Password, одноразовые коды по времени для второго шага входа | [Как войти в систему](Как-войти-в-систему), [Как настроить безопасность входа](Как-настроить-безопасность-входа) |
| TURN | Traversal Using Relays around NAT: сервер-посредник для звука и видео. В Peregovorka его нет, поэтому медиапорты должны быть открыты | [Решение проблем: звонки и сеть](Решение-проблем-звонков-и-сети) |
| VAD | Voice Activity Detection, определение речи: отделяет речь от тишины и режет звук на реплики | [Как настроить распознавание речи](Как-настроить-распознавание-речи) |
| VPN | Virtual Private Network: защищённый туннель во внутреннюю сеть организации | [Публикация во внешний контур](Архитектура-Публикация-во-внешний-контур) |
| WAF | Web Application Firewall: фильтр запросов перед приложением | [Защита публичного сервера](Защита-публичного-сервера-Peregovorka) |
| Webhook | запрос на ваш адрес при событии в системе, с подписью | [Как использовать webhook](Как-использовать-webhook) |
| WebRTC | Web Real-Time Communication: технология браузера для звука и видео с малой задержкой. На ней работают встречи и быстрый просмотр эфира | [Как войти во встречу](Как-войти-во-встречу), [Как включить микрофон и камеру](Как-включить-микрофон-и-камеру) |

| Организатор встречи | тот, кто начал встречу | [Маршрут организатора](Маршрут-организатора), [Кто что может во встрече](Кто-что-может-во-встрече) |
| Площадка | внешний видеосервис, куда идёт эфир: RUTUBE, VK Видео, YouTube, Twitch | [Трансляция по ссылке и внешние площадки](Трансляция-по-ссылке-и-внешние-площадки) |

| Презентационная комната | комната, где выступают руководители и те, кому дали слово, а остальные смотрят | [Как создать комнату](Как-создать-комнату) |
| Протокол | документ по итогам встречи: решения, задачи, открытые вопросы | [Как сформировать протокол](Как-сформировать-протокол), [Запись, стенограмма, протокол: в чём разница](Запись-стенограмма-протокол-в-чём-разница) |
| Профиль установки | `standalone` для выделенного сервера или `shared-host` для общего | [Установка на чистый сервер](Установка-на-чистый-сервер), [Установка на общий сервер](Установка-на-общий-сервер) |

| Руководитель комнаты | сотрудник или группа из списка **Руководители** комнаты | [Маршрут руководителя комнаты](Маршрут-руководителя-комнаты), [Управление участниками комнаты](Управление-участниками-комнаты) |
| Слово | право выступать в презентационной комнате, его выдаёт руководитель | [Реакции и поднятая рука](Реакции-и-поднятая-рука), [Кто что может во встрече](Кто-что-может-во-встрече) |
| Стенограмма | текст разговора с именами говорящих | [Как получить стенограмму](Как-получить-стенограмму) |
