# Шаблоны протоколов

*Для кого: организатор встречи, руководитель комнаты, администратор.*

## Зачем это нужно

Шаблон: это сохранённая инструкция для языковой модели. Если вы часто просите один и тот же вид документа, сохраните инструкцию один раз и применяйте её в два нажатия.

Шаблон задаёт только текст просьбы к модели. Это не бланк документа, и он не задаёт оформление файла. Шаблоны писем для рассылки устроены отдельно: их ведёт администратор.

## Когда пригодится

- В организации есть своя форма протокола.
- Для одних встреч нужны только поручения, для других полный документ.
- Вы хотите, чтобы все руководители комнат пользовались одной формой: нужен общий шаблон.

## Что потребуется

Право формировать документы: организатор, руководитель комнаты или администратор. Общие шаблоны создаёт только администратор.

| Вид | Как подписан в списке | Кто видит | Кто создаёт и удаляет |
| --- | --- | --- | --- |
| Личный | **Мой: название** | только автор | автор |
| Общий | **Общий: название** | все, кто открывает окно формирования | администратор |

## Где найти

- В работе: окно **Сформировать протокол**, блок **Шаблоны инструкций**.
- Общие шаблоны: **Администрирование → Встречи → Протоколы: общие шаблоны**.

## Как это сделать

### Применить шаблон

1. Откройте окно: кнопка **Сформировать протокол** на странице встречи.
2. Вверху выберите вид документа. Список показывает шаблоны этого вида и шаблоны для любого вида.
3. В блоке **Шаблоны инструкций** откройте список **— выберите шаблон —** и выберите шаблон.
4. Нажмите **Применить**. Текст появится в поле **Инструкция для модели** и заменит прежний.
5. При необходимости поправьте текст. Сам шаблон от этого не изменится.
6. Нажмите **Сформировать**.

### Сохранить свой шаблон

1. Напишите инструкцию в поле **Инструкция для модели**.
2. В поле **Название для сохранения текущей инструкции** введите название, до 200 знаков.
3. Нажмите **Сохранить как шаблон**.

Шаблон сохраняется для выбранного сейчас вида документа. Если нужен шаблон и для протокола, и для резюме, сохраните его дважды.

### Изменить личный шаблон

Отдельной кнопки изменения в окне нет.

1. Примените шаблон и поправьте текст.
2. Сохраните его под новым названием.
3. Выберите старый шаблон и нажмите **Удалить шаблон**.

### Создать общий шаблон

Первый способ, в окне формирования: администратор отмечает **общий (для всех)** перед нажатием **Сохранить как шаблон**.

Второй способ, в администрировании:

1. Откройте **Администрирование → Встречи → Протоколы: общие шаблоны**.
2. Нажмите **Создать шаблон**.
3. Заполните **Название шаблона**.
4. В поле **Для какого документа** выберите **Любой (полный протокол и резюме)**, **Только полный протокол** или **Только краткое резюме**.
5. Заполните **Инструкцию для модели**. Стенограмму добавлять не нужно: система добавит её сама.
6. Нажмите **Сохранить**.

### Как написать хорошую инструкцию

- Перечислите разделы, которые нужны.
- Попросите не придумывать то, чего нет в материалах.
- Не вставляйте в инструкцию имена без необходимости: при обезличивании они будут заменены вместе с текстом.

Примеры:

```text
Выдели только принятые решения и поручения. Для каждого поручения укажи ответственного и срок. Не выдумывай данные.
```

```text
Составь протокол: тема, участники, решения, поручения (кто, что, срок). Ничего не выдумывай.
```

### Постоянные дополнения

Шаблон применяется вручную. Если инструкция должна действовать всегда, используйте настройки:

- **Настройки комнаты… → Материалы → Дополнение к инструкции протокола**: добавляется к инструкции по умолчанию для всех встреч комнаты и документов обоих видов. Настраивает руководитель комнаты.
- **Администрирование → Встречи → Протоколы: инструкции и режим**: инструкция по умолчанию для всей организации. Настраивает администратор.

## Что получится

Шаблон виден в списке блока **Шаблоны инструкций**. Строка **Инструкция, по которой создан документ** под готовым документом показывает, какой текст ушёл модели.

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Шаблона нет в списке | он сохранён для другого вида документа | переключите вид документа вверху окна |
| Коллега не видит мой шаблон | личные шаблоны видит только автор | попросите администратора создать общий |
| Кнопка **Удалить шаблон** не видна | общий шаблон может удалить только администратор | обратитесь к администратору |
| Документ не следует шаблону | администратор включил структурный режим: разделы собирает система | см. [Как работают стенограмма и протоколы](Как-работают-стенограмма-и-протоколы) |
| Документ получился не такой, как просили | модель трактует инструкцию по-своему | уточните инструкцию, попробуйте другую модель |
