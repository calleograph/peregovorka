# Как установить приложение для Android

> Относится к приложению для Android 0.1.1 и серверу 0.50.1 · проверено 2026-10-29 · уровень проверки: 2–3 (эмуляторы Android 10, 14, 16 в CI с настоящим LiveKit; на физических телефонах не проверялось) · тип страницы: практическое руководство

Результат: приложение Peregovorka установлено на телефоне или планшете, подключено к серверу организации, и вы можете войти во встречу. Для кого: сотрудник и администратор, который помогает с установкой. Приложение — предварительный выпуск.

## Что нужно заранее

| Что | Зачем |
| --- | --- |
| Android 8.0 или новее | минимальная версия приложения |
| Адрес сервера Peregovorka организации (`https://…`) | сообщает администратор |
| Сервер 0.49.6 или новее | разделы «Календарь», «Чаты», «История» показываются без лишней навигации сайта (на старых серверах работают со своей) |
| Доверенный сертификат сервера с полной цепочкой | телефоны, в отличие от браузеров на компьютере, не докачивают промежуточные сертификаты ([[Разбор эксплуатационных случаев|Разбор-эксплуатационных-случаев]], случай 1) |

## Установка

1. Откройте страницу выпуска: ссылка «Приложение для Android» в подвале сайта Peregovorka или раздел «Приложение для Android» в [README](https://github.com/calleograph/peregovorka#readme).
2. Скачайте файл `Peregovorka-<версия>-android….apk`. Для проверки целостности сравните SHA-256 файла со строкой в `SHA256SUMS.txt`.
3. Разрешите установку из этого источника: «Настройки → Приложения → Особый доступ → Установка неизвестных приложений» (названия пунктов зависят от производителя).
4. Откройте приложение → «Добавить сервер» → адрес сервера → «Подключиться». Приложение проверит адрес и версию сервера.
5. Войдите: вход выполняет страница самого сервера (доменная учётная запись, второй фактор, CAPTCHA — как в браузере). После входа устройство запоминается.

Ожидаемый результат: на вкладке «Главная» — предстоящие встречи и переговорные; кнопки «Войти» у комнат.

## Обновление

Новую версию ставьте поверх прежней, тем же способом. **Исключение:** версии до 0.1.1 включительно подписаны временным ключом — первую версию с постоянным ключом можно поставить только после удаления прежней (сохранённые серверы и вход придётся добавить заново).

## Что умеет и чего нет

Работают: несколько серверов, вход страницей сервера, главная, конференция (звук, видео, переключение камеры, чат, участники, рука, чужая демонстрация экрана), звук при свёрнутом приложении, календарь, чаты, история, личный кабинет — страницами сервера. Нет: уведомлений о встречах и сообщениях, демонстрации своего экрана, гостевого входа по ссылке в приложении (открывается в браузере), версии для iPhone и iPad. Подробно — [docs/ANDROID.md](https://github.com/calleograph/peregovorka/blob/main/docs/ANDROID.md).

## Типичные ошибки

| Симптом | Причина | Что делать |
| --- | --- | --- |
| «Сервер не добавлен», ошибка сертификата | неполная цепочка или внутренний CA, которому телефон не доверяет | администратор исправляет цепочку на прокси; для внутреннего CA — установить его на телефон по политике организации |
| Приложение не устанавливается поверх | другая подпись (временный ключ) | удалить прежнюю версию и установить новую |
| Во встрече нет звука и видео | закрыты порты медиа из сети телефона | сравнить Wi-Fi организации и мобильную сеть; передать в поддержку ([[Руководство технической поддержки|Руководство-технической-поддержки]], сценарий «Невозможно подключиться с телефона») |
| Приложение свернулось при входе в конференцию | причина не установлена (на эмуляторах не воспроизводится) | приложить модель телефона, версию Android и журнал `adb logcat -s PGLIFE PGCALL` |
