# Диагностика трансляций

> Относится к версии 0.49.0 · проверено 2026-10-29 · уровень проверки: 3 (настоящие LiveKit Egress v1.15.0, nginx и Chromium в сквозном сценарии на синтетических участниках; живые люди, WebKit на устройстве и большие аудитории не проверялись) · тип страницы: справочник по ошибкам

Результат: вы находите причину, если эфир не стартует или зрители не видят картинку. Для кого: администратор, владелец комнаты.

## Где смотреть

**Администрирование → Трансляции**: идущие эфиры, зрители, объём HLS на диске, свободное место, предупреждения, последние прерванные эфиры с причиной. Логи: `scripts/logs.sh livekit-egress`, `scripts/video.sh status`.

## Типичные ошибки

| Симптом | Причина и действие |
|---|---|
| В меню «Ещё» нет пункта «Трансляция…» | трансляции выключены администратором, не включены в комнате, у вас нет прав руководителя или вход по гостевой ссылке |
| «Трансляции выключены администратором» | **Администрирование → Трансляции → Включить** |
| «Служба трансляций (LiveKit Egress) недоступна или не установлена» | `sudo scripts/video.sh enable`, затем `scripts/video.sh status`; Egress должен быть подключён к тому же Redis, что и LiveKit |
| «Сейчас идёт максимально допустимое число эфиров» | предел «Одновременных эфиров» достигнут; дождитесь окончания или увеличьте после замеров |
| «Мало свободного места на томе трансляций» | освободите диск или уменьшите порог |
| «В комнате никого нет» | эфир начинается, когда подключился выступающий |
| «При сквозном шифровании трансляция недоступна» | так задумано: у сервера нет ключа, чтобы собрать картинку |
| Зритель видит «Эфир запускается» дольше минуты | Egress не создал плейлист: смотрите журнал Egress; часто причина — `LIVEKIT_NODE_IP=127.0.0.1` |
| Зритель: «Не удаётся получить поток эфира» | web не видит том трансляций или секрет подписи: проверьте `${DATA_ROOT}/live/nginx/secret.conf`, перезапустите web |
| Плейлист отвечает 403 | подпись не сошлась: секрет изменился (смена `APP_MASTER_KEY`) — перезапустите web |
| Плейлист отвечает 410 | срок подписи вышел; страница зрителя продлевает сама, внешний плеер должен получить новую ссылку |
| Плейлист отвечает 404 | ссылка отозвана, пароль менялся или эфир закончился и каталог убран |
| Площадка в статусе «ошибка» («Connection refused», «Could not connect…») | сервер площадки недоступен с вашего сервера: проверьте адрес, порт и исходящий доступ (rtmp — порт 1935, rtmps — 443); остальные площадки и собственный просмотр продолжают работать; после исправления выключите и включите площадку |
| Площадка «подключается», но на ней пусто | неверный или просроченный ключ (у RUTUBE действует до 24 часов, у VK одноразовый ключ нужен новый для каждого эфира): замените ключ в «Изменить» |
| «Адрес сервера ведёт во внутреннюю сеть» | по умолчанию разрешены только серверы в интернете; для своего медиасервера внутри сети администратор включает «Разрешить серверы RTMP во внутренней сети» |
| «Этот адрес сервера не разрешён: он ведёт во внутреннюю или служебную сеть» | адреса loopback, link-local и метаданных облака запрещены всегда |
| «Эфир прерван: служба трансляций перестала отвечать» | контейнер Egress упал: сервер закрывает эфир сам в течение минуты; конференция продолжается; после запуска службы начните эфир заново |
