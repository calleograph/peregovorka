# Справочник: роли и права

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1–2 (код `backend/app/services/roles.py`, тесты `test_roles_floor.py`, `test_room_manage.py`) · тип страницы: справочник

Права проверяются **на backend**; интерфейс лишь скрывает ненужные кнопки. Запрет публикации в презентационной комнате закреплён и в токене LiveKit (`can_publish`, `can_publish_sources`): сервер звонков не примет дорожку, даже если изменить клиент.

## Роли

| Роль | Откуда берётся | Что может |
| --- | --- | --- |
| Администратор сервера (`system_admin`) | группа AD из «Доступа к администрированию» (или `LDAP_ADMIN_GROUP_DN`); локальный администратор | вся система: LLM, обезличивание, LDAP, хранилища, почта, обновление, журналы; руководитель любой комнаты |
| Руководитель комнаты (`room_leader`; их может быть несколько) | список «Руководители» комнаты: группы и люди AD | «Настройки комнаты»; слово; микрофоны и камеры; остановка показа экрана; удаление участников; запись и транскрибация; доска, камера, экран — всегда; история и материалы своей комнаты; рассылка. Глобальных настроек нет |
| Выступающий (`presenter`) | руководитель «дал слово» на текущей встрече | в презентационной комнате — микрофон, камера, показ экрана и правка доски; до конца встречи, постоянной роли не меняет. Руководителем не становится |
| Участник (`participant`) | вход по списку доступа комнаты | в обычной комнате — микрофон, камера, экран по правам комнаты; в презентационной — зритель |
| Гость (`guest`) | гостевая ссылка | минимальные права: без экрана, истории и стенограммы |
| Организатор встречи | тот, кто начал встречу | формирует протокол, резюме и карту; «Отправить материалы» |

Комната без руководителей работает: записью и транскрибацией может управлять любой участник; в презентационной комнате без руководителя управлять нечем.

## Что делает каждая роль с материалами встречи

| Действие | Участник | Организатор | Руководитель комнаты | Администратор |
| --- | --- | --- | --- | --- |
| Читать готовые документы (если есть доступ) | да | да | да | да |
| Формировать протокол, резюме, карту; «Сформировать заново» | нет | да | да | да |
| Выбрать другую модель на один раз | нет | нет | да | да |
| «Отправить материалы» вручную | нет | да | да | да |
| Постоянные настройки комнаты, рассылка по умолчанию, шаблоны писем | нет | нет | настройки комнаты | всё, включая LLM и почту |
| Диагностика встречи («Д» в «Администрирование → Встречи») | нет | нет | нет | да |

Ответ на недопустимое действие — HTTP 403; чужая комната и участник без права получают 404 или 403.

## Что меняет руководитель в настройках комнаты

Меняет: название и описание, тип комнаты, запись и автозапись, права участников (камера, экран, доска), число мест, пароль, приветствие, «микрофон при входе выключен», доступ (пользователи и группы AD), список руководителей, гостевой доступ и ссылку, материалы после встречи, модель для протокола и резюме (внутри разрешённых), телефонию комнаты.

Не меняет: языковую модель и обезличивание на уровне системы, хранилища, сроки хранения, технический идентификатор, включение и выключение комнаты. Нельзя оставить комнату совсем без руководителей (это может только администратор).

## Права гостя и вошедшего пользователя

| Что | Гость | Вошедший сотрудник |
| --- | --- | --- |
| Создавать и видеть список комнат | нет | да (по доступу) |
| Показ экрана | нет | по правам комнаты |
| История и стенограмма | нет | по правилам доступа |
| Чат встречи | да | да |
| Поднять руку | да | да |

## Доска

Параметр комнаты «Общая доска: кто работает»:

| Значение | Результат |
| --- | --- |
| «Как принято для типа комнаты» (по умолчанию) | обычная комната — рисуют все (если доска включена); презентационная — руководители и те, кому дали слово |
| «Все участники рисуют» | все |
| «Руководители и те, кому дали слово» | прежнее поведение презентации |
| «Рисуют только руководители, остальные смотрят» | в обычной комнате; в презентационной слово всегда даёт и доску |
| «Доска только у руководителей» | остальные не видят кнопку доски, сервер не отдаёт им схему и события доски |

Изменение действует у участников со следующего входа в комнату.
