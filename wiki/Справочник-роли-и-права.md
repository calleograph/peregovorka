# Справочник: роли и права

*Для кого: администратор, руководитель комнаты, специалист по безопасности.*

Права проверяет сервер. Интерфейс только скрывает лишние кнопки. Запрет публикации звука, видео и экрана записан и в разрешении на подключение к серверу звонков: он не примет дорожку, даже если изменить приложение.

Простая версия для участников: [Кто что может во встрече](Кто-что-может-во-встрече).

## Роли

| Роль | Как её получить | Что даёт |
| --- | --- | --- |
| Администратор сервера (`system_admin`) | группа администраторов или локальный администратор | вся система и любая комната |
| Руководитель комнаты (`room_leader`) | список **Руководители комнаты**; создатель временной комнаты | полное управление своей комнатой, без настроек системы |
| Выступающий (`presenter`) | руководитель дал слово на текущей встрече | в презентационной комнате: микрофон, камера, показ экрана, правка доски до конца встречи. Постоянную роль не меняет |
| Участник (`participant`) | сотрудник с доступом к комнате | в обычной комнате: по настройкам комнаты; в презентационной: слушатель |
| Гость (`guest`) | гостевая ссылка | микрофон и камера, если комната разрешает; чат; без показа экрана, истории и стенограммы |

## Состояния, которые тоже дают права

Это не роли в коде, но они действуют.

| Кто | Откуда | Что даёт |
| --- | --- | --- |
| Организатор встречи | тот, кто начал встречу | формировать и править документы и карту, отправлять материалы, скачивать общую запись, видеть контакты гостей и авторов вопросов |
| Владелец равноправной комнаты | создатель комнаты, не руководитель | срок, доступ, перевыпуск ссылки, закрытие |
| Участник комнаты без руководителей | у комнаты нет руководителей и она не презентационная | запись, стенограмма, эфир, **Завершить для всех**. Управлять другими участниками не может. Равноправная комната работает так же |
| Зритель эфира | ссылка зрителя | просмотр и свои вопросы. Не участник встречи: нет конференции, чата, доски, истории и материалов |
| Выступающий трансляции | вход как **Выступающий** | обычный участник. Пароль выступающего прав не добавляет |
| Модератор вопросов | любой присутствующий участник идущей встречи | отмечать вопросы зрителей. После встречи: только те, кто управляет встречей |
| Получатель доступа к встрече | выдано через **Управление доступом** | просмотр материалов одной встречи |
| Участник завершённой встречи | был в комнате в момент завершения и не ушёл со страницы | видит материалы, пока открыта страница, по умолчанию не дольше 120 минут |
| Администратор группы чата | создатель группы или назначенный | правка группы и участников. Со встречами не связан |

Отдельной роли «владелец комнаты» нет. Создатель постоянной комнаты дополнительных прав не получает: он только адресат варианта рассылки **Владельцу комнаты**.

Администратор сервера считается руководителем всех комнат.

## Что можно во встрече

Обозначения: да, нет, «по настр.» означает настройки комнаты.

| Действие | Администратор, руководитель | Участник | Участник со словом (презентация) | Слушатель (презентация) | Гость |
| --- | --- | --- | --- | --- | --- |
| Микрофон | да | да | да | нет | да, в презентации нет |
| Камера | да | по настр. | да | нет | по настр., в презентации нет |
| Показ экрана | да | по настр. | да | нет | нет |
| Чат встречи | да | да | да | да | да |
| Поднять руку | да | да | да | да | да |
| Выключить чужой микрофон или камеру | да | нет | нет | нет | нет |
| Остановить чужой показ, запретить показ | да | нет | нет | нет | нет |
| **Показать всем** на общей сцене | да | нет | нет | нет | нет |
| Дать слово, снять руку, удалить из встречи | да | нет | нет | нет | нет |

Показ экрана руководителя можно остановить, но запретить нельзя. Руководителя нельзя удалить из встречи.

Удалённый сотрудник не вернётся в эту встречу, 10 минут не войдёт в комнату и теряет доступ к материалам встречи.

## Управление встречей

Запись, стенограмма, эфир и **Завершить для всех** доступны тому, кто управляет встречей:

| Комната | Кто управляет |
| --- | --- |
| С руководителями | руководители и администраторы |
| Обычная без руководителей | любой участник |
| Равноправная | любой участник |
| Презентационная без руководителей | только администраторы |

## Материалы встречи

| Действие | Участник | Организатор | Руководитель | Администратор |
| --- | --- | --- | --- | --- |
| Видеть завершённую встречу | по правилу ниже | по правилу ниже | да | да |
| Формировать и переформировать протокол, резюме, карту | нет | да | да | да |
| Выбрать другую модель на один раз | нет | нет | да | да |
| Править документ | нет | да | да | да |
| Удалить документ | нет | нет | нет | да |
| **Отправить материалы** | нет | да | да | да |
| Слушать и смотреть общую запись | если видит встречу | если видит встречу | да | да |
| Скачать общую запись | нет | да | да | да |
| Записи отдельных участников | нет | нет | нет | да |
| Удалить запись или встречу | нет | нет | нет | да |
| **Управление доступом**, **История действий** | нет | нет | да | да |
| Диагностика встречи | нет | нет | нет | да |

**Кто видит завершённую встречу.** Администраторы и руководители видят всегда. Остальные видят, если выполнено одно из условий:

1. Человек был на встрече, а в комнате выбрано **Администраторы, руководители и все участники встречи**. Во временных комнатах это значение по умолчанию.
2. Доступ выдан через **Управление доступом**.
3. Человек был в комнате в момент завершения и ещё не ушёл со страницы встречи.

Значение по умолчанию в постоянной комнате: **Администраторы и руководители**. Поэтому участник видит предупреждение **Не закрывайте эту страницу, пока не сохранили нужное**.

Гость видит только идущую встречу, в которую вошёл. Истории и материалов у него нет.

## Настройки комнаты

| Настройка | Руководитель | Администратор |
| --- | --- | --- |
| Название, описание, значок, приветствие | да | да |
| Тип комнаты, запись, камера, экран, доска | да | да |
| Шифрование комнаты | да | да |
| Число мест, пароль, автозавершение | да | да |
| Доступ, руководители, гостевая ссылка | да | да |
| Трансляция, площадки, пароли эфира | да | да |
| Автоотправка, карта, инструкция протокола | да | да |
| Модель комнаты, из разрешённых | да | да |
| Обезличивание в комнате, в рамках политики сервера | да | да |
| Телефония комнаты | да | да |
| **Адрес комнаты** | нет | да |
| **Комната включена** | нет | да |
| Сроки хранения | видит | да |
| **Кто видит встречу после завершения** | видит | да |
| Оставить комнату без руководителей | нет | да |
| Создать и удалить постоянную комнату | нет | да |

Руководителю недоступны все настройки системы: языковые модели, каталог, хранилища, почта, обновление.

Подробно: [Настройки комнаты](Настройки-комнаты).

## Доска

Настройка **Общая доска** на вкладке **Встреча и запись**.

| Значение | Результат |
| --- | --- |
| **Как принято для типа комнаты** | обычная комната: рисуют все; презентационная: руководители и те, кому дали слово |
| **Все участники** | рисуют все |
| **Руководители и те, кому дали слово** | рисуют руководители и участники со словом |
| **Только руководители, остальные смотрят** | рисуют руководители. В презентационной комнате слово всё равно даёт доску |
| **Доска только у руководителей (остальные её не видят)** | остальные не видят кнопку доски, сервер не отдаёт им схему и события |

Руководители и администраторы рисуют всегда. Изменение действует у участников со следующего входа.

## Трансляции

- Настройки эфира, ссылки, пароли и площадки меняют руководители комнаты и администраторы.
- Начинают и останавливают эфир те, кто управляет встречей. В комнате без руководителей это любой участник.
- Пароль выступающего является паролем комнаты и не делает человека руководителем.
- Руководители и администраторы входят в трансляционную комнату без пароля выступающего. В обычной и презентационной комнате с включённым эфиром сервер требует пароль и от них.
- Пароль зрителя открывает только просмотр этого эфира.
- Руководитель одной комнаты не видит площадки, ключи и ссылки другой.

Подробно: [Роли выступающих и зрителей](Роли-выступающих-и-зрителей).

## Ответы сервера

На запрещённое действие сервер отвечает ошибкой 403. Чужая и несуществующая комната неразличимы: ответ 404.
