# Когда продукт не подходит

*Для кого: тот, кто решает, стоит ли ставить Peregovorka.*

Эта страница поможет решить, стоит ли тратить время на установку. Ниже перечислены случаи, когда Peregovorka не подойдёт или подойдёт с оговорками.

## Скорее всего, не подойдёт

**Вам нужен облачный сервис.** Peregovorka работает только на вашем сервере с Linux. Её нужно установить, обновлять и сопровождать, поэтому без администратора не обойтись: [Системные требования](Системные-требования).

**У вас нет каталога Active Directory или другого LDAP.** Сотрудники входят учётными записями из каталога. Локальная учётная запись одна: это аварийный администратор. Завести других локальных пользователей через интерфейс нельзя. Гостям и зрителям учётная запись не нужна: они заходят по ссылке.

**Нужен доступ по HTTP без HTTPS.** Без защищённого соединения браузер не даёт сайту ни микрофон, ни экран: [Как настроить reverse proxy и HTTPS](Как-настроить-reverse-proxy-и-HTTPS).

**Протокол должен быть юридически значимым без вычитки.** Языковая модель может пропустить поручение или принять предложение за решение, поэтому протокол перед подписанием вычитывает человек: [Как работают стенограмма и протоколы](Как-работают-стенограмма-и-протоколы).

**Текст встреч нельзя передавать за пределы организации ни в каком виде.** Протоколы пишет языковая модель по API. Если своего сервера модели в сети организации нет, текст уходит внешнему провайдеру, пусть и обезличенным: [Как настроить обезличивание](Как-настроить-обезличивание). Стенограммы и записи работают без модели.

**Данные нужно защищать от администратора сервера.** Чтобы показать пользователю стенограмму, сервер расшифровывает её в памяти. Администратор с мастер-ключом и доступом к памяти процессов может прочитать содержимое: [Шифрование](Шифрование).

**Нужна гарантированная вместимость.** Сквозного испытания всей системы не было. Ни один замер не сделан на отдельном физическом сервере с настоящими пользователями. Если у вас есть требование к числу участников, проверьте его у себя: [Что известно о нагрузке](Возможности#что-известно-о-нагрузке).

## Подойдёт с оговорками

**Встречи с большим числом участников.** Настоящими браузерами проверялось 3–5 участников одновременно, остальное на синтетических клиентах. Встречи с 20 камерами и больше не проверялись.

**Мероприятия с большой аудиторией.** Для этого есть трансляции: выступающие говорят в комнате, зрители смотрят эфир по ссылке. Эфир раздаётся через CDN или внешние площадки. Наибольший замер: 1500 моделируемых зрителей на узле CDN, на одном сервере, 60 секунд. Статус: проверено в ограниченном сценарии. На настоящей аудитории это не проверялось: [Режим трансляции](Режим-трансляции), [Кто создаёт нагрузку при трансляции](Кто-создаёт-нагрузку-при-трансляции).

**Нужны Safari, Firefox или iPhone.** Основная проверка идёт в Chrome и Edge, а также в приложениях для Windows, Linux и Android. В Safari и Firefox продукт не проверялся. Приложений для iPhone, iPad и macOS нет.

**Нужна работа на телефоне наравне с компьютером.** В приложении для Android нет доски, стенограммы в комнате, управления записью и участниками, уведомлений о сообщениях: [Веб-версия и приложения](Веб-версия-и-приложения).

**Нужен единый вход в Outlook.** Надстройка Outlook работает, но вход в ней по логину и паролю: [Как подключить надстройку Outlook](Как-подключить-надстройку-Outlook).

**Нужны ключи доступа (WebAuthn).** Их пока нет. Второй фактор — одноразовые коды из приложения-аутентификатора: [Как настроить безопасность входа](Как-настроить-безопасность-входа).

**У сервера нет интернета.** Установщику нужны GitHub, PyPI, npm, Docker Hub и источник моделей. Модели можно принести заранее готовым каталогом, но для сборки образов в закрытой сети понадобятся зеркала этих источников: [Установка на чистый сервер](Установка-на-чистый-сервер).

**Вы внедряете продукт в крупной организации.** Связь с Active Directory, почтой, сетевыми папками, АТС и Exchange проверялась на тестовых заменах этих систем, а не на настоящих серверах. Проверьте интеграции у себя, прежде чем открывать доступ сотрудникам: [Что проверено](Границы-проверки).

## Что ещё учесть

- **Лицензия пока не выбрана.** В репозитории нет файла лицензии, поэтому условия использования, особенно коммерческого, нужно уточнять у владельца проекта: [Лицензия](Лицензия).
- **Приложения — предварительные выпуски.** Установщики для Windows не подписаны сертификатом издателя, и Windows покажет предупреждение SmartScreen. Приложение для Android ставится из файла APK, а не из магазина.
- **Серверу нужны ресурсы.** Установщик проверяет 4 ядра, 8 ГБ памяти и 30 ГБ диска. Это порог проверки при установке, а не подтверждённая рабочая конфигурация. На этом минимуме работа не испытывалась, запись и эфир в него не входят. Статус: требует дополнительного тестирования. Подробнее: [Системные требования](Системные-требования).
