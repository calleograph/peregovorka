# Когда продукт не подходит

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1–3 · тип страницы: объяснение

Страница помогает решить, стоит ли тратить время на установку. Каждое ограничение опирается на код или документ проекта; источник указан в скобках.

## Продукт не подходит, если

| Ваша ситуация | Почему | Источник |
| --- | --- | --- |
| Нужен готовый облачный сервис без собственного сервера | продукт ставится только на ваш сервер Linux и требует администратора | [[Системные требования|Системные-требования]] |
| В организации нет Active Directory и сотрудникам нужны обычные учётные записи | сотрудники входят через LDAP-каталог; локальная учётная запись одна — аварийный администратор; создать других локальных пользователей через интерфейс нельзя (в коде такая функция вызывается только установщиком и `admin-reset.sh`) | `backend/app/cli.py` (уровень 1) |
| Нужна видеозапись встречи | сохраняется только звук; видеозапись запланирована, пункт «Аудио и видео» в настройках комнаты недоступен | [[Планы развития|Планы-развития]] |
| На одну встречу придут тысячи зрителей и вам нужно одним узлом | приложение (HTTP, база) выдерживало 2000 синтетических пользователей на ВМ с 8 vCPU, но видео зрителям на одном узле LiveKit упирается в процессор: 300 зрителей 720p занимали около 3 ядер | [[Производительность и масштабирование|Производительность-и-масштабирование]] |
| Нужен доступ только по HTTP без HTTPS | браузер не даёт микрофон и экран без защищённого соединения | [[Как настроить reverse proxy и HTTPS|Как-настроить-reverse-proxy-и-HTTPS]] |
| Нужна поддержка Safari или Firefox с гарантией | основная проверка идёт в Chrome и Edge; Safari и Firefox не проверялись | [[Границы проверки|Границы-проверки]] |
| Нужны юридически значимые протоколы без вычитки | встроенная модель Qwen3 1.7B небольшая: пропускает часть поручений и может принять предложение за решение | [[Как работают стенограмма и протоколы|Как-работают-стенограмма-и-протоколы]] |
| Нужен единый вход (SSO) в Outlook | вход в надстройке — логин и пароль; SSO не реализован | [[Как подключить надстройку Outlook|Как-подключить-надстройку-Outlook]] |
| Нужна поддержка WebAuthn и ключей доступа | не реализовано; доступны одноразовые коды TOTP | [[Как настроить безопасность входа|Как-настроить-безопасность-входа]] |
| Сервер без доступа в интернет и без подготовки | при установке нужны GitHub, PyPI, npm, Docker Hub, источник моделей; для закрытой сети есть режим с готовым каталогом моделей, но сборка образов всё равно требует зеркал | [[Установка на чистый сервер|Установка-на-чистый-сервер]] |
| Нужна защита от самого администратора сервера | сервер расшифровывает данные в памяти, чтобы показать их пользователям; администратор с доступом к памяти процесса и мастер-ключу содержимое получить может | [[Шифрование]] |

## Что стоит учесть до решения

- **Лицензия не указана в репозитории.** В интерфейсе продукт называется открытым, но файла лицензии нет; выяснить условия использования в коммерческом проекте по документам нельзя ([[Лицензия]]).
- **Приложение для Windows — предварительный выпуск.** Установщики не подписаны сертификатом издателя; Windows покажет SmartScreen.
- **Проверка на реальной инфраструктуре не завершена.** Каталоги, почта, SMB и АТС проверялись на подставных системах ([[Границы проверки|Границы-проверки]]).
- **Требования к оборудованию:** от 4 vCPU, 8 ГБ памяти, 30 ГБ диска; распознавание речи на процессоре занимает основную часть ([[Системные требования|Системные-требования]]).
