# Когда продукт не подходит

Эта страница поможет решить, стоит ли тратить время на установку. Ниже перечислены случаи, когда Peregovorka не подойдёт или подойдёт с оговорками.

## Скорее всего, не подойдёт

**Вам нужен облачный сервис.** Peregovorka работает только на вашем сервере с Linux. Её нужно установить, обновлять и сопровождать, поэтому без администратора не обойтись ([Системные требования](Системные-требования)).

**У вас нет Active Directory.** Сотрудники входят под учётными записями из каталога LDAP. Локальная учётная запись одна — это аварийный администратор. Завести других локальных пользователей через интерфейс нельзя. Гостям учётная запись не нужна: они заходят во встречу по ссылке.

**Нужен доступ по HTTP без HTTPS.** Без защищённого соединения браузер не даёт сайту ни микрофон, ни экран ([Reverse proxy и HTTPS](Как-настроить-reverse-proxy-и-HTTPS)).

**Протокол должен быть юридически значимым без вычитки.** Встроенная модель Qwen3 1.7B небольшая. Она может пропустить поручение или принять предложение за решение, поэтому протокол перед подписанием вычитывает человек. Более сильную внешнюю модель подключить можно, но тогда текст уходит за пределы сервера ([Как работают стенограмма и протоколы](Как-работают-стенограмма-и-протоколы)).

**Данные нужно защищать от администратора сервера.** Чтобы показать пользователю стенограмму, сервер расшифровывает её в памяти. Администратор, у которого есть мастер-ключ и доступ к памяти процессов, может прочитать содержимое ([Шифрование](Шифрование)).

## Подойдёт с оговорками

**Встречи с тысячами зрителей.** Обычная комната рассчитана на рабочие встречи. Для большой аудитории есть трансляции: выступающие говорят в конференции, а зрители смотрят эфир по ссылке. Для тысяч зрителей эфир раздаётся через CDN или внешние площадки. Проверялось это на синтетических зрителях, а не на настоящей аудитории ([Массовые трансляции](Массовые-трансляции), [Производительность](Производительность-и-масштабирование)).

**Нужны Safari, Firefox или iPhone.** Основная проверка идёт в Chrome и Edge, а также в приложениях для Windows и Android. В Safari и Firefox продукт не проверялся, приложения для iPhone и iPad нет.

**Нужен единый вход в Outlook.** Надстройка Outlook работает, но вход в ней по логину и паролю ([Надстройка Outlook](Как-подключить-надстройку-Outlook)).

**Нужны ключи доступа (WebAuthn).** Их пока нет. Второй фактор — одноразовые коды из приложения-аутентификатора ([Безопасность входа](Как-настроить-безопасность-входа)).

**У сервера нет интернета.** Установщику нужны GitHub, PyPI, npm, Docker Hub и источник моделей. Модели можно принести заранее готовым каталогом, но для сборки образов в закрытой сети понадобятся зеркала этих источников ([Установка на чистый сервер](Установка-на-чистый-сервер)).

**Вы внедряете продукт в крупной организации.** Связь с Active Directory, почтой, сетевыми папками, АТС и Exchange проверялась на тестовых заменах этих систем, а не на настоящих серверах. Проверьте интеграции у себя, прежде чем открывать доступ сотрудникам ([Что проверено](Границы-проверки)).

## Что ещё учесть

- **Лицензия пока не выбрана.** В репозитории нет файла лицензии, поэтому условия использования, особенно коммерческого, нужно уточнять у владельца проекта ([Лицензия](Лицензия)).
- **Приложения — предварительные выпуски.** Установщики для Windows не подписаны сертификатом издателя, и Windows покажет предупреждение SmartScreen. Приложение для Android ставится из файла APK, а не из магазина.
- **Серверу нужны ресурсы.** Минимум — 4 ядра, 8 ГБ памяти и 30 ГБ диска. Больше всего процессора занимает распознавание речи ([Системные требования](Системные-требования)).
