# Как работает обезличивание

*Для кого: организатор встречи, руководитель комнаты, сотрудники.*

## Зачем это нужно

Языковая модель часто работает вне вашей организации. Обезличивание заменяет имена, адреса, реквизиты и суммы на обозначения **до** отправки текста в модель. Замена выполняется на вашем сервере, сторонние службы для неё не нужны.

Настройка профилей и словарей описана отдельно: [Как настроить обезличивание](Как-настроить-обезличивание). Здесь объяснено, что происходит с вашим документом и что выбрать.

## Когда пригодится

- На встрече обсуждали клиентов, договоры, персональные данные.
- Модель подключена через внешний сервис.
- Нужно передать стенограмму без имён.
- Документ обезличен, а вам нужны настоящие имена.

## Что потребуется

- Выбрать режим для документа могут те, кто его формирует: организатор, руководитель комнаты, администратор.
- Включить обезличивание для комнаты может руководитель, если администратор это разрешил.
- Обезличенную стенограмму может скачать любой, у кого есть доступ к встрече.

## Что заменяется

| Было | Стало (базовый профиль) |
| --- | --- |
| Иван Петров | Иван П. |
| ООО «Ромашка» | Организация 1 |
| имя внутреннего сервера, 192.0.2.15 | [сервер 1], [IP 1] |
| m.petrova@example.org | [почта 1] |
| телефон, адрес | [телефон], [адрес] |
| ИНН, СНИЛС, паспорт, счёт | [идентификатор], [реквизит] |
| договор № 45-17/2026, 1,2 млн руб. | [номер 1], [сумма] |

В строгом профиле участники становятся «Участник 1», а места и все организации тоже заменяются. Полная таблица: [Как настроить обезличивание](Как-настроить-обезличивание).

Один человек в пределах встречи получает одно обозначение во всех документах.

**Пароли, токены и ключи убираются всегда**, даже без обезличивания. Если эта проверка не выполнилась, запрос не отправляется.

## С обезличиванием и без

| | С обезличиванием | Без обезличивания |
| --- | --- | --- |
| Что уходит в модель | текст с обозначениями | настоящие имена и данные, кроме паролей и ключей |
| Что в готовом документе | обозначения: «Иван И.», [сервер 1] | настоящие имена |
| Можно вернуть имена | нет, таблица замен не сохраняется | не требуется |
| Если замена не удалась | документ не создаётся, текст в модель не уходит | не применимо |
| Удобство чтения | ниже, поручения подписаны обозначениями | выше |

Выбирайте обезличивание, если модель внешняя, а в разговоре есть чувствительные данные. Выбирайте без обезличивания, если модель работает внутри организации или организация разрешила передавать такие данные этой модели. Если не уверены, спросите администратора.

## Режимы документа

В окне **Сформировать протокол** и в окне **Параметры…** карты разговора есть блок **Обезличивание**:

| Режим | Что делает |
| --- | --- |
| **По настройкам: с обезличиванием** или **По настройкам: без обезличивания** | как задано в комнате и на сервере |
| **С обезличиванием** | заменить данные в этом документе, даже если в комнате выключено |
| **Без обезличивания** | не заменять в этом документе, даже если в комнате включено |

Выбор действует только на этот документ. Настройки комнаты и сервера не меняются. Окно открывается с режимом прошлого документа этого вида, если он всё ещё разрешён.

Откуда берётся значение **По настройкам**:

1. Если администратор включил **Обязательно для всех комнат**, документ обезличивается всегда.
2. Иначе решает настройка комнаты **Обезличивать материалы встреч этой комнаты**. По умолчанию она выключена.

Ограничения:

| Что видите | Почему |
| --- | --- |
| **Без обезличивания** недоступно, текст «Обезличивание обязательно на этом сервере: снять его для документа может только администратор» | обезличивание обязательно; снять его может только администратор сервера |
| **С обезличиванием** недоступно, текст «Обезличивание выключено администратором сервера» | администратор запретил обезличивание |

Подсказка под инструкцией в окне прямо говорит, что будет сделано. Обязательно прочитайте её перед нажатием **Сформировать**.

## Где найти

- Для одного документа: окно **Сформировать протокол**, блок **Обезличивание**.
- Для карты: вкладка **Карта разговора** → **Параметры…**.
- Для стенограммы: **Ещё** на странице встречи, пункты с припиской **, обезличенная**.
- Для всей комнаты: **Настройки комнаты… → Языковая модель → Обезличивание перед языковой моделью**.

## Как это сделать

### Обезличить один документ

1. Откройте окно **Сформировать протокол**.
2. В блоке **Обезличивание** выберите **С обезличиванием**.
3. Прочитайте подсказку под полем инструкции.
4. Нажмите **Сформировать**.

### Включить для всей комнаты

Нужны права руководителя комнаты.

1. В комнате нажмите кнопку настроек и выберите **Настройки комнаты…**.
2. Откройте вкладку **Языковая модель**.
3. В блоке **Обезличивание перед языковой моделью** отметьте **Обезличивать материалы встреч этой комнаты**.
4. Если доступен выбор профиля, выберите его.
5. Нажмите **Сохранить**.

### Проверить, что документ обезличен

В строке документа в списке есть слово **обезличено**. Его видят все, у кого есть доступ к встрече. Администратор в блоке **Как создан документ: время, модель, части** видит профиль и число замен по категориям. Сами значения нигде не показываются.

## Что происходит с разными материалами

| Материал | Обезличивается? |
| --- | --- |
| Протокол, резюме | по выбранному режиму документа; стенограмма, чат, подписи на доске, инструкция и список присутствующих обезличиваются вместе |
| Карта разговора | по выбранному режиму карты |
| Стенограмма на странице встречи | нет, показывается исходной |
| Стенограмма, скачанная с припиской **, обезличенная** | да, всегда |
| Стенограмма в письме | по настройке комнаты, а не по режиму документа. Если обезличить не удалось, она не отправляется |
| Протокол в письме | уходит таким, каким сформирован |
| Запись | нет, звук и видео не меняются |
| Адреса получателей письма | нет, они берутся из учётных записей и контактов гостей |

Обратите внимание: документ, сформированный **Без обезличивания**, отправляется по почте с настоящими именами.

## Что получится

Документ содержит обозначения вместо данных. Исходная стенограмма на сервере не изменена. Запись о формировании попадает в журнал аудита вместе с выбранным режимом.

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Документ не создан, причина «Обезличивание не выполнено» | на сервере нет нужных файлов или произошёл сбой; текст в модель не уходил | сообщите администратору |
| Какое-то имя осталось в тексте | редкое имя или имя, совпадающее с обычным словом | администратор добавляет его в словарь; участники встречи находятся по списку всегда |
| Нужны настоящие имена | таблица замен не хранится | сформируйте заново **Без обезличивания**, если это разрешено |
| Человека можно узнать по смыслу | обезличивание не убирает содержание разговора | для особо чувствительных встреч не используйте языковую модель |
| В подсказке под документом упомянуты метки вида `[ФИО_1]` | это устаревший пример в тексте подсказки | настоящие обозначения выглядят как в таблице выше |
