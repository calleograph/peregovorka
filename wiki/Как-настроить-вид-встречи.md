# Как настроить вид встречи

*Для кого: все участники встречи. Раздел об общей сцене для руководителя комнаты.*

## Зачем это нужно

Вы сами решаете, что видите крупно: говорящего, показ экрана, доску или всех участников. Ваши настройки не меняют вид у других.

## Когда пригодится

- Нужно видеть всех одинаковыми плитками.
- Показ экрана слишком мал.
- Вы хотите постоянно видеть одного докладчика.
- Руководитель вывел доску всем, а вам нужно смотреть своё.

## Что потребуется

Вход во встречу. Вывод на общую сцену доступен руководителю комнаты и администратору.

## Где найти

- Кнопка **Вид** в нижней панели.
- На телефоне: **Ещё** → **Вид сцены**.
- Меню плитки: правая кнопка мыши, кнопка `⋯` или Shift+F10.

## Как это сделать

### Выбрать раскладку

Нажмите **Вид** и выберите режим.

| Режим | Что покажет |
| --- | --- |
| **Авто** | показ экрана, доска или говорящий крупно, остальные колонкой справа. Если показа нет и участников не больше девяти, будет сетка |
| **Сетка** | все участники одинаковыми плитками |
| **Сцена** | главное крупно, остальные лентой снизу |
| **Рядом** | главное крупно, остальные колонкой справа |

На телефоне крупным всегда идёт один элемент, остальные находятся в ленте снизу. Переключаться можно свайпом.

### Открыть плитку крупно

Дважды нажмите на плитку или откройте её меню и выберите **Открыть крупно**. С клавиатуры на плитке работает Alt+Enter. Чтобы вернуться, выберите **Вернуть общую раскладку**.

### Закрепить плитку

1. Откройте меню плитки.
2. Выберите **Закрепить у себя**. На плитке появится значок закрепления.

Можно закрепить до четырёх элементов. Самое старое закрепление вытесняется новым. На телефоне крупно показывается один.

Снять закрепление можно пунктом **Открепить у себя**. Сбросить все закрепления поможет **Вид** → **Сбросить мои закрепления** или клавиша Esc.

### Другие пункты меню плитки

| Пункт | Что делает |
| --- | --- |
| **Открыть карточку** | показывает сведения об участнике |
| **Во весь экран** | разворачивает плитку |
| **Картинка в картинке** | открывает плитку в отдельном окне, см. [Плавающее окно встречи](Плавающее-окно-встречи) |
| **Заглушить для себя** | убирает звук участника только у вас. Остальные его слышат |
| **Копировать ФИО**, **Копировать e-mail** | копируют данные участника |

### Что видно крупно

Система выбирает главный элемент в таком порядке:

1. ваши закрепления;
2. общая сцена, которую вывел руководитель;
3. чужие показы экрана;
4. доска, если она открыта;
5. говорящий.

### Общая сцена

Руководитель может показать один элемент всем.

Руководителю:

1. Откройте меню плитки и выберите **Показать всем**.
2. Чтобы добавить ещё элемент, выберите **Добавить на общую сцену**. Всего можно вывести до четырёх элементов.
3. Чтобы убрать один элемент, выберите **Убрать с общей сцены**. Чтобы убрать всё, выберите **Вид** → **Очистить общую сцену**.

Участнику:

1. Вверху появляется строка с именем ведущего и тем, что он показывает. На плитке видна метка **Всем**.
2. Нажмите **Вернуться к своему виду**, чтобы смотреть свою раскладку.
3. Чтобы вернуться к общей сцене, нажмите **Смотреть общую сцену** или выберите **Вид** → **Смотреть общую сцену (как у ведущего)**.

Ваши закрепления важнее общей сцены.

### Изменить правую панель

- Перетащите границу панели, чтобы изменить ширину. С клавиатуры работают стрелки влево и вправо.
- Кнопка **Свернуть панель** освобождает место для сцены.

### Развернуть доску

На панели доски нажмите **Развернуть**. Доска займёт почти всё окно только у вас. Вернитесь кнопкой **Вернуться к встрече** или клавишей Esc.

### В приложениях

В приложениях для Windows и Linux всё работает как в браузере.

В приложении для Android: выбора раскладки нет. Участники идут сеткой, а показ экрана занимает всё свободное место. Изображение приближается жестами, а кнопка полноэкранного режима разворачивает его. Панель кнопок возвращается по касанию.

## Что получится

Раскладка меняется только у вас. Выбор сохраняется для этой встречи в этом браузере. В новой встрече снова будет **Авто**.

## Если не получается

| Что происходит | Почему | Что сделать |
| --- | --- | --- |
| Нет кнопки **Вид** | вы на узком экране | откройте **Ещё** → **Вид сцены** |
| Раскладка не меняется | действует ваше закрепление | сбросьте закрепления |
| Вид сам сменился на чужой экран | начался показ экрана | закрепите нужную плитку |
| Нет пункта **Показать всем** | вы не руководитель | попросите руководителя |
| Нет пункта **Картинка в картинке** | браузер не поддерживает режим | см. [Плавающее окно встречи](Плавающее-окно-встречи) |
