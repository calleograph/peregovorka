# Кто что может во встрече

*Для кого: все, кто участвует во встречах и организует их. Настройка прав в системе описана в статье [Справочник: роли и права](Справочник-роли-и-права).*

## Зачем это нужно

Права зависят от роли человека и от настроек комнаты. Эта страница отвечает на вопрос, почему у коллеги есть кнопка, а у вас её нет.

## Какие бывают роли

| Роль | Кто это | Как её получают |
| --- | --- | --- |
| Участник | сотрудник с доступом к комнате | группа или человек в списке **Кто может заходить** |
| Организатор | сотрудник, который начал эту встречу, то есть вошёл первым | действует для одной встречи |
| Руководитель комнаты | полностью управляет комнатой. Руководителей может быть несколько | список **Руководители комнаты**. Создатель временной комнаты становится руководителем сам |
| Гость | человек без учётной записи | [гостевая ссылка](Как-подключить-гостя) |
| Администратор | администратор сервера | группа администраторов или локальная учётная запись администратора. Имеет права руководителя во всех комнатах |

Отдельной роли «владелец комнаты» нет. В старых материалах так называли руководителя. У создателя равноправной комнаты есть технические права на ссылку, но участником он остаётся обычным.

Организатор и руководитель могут быть разными людьми. Участник, который вошёл первым, становится организатором этой встречи, но не руководителем комнаты.

Есть временные состояния:

- **Выступающий.** Участник презентационной комнаты, которому руководитель дал слово. Слово действует до конца встречи или пока его не заберут.
- **Выступающий трансляции.** Отдельной роли нет: это участник, вошедший по ссылке выступающих. Пароль выступающего прав не добавляет.
- **Зритель эфира.** Не участник встречи: смотрит трансляцию по ссылке и задаёт вопросы.

## Права во время встречи

Знаки: ✓ можно, ✗ нельзя.

| Действие | Гость | Участник | Организатор | Руководитель | Администратор |
| --- | --- | --- | --- | --- | --- |
| Говорить и включать камеру | ✓ по настройке | ✓ по настройке | ✓ по настройке | ✓ | ✓ |
| Показывать экран | ✗ | ✓ по настройке | ✓ по настройке | ✓ | ✓ |
| Писать в чат, отправлять файлы, ставить реакции | ✓ | ✓ | ✓ | ✓ | ✓ |
| Поднимать руку | ✓ | ✓ | ✓ | ✓ | ✓ |
| Видеть стенограмму в комнате | ✗ | ✓ | ✓ | ✓ | ✓ |
| Рисовать на доске | по настройке | по настройке | по настройке | ✓ | ✓ |
| Выключать чужой микрофон или камеру | ✗ | ✗ | ✗ | ✓ | ✓ |
| Останавливать чужой показ экрана | ✗ | ✗ | ✗ | ✓ | ✓ |
| Выводить на общую сцену | ✗ | ✗ | ✗ | ✓ | ✓ |
| Давать слово, опускать чужую руку | ✗ | ✗ | ✗ | ✓ | ✓ |
| Удалять из встречи | ✗ | ✗ | ✗ | ✓ | ✓ |
| Включать запись и управлять стенограммой | ✗ | ✗ | ✗ | ✓ | ✓ |
| Вести эфир | ✗ | ✗ | ✗ | ✓ | ✓ |
| Завершать встречу для всех | ✗ | ✗ | ✗ | ✓ | ✓ |
| Менять настройки комнаты | ✗ | ✗ | ✗ | ✓ | ✓ |

Руководителя нельзя удалить из встречи и нельзя запретить ему показ экрана. Его показ можно только остановить.

«По настройке» означает, что решение принимается в **Настройки комнаты…** → **Встреча и запись** → **Что доступно участникам**. Варианты для доски: **Все участники**, **Руководители и те, кому дали слово**, **Только руководители, остальные смотрят**, **Доска только у руководителей (остальные её не видят)**.

### Презентационная комната

Участник и гость входят зрителями: они слушают, читают чат и поднимают руку. Микрофон, камера и показ экрана им недоступны. Слово открывает участнику весь набор сразу, включая правку доски. У гостя показа экрана нет и со словом.

### Комната без руководителей

Такой является равноправная комната, а также обычная комната с пустым списком руководителей. В ней любой участник управляет записью, стенограммой и эфиром и может завершить встречу для всех.

Выключать других и удалять их он не может. В презентационной комнате это правило не действует: там без руководителя такими функциями может пользоваться только администратор.

### Настройки, которых нет у руководителя

Только администратору доступны адрес комнаты, её включение и выключение, сроки хранения и поле **Кто видит встречу после завершения**. Последнего руководителя из списка может убрать только администратор.

## Вход и пароль

| Ситуация | Кто вводит пароль комнаты |
| --- | --- |
| Обычная и презентационная комната с паролем | все: участники, гости, организатор, руководители, администраторы |
| Трансляционная комната с паролем | все, кроме руководителей комнаты и администраторов |

Руководитель всегда может войти в свою комнату, даже если его нет в списке **Кто может заходить**. Администратор видит все включённые комнаты.

Гость не может начать встречу: первым должен войти сотрудник.

## Права после встречи

| Действие | Гость | Участник | Организатор | Руководитель | Администратор |
| --- | --- | --- | --- | --- | --- |
| Видеть завершённую встречу | ✗ | см. ниже | ✓, если не удалён из встречи | ✓ | ✓ |
| Слушать общую запись | ✗ | если видит встречу | ✓, если не удалён из встречи | ✓ | ✓ |
| Скачивать общую запись | ✗ | ✗ | ✓ | ✓ | ✓ |
| Формировать протокол, резюме, карту | ✗ | ✗ | ✓ | ✓ | ✓ |
| Править документ | ✗ | ✗ | ✓ | ✓ | ✓ |
| Отправлять материалы | ✗ | ✗ | ✓ | ✓ | ✓ |
| Выбирать другую модель на один раз | ✗ | ✗ | ✗ | ✓ | ✓ |
| Выдавать доступ к встрече, смотреть историю действий | ✗ | ✗ | ✗ | ✓ | ✓ |
| Удалять документ, запись, встречу | ✗ | ✗ | ✗ | ✗ | ✓ |
| Записи отдельных участников | ✗ | ✗ | ✗ | ✗ | ✓ |

По умолчанию постоянная комната оставляет завершённую встречу руководителям, администраторам и организатору, то есть тому, кто её начал. Обычный участник видит её, пока открыта страница встречи, поэтому только ему показано предупреждение **Не закрывайте эту страницу, пока не сохранили нужное**. Обновление страницы доступ не закрывает. Если администратор разрешил доступ участникам, встреча видна им и в **Истории**. Также руководитель может выдать доступ к одной встрече через **Управление доступом**. Во временной комнате завершённая встреча доступна её участникам.

Удалённый из встречи участник теряет доступ к её материалам.

Гость материалы не открывает. Он получает их письмом, если указал почту и согласился на отправку.

## Вопросы зрителей

Отмечать вопросы зрителей может любой присутствующий участник идущей встречи. После встречи это могут только те, кто управляет встречей. Подробно: [Вопросы зрителей](Вопросы-зрителей).

## Что отличается в приложении для Android

Роль не меняется, но часть функций в приложении отсутствует. Там нет доски, стенограммы в комнате, записи, управления участниками, настроек комнаты и завершения встречи для всех. Руководитель, которому это нужно, открывает встречу на компьютере.
