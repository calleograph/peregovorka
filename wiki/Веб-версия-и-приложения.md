# Веб-версия и приложения

*Для кого: сотрудник, который выбирает, где работать, и администратор, который советует клиент организации.*

## Зачем это нужно

С Peregovorka можно работать в браузере и в приложениях для Windows, Linux и Android. На этой странице показано, чем они отличаются и что выбрать.

Все клиенты подключаются к одному серверу вашей организации. Учётная запись, комнаты и материалы у них общие. В приложениях для Windows и Linux внутри окна открывается тот же интерфейс сервера, что и в браузере. Новые функции интерфейса приходят туда вместе с обновлением сервера.

## Что выбрать

| Ваша ситуация | Что подойдёт |
| --- | --- |
| Разовая встреча, ничего не хочется устанавливать | браузер Chrome или Edge |
| Peregovorka нужна каждый день, важны уведомления о сообщениях | приложение для Windows или Linux |
| Вы работаете с несколькими организациями | приложение для Windows или Linux |
| Вы проводите встречу, ведёте запись или эфир | браузер или приложение на компьютере |
| Нужно подключиться с телефона на ходу | приложение для Android |
| Вы гость и у вас есть ссылка | браузер, установка не нужна |
| Вы зритель трансляции | браузер, установка не нужна |
| iPhone, iPad или Mac | браузер: отдельного приложения нет, Safari не проверялся |

## Браузер

Основная проверка идёт в актуальных Chrome и Edge. Firefox и Safari не проверялись. На сайт нужно заходить по `https://`, иначе браузер не даёт доступ к микрофону, камере и экрану.

При переходе на другую вкладку Chrome и Edge на компьютере открывают плавающее окно встречи: [Плавающее окно встречи](Плавающее-окно-встречи). Внизу страницы есть ссылки на приложения для Windows, Linux и Android. Они не показываются внутри приложения для Windows и Linux.

## Приложения для Windows и Linux

Это одно и то же приложение. Оно добавляет к интерфейсу сервера:

- несколько организаций в одном окне, у каждой свой вход и свои уведомления;
- значок в трее, автозапуск и работу в фоне;
- системные уведомления: [Как настроить уведомления](Как-настроить-уведомления);
- сохранённый вход без хранения пароля;
- выбор устройств в **Настройки → Звук и видео**: [Как настроить устройства](Как-настроить-устройства).

Требования: Windows 10 или 11 (x64), Ubuntu 22.04 и 24.04, Debian 12 и 13 (x86_64 или ARM64). Нужен сервер Peregovorka 0.37.0 или новее.

Что проверено. Установка, запуск, обновление и удаление на Ubuntu и Debian (x86_64) проверены автоматически и на виртуальных машинах. Подтверждено испытаниями. На ARM64 звонки не проверялись. Сборка для Windows проверяется автоматически на Windows Server 2025. Ручная приёмка на Windows 10 и 11 не записана.

Установщики для Windows пока не подписаны сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.

## Приложение для Android

Это предварительный выпуск. Встреча работает в собственном экране приложения. Календарь, чаты, история и личный кабинет открываются страницами сервера.

Минимальная версия системы — Android 8.0. Требует дополнительного тестирования: автоматические проверки идут на эмуляторах Android 10, 14 и 16, а Android 8 и 9 не проверялись, настоящих телефонов в проверках мало.

Чего в приложении нет:

- уведомлений о сообщениях и встречах, есть только значок идущей конференции;
- доски, стенограммы в комнате, управления записью и эфиром, управления участниками;
- вложений в чате встречи;
- гостевого входа и просмотра трансляции в приложении: такие ссылки открываются в браузере телефона.
