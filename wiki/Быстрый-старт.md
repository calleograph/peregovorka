# Быстрый старт

**Что получится:** сервер установлен, вы вошли как администратор, создали комнату, провели пробную встречу и получили стенограмму. Время: 10–30 минут на установку плюс 15 минут на проверку.

Для кого: администратор сервера. Для установки в сети, где уже работают другие приложения, используйте [Установка на общий сервер](Установка-на-общий-сервер).

## Что нужно заранее

- Сервер с чистой Ubuntu 24.04, от 4 vCPU, 8 ГБ памяти, 30 ГБ свободного диска ([Системные требования](Системные-требования)).
- Права `sudo` и доступ сервера в интернет (GitHub, PyPI, npm, Docker Hub).
- Для проверки с двумя участниками — второй браузер или устройство.

## Шаги

1. Скачайте установщик на сервер.

   ```bash
   wget -O install.sh https://raw.githubusercontent.com/calleograph/peregovorka/main/install.sh
   chmod +x install.sh
   ```

   Ожидаемый результат: файл `install.sh` в текущем каталоге.

2. Запустите установку. Если сервер открывают не по основному IP, добавьте `--host имя-или-IP`.

   ```bash
   sudo ./install.sh
   ```

   Установщик спросит один раз «Продолжить?». Он ставит недостающие программы (без `apt upgrade`), создаёт `.env` со случайными секретами, скачивает проект в `/opt/peregovorka`, модель распознавания речи и локальную языковую модель Qwen3 1.7B, собирает образы, запускает сервисы и выполняет полную проверку. Эта операция занимает 10–30 минут.

   Ожидаемый результат: сообщение **«УСТАНОВКА ЗАВЕРШЕНА»** с адресом, логином `admin` и первичным паролем. Пароль показывается один раз, только в терминале.

   > Если установка прервалась, запустите `sudo ./install.sh` ещё раз: готовые этапы пропускаются. Если проверка нашла ошибку, пароль не показывается и установка не считается завершённой.

3. Откройте адрес из блока «ПЕРВИЧНЫЙ ВХОД» в браузере. Сертификат HTTPS по умолчанию самоподписанный, браузер покажет предупреждение: подтвердите переход. Для рабочей эксплуатации замените сертификат ([Как настроить reverse proxy и HTTPS](Как-настроить-reverse-proxy-и-HTTPS)).

4. Войдите как `admin` с первичным паролем и задайте новый: не короче 12 символов, не менее двух видов символов, без имени пользователя.

   Ожидаемый результат: открывается мастер первоначальной настройки.

5. Закройте мастер кнопкой «Закрыть и не показывать снова» (подключение к каталогу и почте вы настроите позже) и откройте **Администрирование → Обзор → Состояние системы**.

   Ожидаемый результат: PostgreSQL, Redis, LiveKit и ASR зелёные. ASR становится зелёным через 1–2 минуты после запуска. Active Directory показан как «не подключён» без ошибки.

6. Создайте комнату: **Администрирование → Комнаты и пользователи → Комнаты и доступ → Создать комнату**. Укажите название и идентификатор (латиница, цифры, `-`, `_`).

7. Включите гостевой доступ для пробной встречи: в комнате откройте «Настройки комнаты → Доступ и гости» и включите гостевой вход. Затем на главной странице у карточки комнаты нажмите «⋯» и выберите «Скопировать гостевую ссылку».

8. Войдите в комнату как `admin`, разрешите браузеру микрофон. Откройте гостевую ссылку во втором браузере и тоже войдите.

   Ожидаемый результат: во втором браузере виден первый участник.

9. Скажите несколько фраз. 

   Ожидаемый результат: в правой панели «Транскрипция» появляются реплики с именами участников.

10. Завершите встречу и откройте **История** → встречу → «Сформировать» протокол.

    Ожидаемый результат: протокол с решениями и поручениями (локальной моделью на процессоре формируется несколько минут).

## Проверка успешной установки

```bash
cd /opt/peregovorka
sudo ./scripts/smoke-test.sh
```

Ожидаемый результат: итоговая строка `Smoke test: PASS`. При ошибках смотрите [Диагностика](Диагностика).

## Потеряли пароль администратора

```bash
sudo /opt/peregovorka/scripts/admin-reset.sh
```

Скрипт выдаёт новый случайный пароль, завершает старые сеансы и пишет событие в аудит.

## Типичные ошибки

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Установщик остановился на этапе `models` | модель распознавания не скачалась (недоступен адрес) | запустить повторно или подготовить модель из каталога: [Установка на чистый сервер](Установка-на-чистый-сервер) |
| «Недопустимый Origin» при входе | страницу открыли не по адресу из `APP_PUBLIC_URL` | открыть приложение по основному адресу ([Диагностика](Диагностика)) |
| Нет микрофона в браузере | страница открыта не по HTTPS | использовать HTTPS-адрес |
| Реплик нет | ASR ещё не готов или нет модели | [Диагностика](Диагностика) |
