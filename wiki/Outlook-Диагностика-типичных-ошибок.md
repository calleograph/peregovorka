# Диагностика типичных ошибок Outlook и Exchange

*Для кого: администратор Peregovorka и поддержка.*

## Зачем это нужно

Статья помогает найти этап, на котором произошёл сбой: сертификат, манифест, панель, вход, сверка или календарь.

> На настоящем сервере Exchange и в настоящем Outlook интеграция не проверялась. Тексты ошибок взяты из кода. Причины для Exchange описаны по документации и подставным ответам. Настоящий сервер может вести себя иначе, поэтому опирайтесь на журнал.

## Что потребуется

- Права администратора Peregovorka.
- Доступ к компьютеру сотрудника или к его браузеру.
- Для сценариев: PowerShell, для части про Exchange Exchange Management Shell.

## Где найти

| Средство | Где | Что показывает |
| --- | --- | --- |
| Проверки | **Администрирование → Интеграции → Microsoft Outlook → Состояние и проверки** | готовность сервера |
| Журнал надстройки | там же, **Журнал надстройки и сверки** | запуск панели, ошибки, итоги сверки |
| Таблица встреч | там же, **Созданные конференции** | какая встреча отслеживается |
| Проверка с компьютера | `https://meet.example.org/outlook` → **Проверить с этого компьютера** | что видит именно этот компьютер |
| Сценарий | `Test-OutlookAddin.ps1` на рабочей станции | адреса манифеста, сертификат, состояние в Exchange |
| Панель | блок **Подробности для администратора** | этап и код ошибки |
| Полный журнал | **Хранение и журналы → Журнал событий**, категория `outlook` | все события интеграции |

## Как это сделать

1. Нажмите **Проверить заново** в блоке **Состояние и проверки**. Исправьте строки с крестиком.
2. Откройте `/outlook` на компьютере сотрудника и нажмите **Проверить с этого компьютера**.
3. Посмотрите **Журнал надстройки и сверки**. Найдите, дошла ли панель до сервера.
4. Для сверки найдите встречу в **Созданные конференции**.
5. Запишите текст ошибки, время и строки журнала.

Галочка означает успех, крестик ошибку, точка сведения или случай, который нужно проверить вручную.

## Строки проверок

| Строка | Что значит сбой | Что сделать |
| --- | --- | --- |
| **Интеграция** | интеграция выключена, манифест не выдаётся, ссылки `/m/…` не работают | включите её |
| **Публичный адрес** | адрес пуст или не HTTPS | задайте HTTPS-адрес |
| **Где завершается HTTPS** | «Требуется уточнение» | выберите схему вручную |
| **Сертификат HTTPS** | сертификат не прошёл проверку | см. таблицу ниже |
| **Внешняя проверка с сервера недоступна** | сервер не видит свой публичный адрес. Это не ошибка надстройки | проверьте с рабочей станции |
| **API внутри приложения** | приложение не отвечает | проверьте службу backend |
| **API через web-контейнер** | сбой маршрута внутри Docker | проверьте контейнер web |
| **API надстройки (публичный адрес)** | 403: WAF или прокси. 404: нет маршрута или интеграция выключена. 502–504: приложение за прокси не отвечает | проверьте правила для `/api/v1/outlook/` |
| **Файлы надстройки** | страницы недоступны | проверьте прокси, путь `/outlook/` |
| **Библиотека Microsoft Office.js** | нет копии или нужна пересборка | `scripts/update.sh --force-build` с доступом к CDN Microsoft |
| **Манифест** | манифест не разбирается | сообщите разработчикам |
| **Серверная сверка календаря** | есть встречи с ошибками | см. раздел о сверке |

Строка **Доступность клиентам** всегда требует проверки из браузера клиента. Сервер не может доказать, что адрес открывается у сотрудника.

## Сертификат

| Что показано | Причина | Где исправлять |
| --- | --- | --- |
| неполная цепочка | устройство не отдаёт промежуточный сертификат | на прокси, WAF или балансировщике. Можно скачать `fullchain.pem` |
| сервер не доверяет цепочке | внутренний центр сертификации | разверните корень на рабочих станциях. Для проверок с сервера положите его в `<DATA_ROOT>/ca/outlook-ca.pem` |
| самоподписанный | сертификату никто не доверяет | замените сертификат |
| имя отсутствует в сертификате | адрес не указан в поле SAN | выпустите новый сертификат |
| просрочен | истёк срок | выпустите новый сертификат |
| перенаправление при загрузке манифеста | прокси отвечает кодом 3xx | уберите перенаправление |

Подробнее: [Решение проблем: HTTPS и прокси](Решение-проблем-HTTPS-и-прокси).

## Надстройка

| Симптом | Вероятная причина | Что сделать |
| --- | --- | --- |
| Кнопки нет | манифест не дошёл или открыто окно письма, а не встречи | подождите, перезапустите Outlook, запустите `Test-OutlookAddin.ps1` |
| «Ошибка надстройки» в классическом Outlook | Office не запустил страницу | откройте журнал, см. строки ниже |
| «Ошибка настройки» в Outlook в браузере | не подтверждено доверие к домену или библиотека не запустилась | при вопросе нажмите **ОК** и откройте панель заново. После отказа очистите данные сайта Peregovorka |
| **Office.js не загрузился** | нет файла библиотеки или закрыт CDN | проверьте строку **Библиотека Microsoft Office.js** и источник в журнале |
| **Outlook не ответил** | Office не выполнил запрос вовремя | закройте и откройте окно встречи |
| **Устаревший Outlook** | встроенный браузер слишком старый | обновите Outlook или используйте версию в браузере |
| Код подтверждения в старом Outlook не вводится | окно входа не работает в IE 11 | используйте Outlook в браузере или учётную запись без дополнительного шага |
| **Окно входа не открылось** | заблокировано всплывающее окно | разрешите окна для Outlook |
| **Нет связи с сервером** | сеть или сертификат | проверьте `/outlook` с этого компьютера |
| **Нет прав** | сотрудник не в разрешённых группах | проверьте **Кому разрешено создавать конференции** |
| **Слишком часто** | больше 30 запросов в минуту | подождите минуту |
| «У вас уже N запланированных конференций» | достигнут предел | закройте ненужные или поднимите предел |
| **Ссылка не вставлена** | Outlook отказал в изменении | **Вставить ссылку ещё раз** |

## Строки журнала надстройки

| Строка | Что значит |
| --- | --- |
| **панель открыта (среда клиента)** | страница загрузилась, в сообщении режим IE и наличие библиотеки |
| **панель запущена Office** | Office запустил панель |
| **Office не запустил панель (причина в сообщении)** | панель не дождалась Office, причина и источник библиотеки в тексте |
| **панель не запустилась** | ошибка при запуске |
| **конференция добавлена** | операция прошла |
| **ошибка надстройки** | ошибка, которую видел пользователь. В скобках этап и код |
| **вход в панели не выполнен** | неудачный вход |
| **кнопка старого манифеста (обновите манифест)** | установлен манифест до версии 0.30 |

Если в журнале нет ни одной строки, Outlook не дошёл до сервера. Проверьте сертификат, адрес и установку манифеста.

Источник библиотеки в сообщении: `local` с сервера, `cdn` с CDN, `local:cdn_fallback` локальных файлов нет.

## Сверка

| Симптом или текст | Причина | Что сделать |
| --- | --- | --- |
| **не отслеживается** | нет идентификатора события | откройте сохранённую встречу и нажмите кнопку. Если не помогает, клиент не передаёт идентификатор: [ограничение](Outlook-Синхронизация-и-повторяющиеся-встречи#ограничение-надстройки-на-локальном-exchange) |
| «Сервер … не предлагает способ …» | неверный способ входа | **Определить способы входа** |
| «Сервер … отклонил учётную запись» | логин, пароль, блокировка | проверьте запись. На другой сервер запрос с тем же паролем не повторяется, чтобы не заблокировать её |
| «Вход выполнен, но прав на календарь организатора нет» | нет роли или права | выдайте `ApplicationImpersonation` или «Рецензент» |
| «EWS на … запретил доступ (HTTP 403)» | права на EWS, брандмауэр или WAF | проверьте доступ к EWS |
| «… вернул не SOAP-ответ» | адрес ведёт не на EWS | проверьте путь и балансировщик |
| «Exchange недоступен: …» | нет связи | проверьте DNS, порт 443 и сертификат |
| «EWS ответил ошибкой …» | код Exchange | найдите код в документации Microsoft |
| «Идентификатор события не принят EWS…» | событие пересохранено | нажмите кнопку в Outlook ещё раз |
| «Перенесённые и отменённые занятия серии не прочитаны…» | часть данных не прочитана, событие сверено | проверьте права Graph |

Ошибка связи или прав комнату не отменяет.

## Календарь

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| «Раздел «Календарь» не включён администратором» | выключена настройка | включите раздел |
| «Администратор не настроил подключение к Exchange…» | **Способ сверки** выключен | настройте сверку |
| «Календарь доступен только сотрудникам из выбранных администратором групп» | сотрудник вне групп | проверьте **Группы, которым доступен календарь** |
| «В вашем профиле нет адреса почты…» | адреса нет в каталоге | заполните адрес |
| «Не удалось получить доступ к вашему календарю: …» | Exchange отказал при подключении | разберите текст после двоеточия |
| **Недостаточно прав для чтения календаря** | у сервера нет права на ящик | выдайте права |
| **Нет соединения с Exchange: показаны сохранённые события…** | Exchange недоступен | проверьте сеть, нажмите **Повторить** |
| **Требуется повторное подключение календаря** | согласие снято или адрес в каталоге изменился | нажмите **Подключить заново** |
| «… не включено администратором» | запись выключена | включите **Создавать и менять встречи из Peregovorka** |
| «Создавать и менять встречи сотрудников можно только в режиме «Имперсонация»…» | выбран делегированный доступ | выдайте имперсонацию |
| «Выберите, что изменить: только это занятие или всю серию.» | не указан выбор | выберите вариант |
| «Изменять и отменять событие может только его организатор…» | сотрудник приглашён | измените у организатора |
| Вы организатор, но календарь считает вас приглашённым | адрес организатора из EWS мог прийти не в виде почтового адреса. Причина предположительная, не проверена | сообщите с журналом, измените встречу в Outlook |
| «Событие в календаре уже изменено…» | правка в Outlook | обновите календарь и повторите |
| «Слишком много обращений к календарю» | предел запросов | подождите минуту |

## Что собрать для обращения

- Текст ошибки и время.
- Строки **Журнал надстройки и сверки**.
- Результат **Состояние и проверки**.
- Вывод `Test-OutlookAddin.ps1` с рабочей станции.
- Клиент и версию Outlook, версию Exchange.

Не присылайте пароли и гостевые ссылки. Общий порядок: [Диагностика](Диагностика).
