# Пределы вложений

*Для кого: сотрудник, руководитель комнаты, администратор.*

Справочник: какие файлы можно отправить в чат, какого размера, где они хранятся и как долго. Правила общие для чата встречи и корпоративных чатов.

## Главное

| Что ограничено | Значение по умолчанию | Что может изменить администратор |
| --- | --- | --- |
| Размер одного файла | 3 МБ | только уменьшить: от 1 до 3 МБ |
| Файлов в одном сообщении | 5 | от 1 до 20 |
| Типы файлов | список ниже | только сократить список |
| Вложения в целом | включены | выключить |

Предел 3 МБ задан в программе. Значение больше 3 в настройках сервер приводит к 3.

В чате встречи есть ещё один предел: не больше 10 загрузок в минуту от одного участника.

## Какие файлы разрешены

| Группа | Расширения |
| --- | --- |
| Изображения | `png`, `jpg`, `jpeg`, `gif`, `webp` |
| Документы | `pdf`, `txt`, `md`, `csv` |
| Word, Excel, PowerPoint | `docx`, `xlsx`, `pptx` |
| OpenDocument | `odt`, `ods`, `odp` |
| Схемы | `drawio` |

Видео, звук и архивы в чатах не принимаются. Такие файлы передавайте почтой или через файлообменник организации.

Исполняемые и активные типы запрещены всегда, в том числе `exe`, `bat`, `js`, `html`, `svg`. Добавить их в список разрешённых нельзя.

## Как проверяется файл

Проверка идёт в браузере и ещё раз на сервере.

- Сравнивается расширение со списком разрешённых.
- Тип изображений, PDF и офисных файлов проверяется по содержимому. Переименованный файл не пройдёт.
- Исполняемый файл отклоняется, какое бы расширение у него ни было.
- Пустой файл отклоняется.
- Длина и контрольная сумма сверяются, чтобы убедиться, что файл дошёл целиком.

Показать файл прямо в сообщении можно только для изображений, подтверждённых по содержимому. Остальные файлы только скачиваются.

## Где хранятся вложения

В базе данных лежат только сведения о файле. Сам файл хранится:

| Настройка | Где лежит файл |
| --- | --- |
| Хранилище выбрано | подпапка `Chat/files` выбранного файлового хранилища, в том числе сетевого (SMB) |
| Хранилище не выбрано | локальный диск сервера приложения |

Если хранилище недоступно, отправитель увидит ошибку, а событие попадёт в журнал.

## Сколько хранятся вложения

| Что | Срок |
| --- | --- |
| Загружен, но не отправлен | удаляется примерно через 2 часа |
| Вложение чата встречи | удаляется вместе с перепиской встречи по сроку хранения текста |
| Вложение корпоративного чата | удаляется вместе с сообщением по сроку хранения переписки |
| Удалённое сообщение корпоративного чата | вложения удаляются вместе с ним |

Срок для встреч описан в статье [Сроки хранения материалов](Сроки-хранения-материалов). Срок корпоративной переписки задаётся в разделе **Корпоративные чаты**, значение 0 означает хранение без срока.

## Как изменить пределы

Нужны права администратора.

1. Откройте **Администрирование → Хранение и журналы → Хранилище вложений чата**.
2. Измените поля:
   - **Разрешить вложения в чате**;
   - **Где хранить**;
   - **Максимальный размер одного файла**;
   - **Файлов в одном сообщении**;
   - **Разрешённые типы файлов (расширения через запятую)**.
3. Сохраните настройки.

Важно: подсказки формы на этой странице устарели. Поле размера допускает ввод до 100 и предлагает пример 25, а пример типов содержит `zip`. Сервер всё равно ограничит размер тремя мегабайтами и отбросит типы вне списка из этой статьи.

## Другие пределы размера

Это другие загрузки, правила выше к ним не относятся.

| Что загружается | Предел |
| --- | --- |
| Вложения письма с материалами встречи | 10 МБ по умолчанию, от 1 до 50 МБ. Если документы больше, в письме будет ссылка на встречу |
| Логотипы и значок вкладки | 2 МБ, см. [Как настроить оформление сайта](Как-настроить-оформление-сайта) |
| Изображение группы чата | PNG, JPEG или WebP, до 600 КБ |
| Значок комнаты | исходный файл PNG, JPG или WEBP до 12 МБ, браузер уменьшает его перед отправкой |
