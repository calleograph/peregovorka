# Собственная трансляция по HLS

*Для кого: владелец комнаты, администратор.*

**Что получится:** зрители смотрят эфир со страницы Peregovorka без внешних сервисов.

## Как смотрят

Страница `/live/<код>`:

- **до начала** — название, дата и время, обратный отсчёт, статус ожидания; страница обновляется сама;
- **во время эфира** — плеер с кнопками «пауза», громкость, «К прямому эфиру» (если зритель отстал), полный экран; метка «ЭФИР»;
- **после** — «Эфир завершён».

Воспроизведение: в **Safari, на iPhone и iPad** — встроенный HLS; в остальных браузерах — библиотека hls.js. Если браузер не разрешил звук, плеер стартует без звука и показывает кнопку «Включить звук». Страница не создаёт WebRTC-соединений.

## Три способа просмотра

Сервер сам выбирает способ для каждого зрителя. Настройки: **Администрирование → Трансляции**.

| Способ | Задержка | Для кого |
| --- | --- | --- |
| Низкая задержка (LL-HLS) | ≈ 3 с | зрители с этого сервера, в пределах настройки «Зрителей с низкой задержкой, не больше» (300 по умолчанию) |
| Обычный HLS | ≈ 7,5 с | Safari и iPhone, узлы CDN, зрители сверх предела |
| WebRTC | меньше секунды | выключен по умолчанию; включается настройкой «Зрителей по WebRTC, не больше»; зрителю нужен доступ к серверу звонков |

Первые 10 секунд эфира все смотрят обычный HLS: поток с низкой задержкой ещё собирается. Плеер переходит на него сам. Если служба низкой задержки остановилась или WebRTC не соединился, плеер возвращается на обычный HLS. Запись и внешние площадки от этого не зависят.

## Что нужно серверу

- В compose у контейнеров Egress, backend и web общий каталог `${DATA_ROOT}/live` (`install.sh` создаёт его, права 10001). Egress пишет сегменты, backend создаёт ссылки доступа и убирает старые файлы, web (nginx) читает.
- Секрет подписи backend записывает в `${DATA_ROOT}/live/nginx/secret.conf`; web сверяет его раз в 5 секунд и применяет сам, с проверкой `nginx -t`. После смены `APP_MASTER_KEY` перезапускать web не нужно.
- Диск: сегменты и MP4 пишутся одновременно (≈ 2,4 ГБ в час в 720p во время эфира); старые сегменты идущего эфира удаляются (по умолчанию старше 15 минут), каталог эфира — через 30 минут после конца.

## Ограничения

Дорожка одна, автоподстройки качества под канал зрителя нет. Задержка и нужная скорость канала — в [Массовые трансляции](Массовые-трансляции). Раздача с одного сервера рассчитана на небольшую аудиторию: администратор увидит предупреждение при росте числа зрителей. Для больших аудиторий — CDN.
