# Собственная трансляция по HLS

*Для кого: владелец комнаты, администратор.*

**Что получится:** зрители смотрят эфир со страницы Peregovorka без внешних сервисов.

## Как смотрят

Страница `/live/<код>`:

- **до начала** — название, дата и время, обратный отсчёт, статус ожидания; страница обновляется сама;
- **во время эфира** — плеер с кнопками «пауза», громкость, «К прямому эфиру» (если зритель отстал), полный экран; метка «ЭФИР»;
- **после** — «Эфир завершён».

Воспроизведение: в **Safari, на iPhone и iPad** — встроенный HLS; в остальных браузерах — библиотека hls.js. Если браузер не разрешил звук, плеер стартует без звука и показывает кнопку «Включить звук». Страница не создаёт WebRTC-соединений.

## Что нужно серверу

- В compose у контейнеров Egress, backend и web общий каталог `${DATA_ROOT}/live` (`install.sh` создаёт его, права 10001). Egress пишет сегменты, backend создаёт ссылки доступа и убирает старые файлы, web (nginx) читает.
- Секрет подписи backend записывает в `${DATA_ROOT}/live/nginx/secret.conf`; web подключает его при запуске (`depends_on: backend`). При смене `APP_MASTER_KEY` перезапустите web: `docker compose restart web`.
- Диск: сегменты и MP4 пишутся одновременно (≈ 2,4 ГБ в час в 720p во время эфира); старые сегменты идущего эфира удаляются (по умолчанию старше 15 минут), каталог эфира — через 30 минут после конца.

## Ограничения

Дорожка одна, автоподстройки качества под канал зрителя нет. Задержка — несколько секунд. Раздача с одного сервера рассчитана на небольшую аудиторию: администратор увидит предупреждение при росте числа зрителей. Для больших аудиторий — CDN.
