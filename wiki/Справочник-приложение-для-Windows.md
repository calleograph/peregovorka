# Справочник: приложение для Windows

*Для кого: администратор Windows и служба поддержки.*

Сведения относятся к клиенту 1.5.1. Нужен сервер Peregovorka 0.37.0 или новее. Заявленная система: Windows 10 или 11, x64. Сборка и тихая установка проверяются в GitHub Actions на Windows Server 2025. Записи о ручной приёмке на настоящих Windows 10 и 11 нет: статус «проверено в ограниченном сценарии». Пошаговое развёртывание: [Как развернуть приложение Windows в организации](Как-развернуть-приложение-Windows-в-организации).

## Свойства MSI и политики

Все значения необязательны. Значения MSI записываются в `HKLM\SOFTWARE\Policies\Peregovorka` и запоминаются в `HKLM\SOFTWARE\Peregovorka\Desktop\Install` для обновлений. Те же значения задаются групповой политикой (шаблон ADMX).

| Свойство MSI | Тип | Значения | Назначение |
| --- | --- | --- | --- |
| `SERVERS` | строка | `Название\|https://адрес`, несколько через `;`; только HTTPS | преднастроенные организации; пользователь их не удалит |
| `ALLOWADDSERVERS` | флаг | `0` — запретить | подключение других серверов |
| `ALLOWEDDOMAINS` | список | домены через `;`, `*.` — только поддомены | разрешённые домены |
| `AUTOSTART` | выбор | `off`, `tray`, `window` | автозапуск; для `tray` и `window` MSI прописывает запуск для всех пользователей |
| `CLOSEACTION` | выбор | `tray`, `quit`, `ask` | действие кнопки «Закрыть» |
| `UPDATEMODE` | выбор | `auto`, `notify`, `off` | режим обновлений (при установке из MSI приложение само не обновляется) |
| `UPDATEURL` | строка | адрес `update.json` | корпоративное зеркало манифеста обновлений для установок EXE |
| `NOTIFICATIONS` | флаг | `0` — выключить | уведомления Windows |
| `HIDENOTIFICATIONCONTENT` | флаг | `1` | в уведомлении только «Новое сообщение» |
| `PROXYMODE` | выбор | `system`, `direct`, `manual`, `pac` | режим прокси |
| `PROXYSERVER`, `PROXYBYPASS` | строка | `proxy.example.org:3128`, `<local>;*.example.org` | для `manual` |
| `PROXYPAC` | строка | `https://proxy.example.org/proxy.pac` | для `pac` |

Только в политиках: `AllowDevTools` (инструменты разработчика, для диагностики).

Политики в шаблоне ADMX называются `Servers`, `AllowAddServers`, `AllowedDomains`, `Autostart`, `CloseAction`, `UpdateMode`, `UpdateUrl`, `Notifications`, `HideNotificationContent`, `ProxyMode`, `ProxyServer`, `ProxyBypass`, `ProxyPac`, `AllowDevTools`. Каждая есть в конфигурации компьютера и пользователя. Порядок: политика компьютера (HKLM), политика пользователя (HKCU), настройка пользователя. Поле, заданное политикой, пользователь видит недоступным с пометкой «Задано администратором».

## Данные на компьютере

Каталог `%APPDATA%\Peregovorka`:

| Что | Назначение |
| --- | --- |
| `settings.json` | настройки (в том числе `media`: названия выбранных устройств, шумоподавление, эхо, автоусиление) |
| `orgs.json` | подключения |
| `window.json` | положение окна |
| `trust\*.bin` | токены устройства (защита DPAPI) |
| `logs\main.log` | журнал, 5 файлов по 1 МБ, ротация |
| `logs\chromium-audio.log` | журнал звука для отчёта «Диагностика» |
| `Partitions\org-*` | cookie и кэш каждой организации (cookie зашифрованы DPAPI) |

Удаление организации в приложении стирает её раздел и токен.

## Звук и видео

Вкладки **Настройки**: **Общие**, **Уведомления**, **Звук и видео**, **Организации**, **Сеть**, **Обновления**, **Диагностика**, **О программе**.

Вкладка **Звук и видео**: выбор микрофона, устройства воспроизведения и камеры по названию, проверка микрофона (шкала уровня), звука и камеры, шумоподавление, эхоподавление, автоусиление, уведомления о подключении и отключении гарнитуры, диагностика отказа микрофона. Пошагово — [Как настроить звук и видео в приложении для Windows](Как-настроить-звук-и-видео-в-приложении-Windows).

| Что | Значение |
| --- | --- |
| Доступ к микрофону и камере | только у окна самого приложения (`app://shell`); страницы серверов — к устройствам своей организации, как раньше |
| Мост для страницы организации | `peregovorkaDesktop.media.get()` (значения по умолчанию, только чтение) и `openSoundSettings(вид)`; `api` моста остаётся `1` |
| Системные окна Windows | `mic-classic` — `rundll32.exe shell32.dll,Control_RunDLL mmsys.cpl,,1` (затем `ms-settings:sound` при неудаче), `sound`, `privacy-mic`, `privacy-cam` (`ms-settings:…`); других значений нет, параметров от страницы приложение не принимает |
| Применение на сервере | серверы 0.40 и новее; старые серверы выбор не используют |

## Командная строка

| Параметр | Что делает |
| --- | --- |
| `Peregovorka.exe --diagnostics=<файл.json>` | записывает отчёт и завершается; приложение должно быть закрыто |
| `Peregovorka.exe --debug-log` | подробный журнал главного процесса в терминал |
| `Peregovorka-Setup-X.Y.Z.exe /S` | тихая установка |

## Ссылки

Ссылки вида `peregovorka://` открываются в приложении. Обычная ссылка на встречу открывается в браузере, а на странице встречи есть кнопка «Открыть в приложении».

## Сообщения о подключении к серверу

| Сообщение | Код | Что делать |
| --- | --- | --- |
| Сервер не найден | `ERR_NAME_NOT_RESOLVED` | проверить адрес, VPN, DNS |
| Нет подключения к сети | `ERR_INTERNET_DISCONNECTED`, `ERR_NETWORK_CHANGED` | проверить интернет или корпоративную сеть |
| Сервер недоступен | `ERR_CONNECTION_REFUSED`, `_RESET`, `_CLOSED`, `ERR_ADDRESS_UNREACHABLE`, `ERR_EMPTY_RESPONSE` | проверить, работает ли сервер и нет ли блокировки |
| Сервер не отвечает | `ERR_TIMED_OUT` | сеть, VPN, прокси |
| Сертификат не доверен | `ERR_CERT_AUTHORITY_INVALID` | установить корневой сертификат организации |
| Сертификат выдан на другое имя | `ERR_CERT_COMMON_NAME_INVALID` | ввести имя вместо IP |
| Срок действия сертификата истёк | `ERR_CERT_DATE_INVALID` | проверить дату компьютера, затем сертификат сервера |
| Сертификат отозван | `ERR_CERT_REVOKED` | подключение небезопасно, заменить сертификат сервера |
| Ошибка защищённого соединения | прочие `ERR_CERT_*`, `ERR_SSL_*` | сообщить код администратору |
| Ошибка прокси-сервера | `ERR_PROXY_*`, `ERR_TUNNEL_CONNECTION_FAILED` | **Настройки → Сеть** |
| Это не сервер Peregovorka, версия сервера слишком старая | `not_peregovorka`, `server_too_old` | неверный адрес или сервер старше 0.37.0 |
| Не поддерживается требуемая версия API | `server_too_new`, `client_too_old` | обновить приложение |

После временного сбоя приложение переподключается само с нарастающей паузой от 2 секунд до 5 минут.

## Сохранённый вход

| Ситуация | Причина |
| --- | --- |
| Пароль просят при каждом запуске | на сервере «Приложение Windows помнит вход» = 0 дней (по умолчанию 30, допустимо 0–90) или срок вышел; в отчёте `saved_sign_in: false` |
| `trust_storage: unavailable` | защищённое хранилище Windows (DPAPI) недоступно, редкий случай |
| «Сохранённый вход больше не действует» | выход, смена пароля, отключение учётной записи, завершение сеанса |
| «Достигнут предел сеансов» | приложение занимает один сеанс на организацию; на странице входа можно завершить сеанс |

## Подпись и обновления

| Режим CI | Результат |
| --- | --- |
| секретов нет | неподписанная сборка, выпуск «предварительный» |
| самоподписанный сертификат | тестовая подпись, выпуск «предварительный», рядом `Peregovorka-publisher.cer` |
| сертификат удостоверяющего центра | доверенная сборка, обычный выпуск |

Ключ обновлений — отдельный ключ Ed25519, не сертификат подписи кода. Он подписывает манифест `update.json` новых версий. Без ключа обновлений приложение не устанавливает обновления само и предлагает «Скачать установщик вручную». Сообщения: «Управляется администратором» (MSI), «Подпись обновления не прошла проверку — обновление отклонено» (подмена или повреждение). Подробности: `docs/DESKTOP_SIGNING.md` в репозитории.

**Состояние.** Ключ обновлений постоянный, поэтому с 1.4.3 выпуски обновляются из приложения. Сертификата подписи кода от удостоверяющего центра нет: публичные установщики не подписаны, Windows показывает SmartScreen и «Неизвестный издатель». Организация может подписать установщики своим сертификатом: **Администрирование → Windows-клиент → Подпись и корпоративные сборки**, вкладки **Сертификаты**, **Корпоративные установщики**, **Обновления**, **Диагностика подписи**, **Инструкции**. Закрытый ключ остаётся на отдельном доверенном компьютере Windows, подписывающем узле.

## Диагностика

Кнопка **Сохранить отчёт** на вкладке **Настройки → Диагностика**. В отчёте: версии клиента, Electron, Chromium и Windows, мониторы и масштаб, вид установки, заданные политики, для каждой организации адрес, состояние, код ошибки, версия сервера, сохранён ли вход, состояние канала событий, разрешения камеры и микрофона, число устройств, память процессов, коды ошибок звука Windows, установленные защитные программы, последние строки журнала без секретов.
