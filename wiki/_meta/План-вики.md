# План вики Peregovorka

Версия продукта: сервер 0.39.4, приложение для Windows 1.2.0. Изучено: ветка `main`, коммит `fde4bac266a58c835128128b7dcdea3d7278257e` (2026-10-25). Режим: **создание** (репозиторий вики `calleograph/peregovorka.wiki.git` не найден при проверке `git ls-remote`; публикация не выполнялась, параметр публикации не задан — значит «нет»).

Тип продукта: веб-сервис (Docker Compose) с настольным клиентом (Electron) и необязательными интеграциями (Outlook, API). Из-за этого в набор добавлены страницы про интеграции, публичный API, приложение для Windows и эксплуатацию.
