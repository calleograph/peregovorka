# Отчёт о пробелах и ограничениях подготовки вики

Дата: 2026-10-25. Версия продукта: сервер 0.39.4, приложение для Windows 1.2.0. Коммит: `fde4bac266a58c835128128b7dcdea3d7278257e`, ветка `main`.

## Режим и публикация

- Режим: **создание**. Репозиторий вики `calleograph/peregovorka.wiki.git` не существует (проверено `git ls-remote`: «Repository not found»).
- **Опубликовано 2026-10-26** по прямому указанию владельца (`scripts/publish-wiki.sh --yes`, обычная отправка без принудительной перезаписи). В браузере открыты главная, «Как устроена Peregovorka» и «Как провести встречу»; остальные 49 страниц на отображение не открывались.
- Независимый проверяющий агент не использовался: проверку выполнил автор текста; поэтому в матрице покрытия состояние страниц — «проверена автором», а не «проверена независимо».

## Что не запускалось

Ни одна команда установки, обновления, резервного копирования, SIP, Outlook, API и приложения для Windows при подготовке вики не выполнялась; в страницах они помечены «не запускалась» или указано в шапке. Запускалось: `python3 scripts/check_wiki.py`, `scripts/check_private_data.py`, сбор тестов ASR (`pytest --collect-only`), полные тесты backend и shell (при подготовке выпусков 0.39.x), `vitest`.

## Интеграции не выше уровня 3

| Интеграция | Уровень | Чем проверена |
| --- | --- | --- |
| Active Directory | 2–3 | подставной каталог; записи о проверке на настоящем AD нет |
| SMTP / Exchange | 2 | подставной SMTP-сервер |
| SMB | 2 | подставной клиент и локальный профиль |
| SIP / АТС | 2 | подставной API LiveKit |
| Outlook | 3 | поддельный Office.js |
| Bitrix24 | 2 | подставной портал |
| Внешние LLM и обезличивание | 2 | подставные HTTP-ответы |
| Приложение для Windows | 3 | Electron под Linux; сборка и тихая установка в CI на Windows; ручной проверки на Windows нет |
| Обновление | 3, частично 4 | подставной Docker; обновление из браузера на сервере владельца (по снимку владельца) |

## Скриншоты

Сделаны два (из репозитория, `docs/img/`, стенд с вымышленными данными, актуальное оформление «Стекло»): «Переговорки» (Home) и «Комната» (Как провести встречу); оба в `wiki/images/` с подписью и текстом-заменой. **Не сделаны** (нужны кадры с актуальной версии на стенде):

1. Администрирование → Состояние системы.
2. Мастер первоначальной настройки.
3. Страница «Обновления и версии».
4. Приложение для Windows: боковая панель организаций и настройки (нужен запуск на Windows или Electron под Xvfb).
5. Окно «Сформировать протокол» и готовый протокол.

Макеты под видом интерфейса не создавались.

## Какие данные нужны от автора

1. Лицензия проекта.
2. Контакт и порядок для уязвимостей.
3. Какие интеграции (AD, SMTP, SMB, АТС, Outlook) проверялись на реальном сервере, с каким результатом.
4. Подтверждение, что порядок «перенос с данными» (дамп, `.env`, `DATA_ROOT`) корректен.
5. Решение о включении вики в процесс выпуска (добавлено в `docs/VERSIONING.md`).
