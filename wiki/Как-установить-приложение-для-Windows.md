# Как установить приложение для Windows

> Относится к приложению для Windows 1.2.0 и серверу 0.39.4 · проверено 2026-10-25 · уровень проверки: 3 (Electron под Linux на стенде) и сборка с тихой установкой в CI на Windows; **ручная проверка на настоящей Windows не выполнялась** · тип страницы: практическое руководство

Результат: приложение Peregovorka установлено, вы вошли в одну или несколько организаций. Для кого: сотрудник с компьютером Windows 10 или 11 (x64). Для массового развёртывания — [[Как развернуть приложение Windows в организации|Как-развернуть-приложение-Windows-в-организации]].

Выпуск 1.2.0 — предварительный: установщики не подписаны сертификатом издателя. Windows может показать окно SmartScreen.

## Что нужно заранее

- Адрес сервера вашей организации (тот же, что в браузере) и учётная запись.
- Сервер Peregovorka версии 0.37.0 или новее; оформление «Стекло» появляется на сервере 0.39.1 и новее.
- Корневой сертификат вашего внутреннего центра сертификации должен быть доверен в Windows (обычно это делает администратор групповой политикой).

## Шаги

1. Скачайте установщик со [страницы выпуска 1.2.0](https://github.com/calleograph/peregovorka/releases/tag/desktop-v1.2.0): `Peregovorka-Setup-1.2.0.exe`. Контрольные суммы лежат рядом, в файле `SHA256SUMS.txt`.

   ```powershell
   Get-FileHash .\Peregovorka-Setup-1.2.0.exe -Algorithm SHA256   # не запускалась
   ```

   Ожидаемый результат: значение совпадает с суммой из `SHA256SUMS.txt`.

2. Запустите `Peregovorka-Setup-1.2.0.exe`. Права администратора не нужны: программа ставится для вашей учётной записи. В установщике можно выбрать установку «для всех» — тогда Windows запросит права.

   Если Windows показала SmartScreen: «Подробнее» → «Выполнить в любом случае». Это нормально для неподписанного установщика.

3. После установки приложение запускается. Введите адрес сервера (можно вставить ссылку на встречу). Приложение проверит доступность сервера, защищённое соединение и версию, а при проблеме назовёт причину («Сертификат не доверен» и т. д.).

4. Войдите как в браузере: доменной учётной записью, со вторым фактором, если он включён.

   Ожидаемый результат: открывается интерфейс организации; слева — значки организаций.

Пароль приложение не хранит. После входа компьютер запоминается как доверенное устройство: после перезапуска приложения и Windows пароль не спрашивают. Срок задаёт администратор сервера. Вход сбрасывается, если вы вышли, сменили пароль, вашу учётную запись отключили или завершили сеанс в «Активных устройствах».

## Несколько организаций

Значки организаций слева. Нажмите значок, чтобы переключиться; **+** подключает ещё одну. У каждой организации свой вход, чаты, уведомления и непрочитанные. Встреча в одной организации не прерывается, пока вы работаете в другой. Переименовать, упорядочить, выйти и удалить подключение — **Настройки → Организации**.

## Трей и автозапуск

Кнопка «Закрыть» по умолчанию сворачивает приложение в трей. Левый щелчок по значку открывает окно, правый — меню (чаты, предстоящие встречи, организации, настройки, «Выйти из приложения»). Если вы во встрече, приложение спросит: продолжить встречу в фоне или покинуть её. Для новой установки автозапуск по умолчанию включён и стартует свёрнутым в трей; изменить: **Настройки → Общие**. Политика организации сильнее личных настроек.

## Уведомления

Новые сообщения, упоминания, скорое начало встречи, перенос и отмена встречи, готовый протокол. Нажатие открывает нужную организацию и переписку или встречу. **Настройки → Уведомления**: выключить, звук, скрыть текст сообщений, «Не беспокоить» (на час, на 4 часа или до выключения).

## Встречи и экран

Камера, микрофон, выбор устройств и шумоподавление — как в браузере. «Показать экран» открывает окно выбора: весь экран или отдельное окно. Звук компьютера доступен только при показе всего экрана (ограничение Windows). Во время показа поверх окон виден индикатор с кнопкой «Остановить».

## Обновление

Установка из `exe` обновляется приложением, если сборка подписана ключом обновлений издателя. Сборки 1.2.0 ключа обновлений не содержат: приложение предложит «Скачать установщик вручную». Установка из MSI обновляется администратором.

## Удаление

«Параметры Windows → Приложения → Peregovorka → Удалить». Установщик спросит, удалить ли настройки и сохранённые входы. Переписка и материалы на сервере не меняются.

## Типичные ошибки

| Сообщение | Что делать |
| --- | --- |
| «Сертификат не доверен» (`ERR_CERT_AUTHORITY_INVALID`) | установить корневой сертификат организации в «Доверенные корневые центры сертификации»; отключить проверку нельзя |
| «Сертификат выдан на другое имя» | ввести адрес по имени, а не по IP |
| «Сервер не найден» | проверить адрес, VPN, DNS |
| «Версия сервера слишком старая» | сообщить администратору: нужен сервер 0.37.0 или новее |
| Камера или микрофон запрещены | Параметры Windows → Конфиденциальность → разрешить классическим приложениям |

Больше причин — [[Справочник: приложение для Windows|Справочник-приложение-для-Windows]] и [[Диагностика]].
