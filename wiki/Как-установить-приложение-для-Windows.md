# Как установить приложение для Windows

*Для кого: сотрудник с компьютером на Windows 10 или 11 (x64). Администратору для массовой установки нужна статья [Как развернуть приложение Windows в организации](Как-развернуть-приложение-Windows-в-организации).*

## Зачем это нужно

Приложение открывает Peregovorka в отдельном окне. Оно добавляет уведомления Windows, значок в трее, несколько организаций и вход без повторного ввода пароля. Сравнение с браузером: [Веб-версия и приложения](Веб-версия-и-приложения).

## Когда пригодится

- Вы работаете в Peregovorka каждый день.
- Вы не хотите пропускать сообщения и начало встреч.
- Вы подключены к нескольким организациям.

## Что потребуется

- Windows 10 или 11, 64 бита.
- Адрес сервера организации (тот же, что в браузере) и учётная запись.
- Сервер Peregovorka 0.37.0 или новее.
- Доверие Windows к сертификату сервера. Для внутреннего центра сертификации его обычно настраивает администратор групповой политикой.

Права администратора компьютера не нужны.

## Где найти

Установщик можно скачать двумя способами:

- по ссылке **Приложение для Windows** внизу страницы вашего сервера Peregovorka;
- на [странице выпусков](https://github.com/calleograph/peregovorka/releases?q=desktop-v), файл `Peregovorka-Setup-<версия>.exe`.

## Как это сделать

1. Скачайте `Peregovorka-Setup-<версия>.exe`.
2. Проверьте файл, если этого требуют правила организации. Контрольная сумма лежит на странице выпуска в файле `SHA256SUMS.txt`.

   ```powershell
   Get-FileHash .\Peregovorka-Setup-<версия>.exe -Algorithm SHA256
   ```

   Результат: значение совпадает со строкой в `SHA256SUMS.txt`.

3. Запустите установщик. Программа ставится для вашей учётной записи. Если выбрать установку для всех пользователей, Windows запросит права администратора.

   Windows может показать окно SmartScreen, потому что установщик пока не подписан сертификатом издателя. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

4. Приложение запустится и покажет **Добро пожаловать в Peregovorka**. Нажмите **Добавить организацию**.
5. На экране **Шаг 1 из 2 · Сервер организации** заполните поля:
   - **Название организации (необязательно)**: как подписать подключение;
   - **Адрес сервера Peregovorka**: например, `https://meet.example.org`. Можно вставить ссылку на встречу.
6. Нажмите **Проверить подключение**.

   Результат: приложение проверяет доступность, защищённое соединение и версию сервера, затем пишет **Сервер доступен**.

7. Нажмите **Продолжить**.
8. Войдите на странице сервера, как в браузере: [Как войти в систему](Как-войти-в-систему).

## Что получится

Открывается интерфейс организации, слева видны значки организаций. Теперь проверьте устройства: откройте **Настройки → Звук и видео** и выполните [проверку](Как-настроить-звук-и-видео-в-приложении-Windows).

Пароль приложение не хранит. После входа компьютер запоминается как доверенное устройство, и после перезапуска пароль не спрашивается. Срок задаёт администратор сервера, по умолчанию 30 дней. Вход сбрасывается, если вы вышли, сменили пароль, вашу запись отключили или ваш сеанс завершили в **Активных устройствах**.

## Работа в приложении

**Несколько организаций.** Нажмите значок организации слева, чтобы переключиться, **+** добавляет ещё одну. У каждой организации свой вход, чаты и уведомления. Встреча в одной организации не прерывается, пока вы работаете в другой. Управление подключениями: **Настройки → Организации**.

**Трей и автозапуск.** Кнопка «Закрыть» по умолчанию сворачивает приложение в трей. Правый щелчок по значку открывает меню: **Открыть Peregovorka**, **Чаты**, **Предстоящие встречи**, **Настройки**, **Проверить обновления**, **Выйти из приложения**. Если вы во встрече, приложение спросит: **Свернуть — встреча продолжится** или **Покинуть встречу и свернуть**. Для новой установки автозапуск включён и стартует свёрнутым в трей. Изменить: **Настройки → Общие**.

**Уведомления.** См. [Как настроить уведомления](Как-настроить-уведомления).

**Показ экрана.** Откроется окно **Что показать участникам?**: выберите экран или окно и нажмите **Показать**. Отметка **Передавать звук компьютера** доступна только при показе всего экрана. Во время показа поверх окон виден индикатор с кнопкой **Остановить**.

**Обновление.** Откройте **Настройки → Обновления**. Приложение проверяет подпись описания версии и ставит обновление. Если не получается, используйте **Скачать установщик вручную**. Установку из MSI обновляет администратор.

**Удаление.** Откройте параметры Windows, раздел приложений, выберите Peregovorka и нажмите «Удалить». Установщик спросит, удалить ли настройки, подключённые организации и сохранённые входы. Переписка и материалы на серверах не меняются.

## Если не получается

| Сообщение | Почему | Что сделать |
| --- | --- | --- |
| **Сертификат не доверен** | Windows не доверяет центру, выдавшему сертификат | сообщите администратору: нужен корневой сертификат организации. Отключить проверку нельзя |
| **Сертификат выдан на другое имя** | адрес не совпадает с сертификатом | введите адрес по имени, а не по IP |
| **Срок действия сертификата истёк** | сертификат просрочен или неверна дата | проверьте дату на компьютере, затем сообщите администратору |
| **Сервер не найден** | неверный адрес или нет DNS | проверьте адрес и VPN |
| **Сервер недоступен** или **Сервер не отвечает** | нет сети до сервера | откройте адрес в браузере на этом же компьютере, проверьте VPN и прокси |
| **Ошибка прокси-сервера** | неверная настройка прокси | проверьте **Настройки → Сеть** |
| **Не поддерживается версия сервера** | сервер устарел | нужен сервер 0.37.0 или новее, сообщите администратору |
| **Нужен защищённый адрес https://.** | указан адрес `http://` | укажите `https://` |
| **Добавление серверов запрещено политикой организации.** | подключения задаёт администратор | обратитесь к администратору |

Камера или микрофон запрещены: разрешите доступ в параметрах конфиденциальности Windows. Подробно: [Как настроить звук и видео в приложении для Windows](Как-настроить-звук-и-видео-в-приложении-Windows).
