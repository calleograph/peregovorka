# Что такое Peregovorka

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1–3 (чтение кода и запуск на стенде) · тип страницы: объяснение

Peregovorka — веб-система переговорных комнат для локальной сети организации. Она заменяет внешний сервис видеосвязи и отдельные средства стенографирования одним продуктом, который работает на вашем сервере.

## Какую задачу решает

Организации с требованиями к конфиденциальности не могут отправлять записи и тексты совещаний во внешние облака. Peregovorka решает три задачи:

1. **Провести встречу.** Голос, видео, несколько демонстраций экрана, общая доска draw.io и чат в одной комнате. Гости заходят по ссылке без учётной записи.
2. **Записать, кто что сказал.** Речь каждого участника распознаётся отдельно моделью GigaAM v3 на вашем процессоре. Интернет для распознавания не нужен.
3. **Получить документы.** После встречи система формирует протокол, краткое резюме и карту разговора. Их пишет встроенная языковая модель Qwen3 1.7B либо внешняя модель, которую вы подключили сами.

## Для кого

| Читатель | Что получает |
| --- | --- |
| Сотрудник | встречи по доменной учётной записи, стенограмма в реальном времени, протокол после встречи, чаты |
| Руководитель комнаты | управление участниками, доступом, записью и рассылкой материалов своей комнаты |
| Администратор | настройка через браузер, обновление одной кнопкой, журнал аудита |
| Организация | данные и модели на своём сервере, интеграции с Active Directory, почтой, SMB, АТС |

## Из чего состоит

| Компонент | Назначение |
| --- | --- |
| web (nginx) | единственная HTTP-точка входа: интерфейс, API, сигналинг звонков |
| backend (FastAPI) | логика, права, API, фоновые задачи |
| LiveKit | передача звука и видео (WebRTC) |
| asr (GigaAM + Silero VAD) | распознавание речи |
| PostgreSQL, Redis | данные и очереди |
| llm-local (llama.cpp) | встроенная языковая модель, без доступа в интернет |
| приложение для Windows | отдельный клиент: несколько организаций, трей, уведомления |

Схема взаимодействия — в [[Как устроена Peregovorka|Как-устроена-Peregovorka]].

## Что система не делает

- Не хранит видеозапись встречи: сохраняется общая аудиозапись ([[Возможности]], статус «запланировано» для видео).
- Не заменяет юриста: протокол от небольшой локальной модели нужно проверять человеку ([[Как работают стенограмма и протоколы|Как-работают-стенограмма-и-протоколы]]).
- Не даёт единого входа (SSO) в надстройке Outlook ([[Как подключить надстройку Outlook|Как-подключить-надстройку-Outlook]]).
