# Архитектура: порты и сервисы

*Для кого: сетевой инженер, администратор.*

**Что получится:** полный перечень сетевых сервисов: что публиковать наружу, что остаётся внутри и от чего зависит значение.

Значения — из `deployment/compose.yml`, `.env.example` и шаблонов nginx. Установщик может выбрать другие свободные порты. **Точный перечень вашей установки** даёт `scripts/ports.sh` или **Администрирование → Система → Сетевая доступность**.

Различайте два номера: **порт контейнера** работает внутри сети Docker, **порт хоста** опубликован на сервере. Ниже у каждого сервиса указаны оба, если он публикуется.

## Обязательные внешние

Их должны видеть пользователи.

| Сервис | Назначение | Протокол | Порт | Направление | Настройка | Компонент |
|---|---|---|---|---|---|---|
| HTTPS | страница, API, события, сигналинг, HLS | TCP | 443 | клиент → прокси | порт в `APP_PUBLIC_URL`, `--https-port` | обратный прокси |
| Медиа WebRTC | звук, видео, экран | UDP | `LIVEKIT_UDP_PORT`, шаблон 17882 | клиент → сервер | `.env`; адрес `LIVEKIT_BIND_ADDR` | `livekit` |
| Медиа, запасной путь | то же при закрытом UDP | TCP | `LIVEKIT_TCP_PORT`, шаблон 17881 | клиент → сервер | `.env` | `livekit` |

Медиапорты публикуются напрямую и **не проходят через HTTP-прокси**. За NAT пробрасывайте их без смены номера: [Публикация во внешний контур](Архитектура-Публикация-во-внешний-контур).

## Внутреннее взаимодействие

Наружу не публикуются. Защита — сеть проекта Docker и пароли.

| Сервис | Назначение | Протокол | Порт контейнера | Порт хоста | Кто обращается | Компонент |
|---|---|---|---|---|---|---|
| Вход в приложение | nginx приложения | TCP | 8080 | `WEB_BIND_ADDR:WEB_PORT`, шаблон `127.0.0.1:18480` | обратный прокси | `web` |
| Промежуточный site | nginx хоста для внешнего прокси | TCP | — | `NGINX_LISTEN_PORT`, шаблон 18400 | внешний прокси | nginx хоста |
| API | backend | TCP | 8000 | нет | `web`, `livekit` (webhook) | `backend` |
| LiveKit API и сигналинг | WebSocket, API | TCP | 7880 | `127.0.0.1:LIVEKIT_HTTP_PORT`, шаблон 17880 | `web`, `backend`, `asr`, `egress`, `sip` | `livekit` |
| Здоровье ASR, управление | HTTP | TCP | 8090 | нет | `backend` | `asr` |
| База данных | PostgreSQL | TCP | 5432 | нет | `backend` | `postgres` |
| Redis | сессии, очереди, шина | TCP | 6379 | нет | `backend`, `asr`, `livekit`, `egress`, `sip` | `redis` |

## Дополнительные

Нужны только при включённой функции.

| Сервис | Назначение | Протокол | Порт | Направление | Доступ | Настройка |
|---|---|---|---|---|---|---|
| SIP | сигнализация АТС | UDP и TCP | `SIP_SIGNALING_PORT`, 5060 | АТС ↔ сервер | только АТС, `SIP_BIND_ADDR` | профиль `sip` |
| RTP | звук телефонии | UDP | `SIP_RTP_START`–`SIP_RTP_END`, 20000–20100 | АТС ↔ сервер | только АТС | профиль `sip` |
| Узел CDN, HTTPS | раздача зрителям, статистика | TCP | 443 | зрители, сервер → узел | внешний | [Узлы CDN](Узлы-CDN) |
| Узел CDN, HTTP | выпуск Let's Encrypt, перенаправление | TCP | 80 | интернет → узел | внешний | режим Let's Encrypt |
| Узел CDN, SSH | управление | TCP | 22 или ваш | сервер → узел | только основной сервер | карточка узла |

## Администрирование и диагностика

Не публикуйте наружу.

| Сервис | Назначение | Протокол | Порт | Доступ |
|---|---|---|---|---|
| SSH сервера | обслуживание | TCP | 22 или ваш | сеть администраторов |
| Метрики LiveKit | «Производительность» | TCP | 6789, контейнер | внутри сети проекта |
| Здоровье Egress | нагрузка, проверка службы | TCP | 8082, контейнер | внутри сети проекта |
| `/internal/` | служебные маршруты | TCP | через `web` | 404 снаружи |
| `/__hls/state` | состояние секрета подписи | TCP | 8080, контейнер | для проверки backend |

## Исходящие соединения

Сервер инициирует их сам, входящих правил они не требуют.

| Куда | Протокол, порт | Зачем | Когда |
|---|---|---|---|
| Контроллеры домена | LDAPS 636 или STARTTLS 389 | вход, группы, профили | если подключён каталог |
| SMTP | 25, 465, 587 | письма | если настроена почта |
| SMB | 445 | хранилища | если настроены |
| Exchange или Microsoft Graph | HTTPS 443 | календарь | если подключён |
| Языковая модель | HTTPS 443 или ваш порт | протоколы | если подключена |
| Площадки | RTMP 1935, RTMPS 443 | внешний эфир | если добавлены |
| STUN | UDP, адреса из `LIVEKIT_STUN_SERVERS` | узнать свой адрес | режим `nat-stun` |
| Bitrix24, получатели webhooks | HTTPS | профили, события | если настроены |
| Узлы CDN | SSH и HTTPS | управление, состояние | если подключены |
| GitHub, Docker Hub, npm, PyPI, apt, модели | HTTPS | установка и обновление | только на это время |
