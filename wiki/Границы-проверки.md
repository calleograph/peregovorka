# Что проверено

*Для кого: владелец системы, администратор, специалист по ИБ.*

Здесь собрано, что в Peregovorka проверено и что ещё нет. Прочитайте эту страницу, прежде чем принимать продукт в работу.

**Главное.** Подтверждённой вместимости всей системы нет. Сквозного испытания, где одновременно идут встречи, медиа, распознавание, запись, эфир и протоколы, не проводилось. Замеры относятся к отдельным службам, на одной машине разработчика, с синтетическими клиентами. Настоящих браузеров одновременно было не больше пяти. Условия замеров: [Производительность и масштабирование](Производительность-и-масштабирование). Какие испытания нужны: [Матрица нагрузочных испытаний](Матрица-нагрузочных-испытаний).

## Как проверяется продукт

- **Автоматические тесты** сервера, интерфейса, скриптов установки и обновления, распознавания речи и приложений. Они запускаются при каждом выпуске и в GitHub Actions.
- **Живые сценарии** в настоящих браузерах с настоящим медиасервером LiveKit. Каталог пользователей, почта, сетевые папки и АТС в этих сценариях заменены тестовыми.
- **Тестовый экземпляр**, установленный штатным установщиком (профиль `shared-host`). На нём выполняются команды из руководств администратора и поддержки: обновление, откат, резервное копирование и восстановление.
- **Чистые системы в CI.** На Ubuntu 22.04, 24.04 и Debian 12, 13 проверяется только установка зависимостей. Полная сборка образов и запуск служб там не выполняются.
- **Сборка приложений** для Windows и Android в GitHub Actions: установщики Windows проходят тихую установку, приложение для Android запускается на эмуляторах.

## Что не проверено в настоящей среде

В таблице — что пока не подтверждено на настоящих системах организации. Перед внедрением проверьте эти пункты у себя.

| Область | Что не подтверждено |
| --- | --- |
| Active Directory | вход и проверка групп на настоящем каталоге: в репозитории нет записи о такой проверке |
| SMTP / Exchange | отправка через настоящий почтовый сервер, ограничения шлюзов на вложения |
| SMB | запись, листинг больших каталогов и сверка на настоящей сетевой папке |
| SIP / АТС | звонок в обе стороны с настоящей АТС (Asterisk, PJSIP или другой) |
| Outlook | настоящие Outlook и Exchange (EWS, Graph, NTLM, Kerberos); единый вход не реализован |
| Календарь Outlook в Peregovorka | создание, перенос и отмена на настоящих Exchange и Microsoft 365: права имперсонации и политики Graph, формат рассылаемых приглашений, серии с исключениями, пояса Windows в EWS |
| Гостевые ссылки Outlook | настоящий Outlook (вставка блока в письмо, отправленные приглашения при перевыпуске ссылки) |

| Сетевая доступность | доступность портов из интернета через настоящий NAT и межсетевой экран (с сервера это проверить нельзя); UDP без участия клиента не проверяется |
| Восстановление материалов | SMB-хранилище с большими архивами, сотни тысяч файлов, перенос между серверами с разными базами |
| Звук и видео в приложении Windows | настоящие USB-, Bluetooth- и встроенные микрофоны, запуск окна «Звук» и `ms-settings:`; коды ошибок WASAPI в журнале звука и поведение при защитной программе (Kaspersky Endpoint Security) |
| Bitrix24 | настоящий портал |
| Установка | полная установка профиля `standalone` на настоящий чистый сервер от начала до конца; новые версии систем сверх Ubuntu 24.04 и Debian 13; поведение при плохом канале до источника моделей |
| Обновление | настоящее обновление при деградации сети (медленный npm, недоступный источник) |
| Распознавание речи | точность на живых разговорах, настоящие микрофоны и акустика, GPU-образ |
| Протоколы | качество протоколов на настоящих записях; открытие документов в Word и LibreOffice |
| Обезличивание | полнота распознавания имён на настоящих стенограммах (проверено на синтетических русских текстах); сканы PDF (OCR не выполняется) |
| Нагрузка | сервер целевого класса с генераторами на других машинах; конфигурация 4 vCPU и 8 ГБ; настоящие браузеры в масштабе; встречи с 20 камерами и больше; PostgreSQL на дисках сервера; несколько контейнеров `backend`; LiveKit на нескольких узлах; замеры на текущей версии: основной замер приложения относится к 0.32.0 |
| Запись и эфир | две и больше одновременных записи или эфира; эфиры дольше 2 часов; 1440p по процессору и памяти; настоящие камеры в эфире; заполнение диска на настоящем сервере |
| Просмотр эфира | WebRTC под нагрузкой; LL-HLS больше 300 клиентов; настоящие зрители в масштабе; служебная нагрузка зрителей на `backend`: ссылки, пульс, вопросы; внешний прокси и `/llhls/`; Safari и iPhone как плееры |
| Сеть | настоящий канал CDN и сетевая карта; потери и джиттер в масштабе; вместимость по TCP |
| Браузеры | Safari и Firefox (основная проверка в Chrome и Edge), физические телефоны |
| Приложение для Windows | ручная проверка на настоящей Windows: вход с компьютера домена, камеры и гарнитуры, несколько мониторов, автозапуск после перезагрузки, SmartScreen |
| Сквозное шифрование | Safari, Firefox, настоящая служба распознавания в E2EE-комнате |

## Что подтверждено на сервере владельца

- Система установлена и работает на настоящем сервере с октября 2026 года.
- Обновление из браузера отработало на настоящем сервере (0.39.1 → 0.39.2, 25 октября 2026 года).

Записей о том, какие интеграции (каталог, почта, сетевые папки, АТС) проверялись на этом сервере, нет. Поэтому для интеграций действует таблица выше.

## Что значит «поддерживается»

Когда вики говорит, что интеграция поддерживается, это значит: она реализована и проверена на тестовой замене внешней системы. Это ещё не доказательство, что она заработает в вашей инфраструктуре. Перед рабочим применением проверьте каждую интеграцию на тестовом экземпляре по странице [Диагностика](Диагностика).
