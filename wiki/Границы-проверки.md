# Границы проверки

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1–3 · тип страницы: справочник

Страница собирает то, что **не** подтверждено запуском в реальной корпоративной среде. Её нужно прочитать до принятия продукта в эксплуатацию. Источник — раздел «Известные ограничения и непроверенное» файла `PROJECT.md` в репозитории и журнал `HISTORY.md`.

## Как проверялся продукт

| Вид проверки | Что подтверждает | Объём на 2026-10-25 |
| --- | --- | --- |
| Автоматические тесты backend | логику, права, API | 1208 тестов |
| Автоматические тесты frontend | интерфейсную логику | 466 тестов |
| Автоматические тесты shell | скрипты установки и обновления на подставном Docker | 561 тест |
| Автоматические тесты распознавания речи | конвейер на подставной модели | 74 теста (собраны `pytest --collect-only`; не все исполнялись при подготовке вики) |
| Живые сценарии | настоящие LiveKit и браузеры на стенде разработчика (`tests/live/`) | десятки сценариев; каталог пользователей, почта, SMB и АТС в них подставные |
| CI GitHub Actions | сборку, тесты, сборку установщиков Windows | зелёный на выпусках 0.39.4 и клиента 1.2.0 |

Источник чисел: запуск тестов при подготовке выпусков (backend и shell — полный прогон; frontend — `vitest`). Число тестов ASR — результат сбора, без полного прогона.

## Что не проверено на реальной инфраструктуре

| Область | Что не подтверждено |
| --- | --- |
| Active Directory | вход и проверка групп на настоящем каталоге: в репозитории нет записи о такой проверке |
| SMTP / Exchange | отправка через настоящий почтовый сервер, ограничения шлюзов на вложения |
| SMB | запись, листинг больших каталогов и сверка на настоящей сетевой папке |
| SIP / АТС | звонок в обе стороны с настоящей АТС (Asterisk, PJSIP или другой) |
| Outlook | настоящие Outlook и Exchange (EWS, Graph, NTLM, Kerberos); единый вход не реализован |
| Bitrix24 | настоящий портал |
| Установка | полная установка на чистый сервер от начала до конца; режим `shared-host` вживую; поведение при плохом канале до источника моделей |
| Обновление | настоящее обновление при деградации сети (медленный npm, недоступный источник) |
| Распознавание речи | точность на живых разговорах, настоящие микрофоны и акустика, GPU-образ |
| Протоколы | качество локальной модели на настоящих записях (измерено на синтетических встречах); открытие документов в Word и LibreOffice |
| Нагрузка | настоящие браузеры в масштабе, PostgreSQL на дисках сервера, несколько контейнеров backend, LiveKit на нескольких узлах |
| Браузеры | Safari и Firefox (основная проверка — Chrome и Edge), физические телефоны |
| Приложение для Windows | ручная проверка на настоящей Windows: вход с компьютера домена, камеры и гарнитуры, несколько мониторов, автозапуск после перезагрузки, SmartScreen |
| Сквозное шифрование | Safari, Firefox, настоящая служба распознавания в E2EE-комнате |

## Что подтверждено на сервере владельца (уровень 4, частично)

В документах проекта есть следующие свидетельства работы на реальном сервере владельца:

- Система установлена и работает на реальном сервере (`docs/INTERNALS.md`, раздел «Статус»; первая реальная установка — запись `HISTORY.md` от 2026-10-06).
- Правки по итогам обновления на реальном сервере (`HISTORY.md`, запись от 2026-10-08).
- Обновление из веб-интерфейса отработало: после обновления с 0.39.1 страница «Обновления и версии» показывала 0.39.2 (25 октября 2026 года; источник — снимок экрана владельца).

Записей о том, **какие интеграции** (каталог, почта, SMB, АТС) проверялись на этом сервере и с каким результатом, в документах нет. Поэтому интеграции в этой вики остаются на уровне 2–3.

## Как читать формулировку «поддерживается»

В вики слово «поддерживается» для интеграции с внешней системой означает: реализовано и проверено автотестами на подставной системе (уровень 2) либо запуском на стенде (уровень 3). Это не доказательство работы в вашей инфраструктуре. Перед рабочим применением проверьте каждую интеграцию на тестовом экземпляре, пользуясь страницей [[Диагностика]].
