# Поиск по вопросам

*Для кого: все, кто ищет ответ обычными словами.*

Найдите свой вопрос на этой странице: нажмите **Ctrl+F** и введите слово. Вопросы записаны так, как их обычно задают, а рядом есть другие слова для того же. В приложении Peregovorka такой же поиск открывается через **Справка** в меню пользователя.

Поиск GitHub ищет по точным словам. Если он ничего не нашёл, вернитесь сюда: здесь учтены разные формулировки.
