# Как настроить переговорки и доступ

*Для кого: администратор.*

## Зачем это нужно

Статья показывает порядок работы администратора: создать комнаты, определить, кто в них входит и кто руководит, включить нужные виды комнат на сервере. Подробности собраны в отдельных статьях, эта задаёт последовательность и описывает настройки сервера.

## Когда пригодится

- Первоначальная настройка нового сервера.
- Подключение нового отдела.
- Нужно разрешить или запретить временные комнаты.

## Что потребуется

- Права администратора.
- Для доступа по группам: подключённый каталог, см. [Как подключить Active Directory](Как-подключить-Active-Directory).

## Где найти

| Задача | Путь |
| --- | --- |
| Комнаты | **Администрирование → Комнаты и пользователи → Комнаты и доступ** |
| Пользователи и вход | **Администрирование → Комнаты и пользователи** |
| Виды комнат | **Администрирование → Система → Общие настройки** |

## Как это сделать

1. **Создайте комнату.** Нажмите **＋ Создать комнату**, задайте название и адрес. Подробно: [Как создать комнату](Как-создать-комнату).
2. **Выберите тип.** На вкладке **Встреча и запись** выберите **Обычная**, **Презентационная** или **Трансляционная**.
3. **Дайте доступ.** На вкладке **Доступ и гости** заполните **Кто может заходить**. Без записей комната видна только администраторам и руководителям.
4. **Назначьте руководителя.** Он ведёт комнату без администратора. Подробно: [Управление участниками комнаты](Управление-участниками-комнаты).
5. **Решите, кто видит завершённые встречи.** Поле **Кто видит встречу после завершения** на вкладке **Доступ и гости**. Это поле доступно только администратору.
6. **Задайте сроки хранения.** Вкладка **Материалы**, блок **Хранение**. Подробно: [Сроки хранения материалов](Сроки-хранения-материалов).
7. **Настройте остальное при необходимости:** запись, гостевой вход, автоотправка, модель, телефония. Описание всех вкладок: [Настройки комнаты](Настройки-комнаты).
8. **Сохраните** и попросите сотрудника проверить вход.

### Выбрать тип комнаты

| Тип | Когда выбрать |
| --- | --- |
| **Обычная** | совещание: участники говорят и показывают экран по правам комнаты |
| **Презентационная** | доклад: руководители выступают, остальные слушают, слово даётся и забирается |
| **Трансляционная** | эфир: выступающие в конференции, зрители смотрят по ссылке. Подготовка идёт без записи и стенограммы |

Эфир можно вести и в обычной или презентационной комнате: включите его на вкладке **Трансляция**. Подробно: [Создание трансляционной комнаты](Создание-трансляционной-комнаты).

Смена типа, камеры и показа экрана действует для уже вошедших со следующего входа.

### Сменить адрес комнаты

Поле **Адрес комнаты** на вкладке **Основное**. Система попросит подтвердить изменение. Прежний адрес продолжит работать и перенаправит на новый. Гостевая ссылка не изменится. Старые ссылки вида `/rooms/<UUID>` тоже работают.

### Завершить встречу или удалить комнату

В строке комнаты:

- **Завершить встречу**: все участники отключаются, записи и стенограмма сохраняются;
- **Удалить**: комната удаляется вместе с историей встреч и файлами. Это необратимо. Пока идёт встреча, удалить комнату нельзя.

Отметка **показывать закрытые временные** добавляет в список закрытые временные комнаты.

### Настроить временные переговорки

**Администрирование → Система → Общие настройки**, блок **Временные переговорки**:

| Настройка | По умолчанию |
| --- | --- |
| **Разрешить пользователям создавать временные переговорки** | включено |
| **Активных временных комнат у одного пользователя** | 2 |
| **Активных временных комнат во всей системе** | 30 |
| **Сколько ждать возврата, когда все вышли** | 5 минут |
| **Закрывать комнату, в которую никто не вошёл, через** | 30 минут |
| **Предельная длительность встречи во временной комнате** | 12 часов |
| **Разрешить владельцу временной комнаты выпускать гостевую ссылку** | выключено |

Как закрывается временная комната:

- руководитель завершил встречу: комната закрывается сразу;
- все вышли: система ждёт возврата, затем закрывает;
- никто не вошёл: закрывается по таймеру;
- встреча зависла: завершается принудительно по предельной длительности.

Закрытая комната исчезает из списков. Запись, стенограмма, чат, доска и протоколы остаются в **Истории**. Участники временной комнаты видят её материалы после встречи.

### Настроить равноправные комнаты

**Администрирование → Система → Общие настройки**, блок **Равноправные комнаты**:

| Настройка | По умолчанию |
| --- | --- |
| **Разрешить временные равноправные комнаты** | выключено |
| **Создавать комнату при первом переходе по ссылке** | включено |
| **Активных равноправных комнат у одного пользователя** | 3 |
| **Активных равноправных комнат во всей системе** | 50 |
| **Новых комнат в час у одного пользователя** | 10 |
| **Закрывать комнату, в которую никто не вошёл, через** | 24 часа |
| **На сколько часов владелец может продлить комнату за раз** | 24 часа |

Равноправная комната открывается по ссылке `/p/<код>`, код из 20 знаков. Ведущего нет, управляет ссылкой создатель.

### Включить шифрование для новых комнат

**Общие настройки**, блок **Шифрование хранилища**: **Шифровать чат и стенограммы в новых комнатах**. Существующие комнаты не меняются. Подробно: [Шифрование](Шифрование).

## Что получится

Комнаты видны в разделе **Переговорки** тем, кому разрешён доступ. Руководители управляют своими комнатами сами.

## Если не получается

| Что видно | Причина | Что сделать |
| --- | --- | --- |
| Сотрудник не видит комнату | пуст список доступа, или он не в группе | проверьте вкладку **Доступ и гости** |
| Нельзя занять адрес | он используется или был прежним адресом другой комнаты | выберите другой |
| Руководитель не меняет адрес или сроки хранения | это права администратора | измените сами |
| Сотрудник не может войти в систему вообще | он вне **Разрешённых групп** | см. [Управление пользователями](Управление-пользователями) |
| Удаление отклонено: **В комнате идёт встреча** | встреча активна | сначала завершите её |
| **Комната не удалена: … файл(ов) записей не удалось удалить…** | внешнее хранилище недоступно, удаление файлов повторяется автоматически | удалите комнату снова, когда файлы будут удалены |
