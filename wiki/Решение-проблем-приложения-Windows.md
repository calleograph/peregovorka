# Решение проблем: приложение для Windows

*Для кого: служба поддержки и администратор рабочих станций.*

Первым делом соберите отчёт: **«Настройки → Диагностика → Сохранить отчёт»**. Если окно не открывается, отчёт создаётся из командной строки: `Peregovorka.exe --diagnostics=<файл>`. Журнал приложения лежит в `%APPDATA%\Peregovorka\logs\main.log`. Пароли, токены и параметры ссылок в нём скрыты.

## Сервер не добавляется

| Сообщение | Причина | Что сделать |
| --- | --- | --- |
| нужен защищённый адрес https | указан адрес `http://` | указать `https://…` |
| сервер недоступен | нет сети до сервера или неверный адрес | открыть адрес в браузере на том же компьютере |
| сертификат не доверен | Windows не доверяет центру, выдавшему сертификат сайта | корневой сертификат организации — в хранилище доверенных Windows (обычно по групповой политике) |
| несовместимая версия | сервер старше версии, нужной приложению | обновить сервер |

## Пустое окно или «not found» при запуске

Отчёт `--diagnostics`, раздел `shell`, и журнал `main.log` (строки `shell.not_found`, `preload.error`) называют, какой файл программы не загрузился. Обычно помогает переустановка поверх той же версией.

## Вход не сохраняется, приходится входить заново

Приложение хранит отзываемый ключ устройства, а Windows его защищает. Ключ перестаёт действовать, если его отозвали на сервере, истёк его срок или сменился профиль Windows (защищённые данные привязаны к профилю). Войдите снова — ключ выпустится заново.

## Нет уведомлений о сообщениях и встречах

Проверьте «Настройки → Уведомления» (включены, «Не беспокоить» выключен), уведомления приложения в параметрах Windows, режим фокусировки и групповую политику `Notifications`. Когда страница организации видна на экране, уведомление показывается внутри неё, а не системным окном.

## Windows предупреждает SmartScreen при установке

Установщики пока не подписаны сертификатом издателя. Это ожидаемо для предварительного выпуска: «Подробнее → Выполнить в любом случае». Для установки на все компьютеры организации используйте MSI и групповые политики — [Как развернуть приложение Windows в организации](Как-развернуть-приложение-Windows-в-организации).
