# Как читать эту вики

> Относится к версии 0.39.4 · проверено 2026-10-25 · уровень проверки: 1 (правила вики) · тип страницы: справочник

## Типы страниц

Каждая страница относится ровно к одному типу (подход [Diátaxis](https://diataxis.fr/)):

| Тип | Признак в названии | Что внутри |
| --- | --- | --- |
| Учебник | «Первые шаги с …» | шаги от нуля до видимого результата |
| Практическое руководство | «Как …» | решение одной задачи |
| Справочник | «Справочник: …», «Возможности» | точные факты в таблицах |
| Объяснение | «Как устроена …», «Безопасность и приватность» | устройство и причины решений |

## Статусы функций

| Статус | Значение |
| --- | --- |
| Реализовано и проверено | работает; есть тесты и запуск на стенде |
| Реализовано, не проверено в реальной среде | код есть; внешняя система была подставной |
| Экспериментально | включать на свой риск |
| Запланировано | не работает; описано только на странице [[Планы развития|Планы-развития]] |
| Устарело | снято с вооружения |

## Уровни проверки

| Уровень | Что означает |
| --- | --- |
| 0 | утверждение есть в документах |
| 1 | подтверждено чтением кода |
| 2 | подтверждено автоматическими тестами |
| 3 | подтверждено запуском на стенде разработчика |
| 4 | подтверждено работой в реальной инфраструктуре |

В вики встречаются записи **ТРЕБУЕТ ПРОВЕРКИ** (факт не удалось подтвердить) и пометка **не запускалась** у команд, которые не выполнялись при подготовке страницы.

## Источники

Факты берутся из кода, тестов, конфигурации и документов репозитория [calleograph/peregovorka](https://github.com/calleograph/peregovorka). При расхождении приоритет у кода и последнего выпуска. Найденные устаревшие места в документах описаны на странице [[Известные проблемы|Известные-проблемы]] и исправляются в репозитории.
