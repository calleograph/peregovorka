# Как выбрать языковую модель

*Для кого: руководитель комнаты, администратор. Организатору: чтобы понять, какая модель сработает.*

## Зачем это нужно

Языковая модель: нейросеть, которая пишет протокол, резюме и карту разговора. Администратор может подключить несколько моделей. Для важных протоколов можно выбрать более сильную, для обычных более быструю. Для чувствительных встреч можно выбрать модель, работающую внутри организации.

Подключение модели к серверу описано отдельно: [Как настроить языковые модели](Как-настроить-языковые-модели). Встроенной модели в Peregovorka нет.

## Когда пригодится

- Протоколы одной комнаты требуют более сильной модели.
- На конкретной встрече обсуждают конфиденциальное.
- Документ получился плохо, и хочется попробовать другую модель.
- Комнате языковая модель не нужна вообще.

## Что потребуется

| Уровень | Кто выбирает |
| --- | --- |
| Один документ | руководитель комнаты, администратор |
| Одна встреча | руководитель комнаты, администратор |
| Комната | руководитель комнаты, администратор |
| Вся система | администратор |

Организатор, который не руководит комнатой, видит выбранную модель, но изменить её не может. Выбирать можно только из подключений, которые создал администратор.

## Какая модель сработает

Действует самый сильный из заданных уровней:

1. Разовый выбор в окне формирования.
2. Настройка встречи.
3. Настройка комнаты.
4. Системное назначение.

Протокол и резюме настраиваются раздельно. Для карты разговора действуют только разовый выбор и системное назначение: настройки комнаты и встречи на неё не влияют.

## Где найти

| Уровень | Путь |
| --- | --- |
| Один документ | окно **Сформировать протокол** → блок **Модель** → **Использовать другую модель только для этого формирования** |
| Одна карта | вкладка **Карта разговора** → **Параметры…** |
| Одна встреча | в комнате кнопка настроек → **Эта встреча…** → вкладка **Языковая модель** |
| Комната | **Настройки комнаты…** → вкладка **Языковая модель** |
| Вся система | **Администрирование → Интеграции → Языковая модель (LLM) → Назначения** |

## Как это сделать

### Для одного документа

1. Откройте окно **Сформировать протокол**.
2. В блоке **Модель** посмотрите текущую модель. Рядом указан источник: **выбрана на один раз**, **настройка встречи**, **настройка переговорки** или **системная по умолчанию**.
3. В поле **Использовать другую модель только для этого формирования** выберите модель. **Ожидаемое время** пересчитается.
4. Нажмите **Сформировать**.

Настройки комнаты и системы не меняются. Факт выбора записывается в журнал.

### Для одной встречи

Выполняется во время встречи.

1. Нажмите кнопку настроек в шапке комнаты.
2. Выберите **Эта встреча…**.
3. На вкладке **Языковая модель** в блоках **Модель для протокола** и **Модель для резюме** выберите **Как в комнате**, **Подключение к модели** или **Отключить языковую модель**.
4. Нажмите **Сохранить для этой встречи**.

Кнопка **Вернуть как в комнате** отменяет выбор. На следующей встрече снова действуют настройки комнаты.

### Для комнаты

1. Откройте **Настройки комнаты…**, вкладку **Языковая модель**.
2. В блоках **Модель для протокола** и **Модель для резюме** выберите:
   - **Использовать системную по умолчанию**: значение из администрирования;
   - **Подключение к модели**: конкретное подключение из списка;
   - **Отключить языковую модель**: документы формироваться не будут.
3. Сохраните настройки комнаты.

### Для всей системы

1. Откройте **Администрирование → Интеграции → Языковая модель (LLM)**.
2. На вкладке **Назначения** в строке задачи (**Протокол**, **Резюме**, **Карта разговора**) нажмите **Изменить**.
3. Выберите подключение. Для резюме и карты есть вариант **Как для протокола**, для любой задачи **Не использовать (задача отключена)**.
4. Нажмите **Сохранить**.

Ниже находится настройка **Если модель комнаты или встречи недоступна**:

- **Использовать системное назначение задачи (с пометкой)**: подставляется системная модель;
- **Не формировать: показать «модель недоступна»**: документ не создаётся.

Разовый выбор никогда молча не заменяется другой моделью.

### Что учитывать при выборе

| Вопрос | На что смотреть |
| --- | --- |
| Куда уходит текст? | модель внутри организации не передаёт текст наружу. Для внешней модели используйте обезличивание: [Как работает обезличивание](Как-работает-обезличивание) |
| Насколько длинная встреча? | у модели должно хватать окна контекста и предела ответа. Иначе появится состояние **обрезано** |
| Важна скорость? | смотрите **Ожидаемое время** в окне и вкладку **Статистика** в администрировании |
| Сколько стоит? | у платных сервисов запросы оплачиваются; токены видны администратору в блоке **Как создан документ: время, модель, части** |

Сравнительных замеров качества разных моделей у проекта нет. Сформируйте документ по типичной встрече разными моделями и сравните сами.

## Что получится

В блоке **Модель** окна формирования указана нужная модель. После формирования модель видна в строке документа и в блоке **Как создан документ**.

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Нет поля выбора другой модели | вы организатор, а не руководитель | попросите руководителя комнаты |
| В списке нет нужной модели | подключение выключено или не создано | обратитесь к администратору |
| «Языковая модель для этой комнаты отключена» | в комнате выбрано **Отключить языковую модель** | измените настройку комнаты |
| «Языковая модель по умолчанию отключена или не настроена» | нет системного назначения | администратор выбирает подключение на вкладке **Назначения** |
| «Выбранный профиль языковой модели удалён» | подключение удалили | выберите другое |
| В сведениях о документе пометка об использовании системной модели | выбранная модель недоступна, сработала запасная | проверьте подключение |
| Нет пункта **Эта встреча…** | пункт доступен только руководителю во время встречи | откройте настройки комнаты |
