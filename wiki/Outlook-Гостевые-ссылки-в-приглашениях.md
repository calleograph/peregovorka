# Гостевые ссылки в приглашениях

*Для кого: администратор, который разрешает гостей, и организатор встречи.*

## Зачем это нужно

Внешний участник входит во встречу без учётной записи Peregovorka. Для него в приглашении есть отдельная ссылка.

> В настоящем Outlook это не проверялось. Не подтверждены вставка блока в письмо и поведение уже отправленных приглашений при новой ссылке. Панель проверялась в браузере с заменой библиотеки Outlook.

## Когда пригодится

- На встречу приглашены клиенты, подрядчики или коллеги из другой организации.
- Ссылка попала не тому человеку, и её нужно заменить.
- Организация запрещает гостей, и старые ссылки должны перестать работать.

## Что потребуется

- Администратор включил **Пускать гостей без учётной записи**. По умолчанию настройка выключена.
- Встреча создана через надстройку или календарь Peregovorka.
- Управлять ссылкой в панели Outlook может создатель конференции и администратор сервера.

## Где найти

| Что | Где |
| --- | --- |
| Разрешение | **Администрирование → Интеграции → Microsoft Outlook → Настройки интеграции → Ограничения и вход надстройки** |
| Ссылка в Outlook | боковая панель, блок **Для внешних участников** |
| Ссылка в календаре | карточка события, строка **Для внешних участников**. Её видит только организатор |
| Ссылка на главной | блок **Предстоящие встречи**, кнопка **Копировать гостевую ссылку** или пункт меню **Скопировать гостевую ссылку** |

## Как это сделать

### Разрешить гостей

1. Откройте **Администрирование → Интеграции → Microsoft Outlook**.
2. Включите **Пускать гостей без учётной записи**.
3. Нажмите **Сохранить**.

### Встреча из Outlook

1. Добавьте конференцию: [Конференции через Outlook](Outlook-Конференции-через-Outlook). Гостевая ссылка выпускается вместе с комнатой.
2. Проверьте, что в тексте есть блок **Для внешних участников**.
3. Если ссылки нет, нажмите в панели **Выпустить гостевую ссылку**.
4. Отправьте приглашение.

### Встреча из календаря

1. В форме **Новая встреча** оставьте **Создать конференцию Peregovorka**.
2. Отметьте **Добавить гостевую ссылку для внешних участников**. Без отметки ссылка не выпускается.
3. Нажмите **Создать и разослать приглашения**.

Если забыли, организатор может выпустить ссылку на карточке в блоке **Предстоящие встречи**.

### Заменить или отозвать ссылку

1. Откройте встречу в Outlook и панель надстройки.
2. Нажмите **Выпустить новую** или **Отозвать**.
3. Нажмите ещё раз для подтверждения.
4. Отправьте обновление встречи: в уже отправленных письмах остаётся прежняя ссылка.

Обе команды сразу отключают гостей, которые сейчас во встрече.

## Что получится

В приглашении две подписанные ссылки:

| Подпись | Адрес | Вход |
| --- | --- | --- |
| **Для сотрудников организации** | `/m/<код>` | учётная запись |
| **Для внешних участников** | `/guest/<токен>` | имя, без учётной записи |

Гость открывает ссылку, вводит имя не короче двух знаков, почту по желанию и проверяет оборудование. Если организация требует подтвердить документы, он подтверждает их.

Гость входит только в идущую встречу. Пока сотрудник не открыл комнату, он видит: «Встреча ещё не началась. Дождитесь, пока сотрудник откроет комнату — страница обновится сама.» До открытия входа комната закрыта и для него.

Что доступно гостю:

| Возможность | Гость |
| --- | --- |
| Микрофон | да |
| Камера | да, если разрешена в комнате. В комнатах из Outlook она разрешена при создании |
| Чат | да |
| Показ экрана | нет |
| История встреч и материалы организации | нет |
| Другие встречи | нет |

## Важно знать

- Ссылка одна на встречу. Повторное нажатие кнопки и перенос её не меняют.
- Серия использует одну ссылку на все занятия.
- Срока у ссылки нет. Она работает, пока комната не закрыта, не отменена и ссылка не отозвана.
- Ссылка для сотрудников вида `/m/<код>` гостевого входа не даёт. Страница просит войти учётной записью, а если у встречи есть гостевая ссылка, подсказывает: **Нет учётной записи? Войдите по гостевой ссылке из приглашения или попросите её у организатора.**
- Гость входит только по своей ссылке. Поэтому **Выпустить новую** и **Отозвать** закрывают прежний вход полностью.
- Если гостей разрешили уже после рассылки, в приглашении гостевой ссылки нет. Организатор копирует её и передаёт вручную.
- Если администратор выключит **Пускать гостей без учётной записи**, ссылки встреч Outlook перестанут работать, а блок исчезнет из новых приглашений. Если включить настройку снова, прежние ссылки заработают опять.
- Токен гостевой ссылки не пишется в журнал и аудит. Записывается только факт действия.

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Блока для внешних участников нет | гости запрещены или ссылка отозвана | проверьте настройку, нажмите **Выпустить гостевую ссылку** |
| «Гости во встречах Outlook отключены администратором» | настройка выключена | обратитесь к администратору |
| «Встреча закрыта или отменена» | комната закрыта | создайте новую конференцию |
| Гость видит «Встреча ещё не началась» | сотрудник ещё не вошёл | сотрудник открывает комнату |
| «Гостевая ссылка недействительна или отозвана» | ссылку заменили, отозвали или запретили гостей | отправьте новую ссылку |
| Внешний участник открыл ссылку для сотрудников и не может войти | эта ссылка требует учётную запись | передайте ему ссылку из блока для внешних участников |
| Гость получил отказ из своей сети | сервер ограничен разделом **Доверенные подсети** | проверьте исключение для гостевых ссылок |
