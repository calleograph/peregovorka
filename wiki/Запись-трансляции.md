# Запись трансляции

*Для кого: руководитель комнаты, организатор эфира, зритель.*

## Зачем это нужно

Каждый эфир записывается автоматически. Запись остаётся в **Истории**, а зрители могут посмотреть её по той же ссылке, если вы разрешили.

## Когда пригодится

- Часть зрителей не смогла прийти.
- Надо сделать стенограмму и протокол выступления.
- Запись нужно закрыть или открыть уже после мероприятия.

## Что записывается

В файл MP4 попадает общая сцена встречи: показ экрана, доска, выступающие и звук. Это тот же кадр, что видят зрители. Подготовка до **Выйти в эфир** в запись не входит.

Отдельно включать запись не нужно, отключить её нельзя. Перед запуском сервер проверяет службу, свободное место и доступ к каталогу записей. Если записать эфир нельзя, эфир не начнётся, а ведущий увидит причину. Эфира без записи не бывает.

Если в комнате уже шла отдельная видеозапись, с началом эфира она закрывается: запись переходит в эфир.

Качество записи равно качеству эфира. Размер: [Качество эфира](Качество-эфира).

Самый долгий проверенный эфир длился 2 часа. Статус: проверено в ограниченном сценарии (один сервер, 1080p). Эфиры дольше двух часов не проверялись, предел в 12 часов и продление до 48 часов требуют дополнительного тестирования.

## Что потребуется

- Роль руководителя комнаты или администратора, чтобы менять показ записи.
- Завершённый эфир, чтобы открыть запись.
- Место на диске: [Производительность и требования к серверу для трансляций](Производительность-и-требования-к-серверу-для-трансляций).

## Где найти

| Что | Где |
|---|---|
| Запись для сотрудников | **История** → встреча → **Материалы встречи** |
| Показ записи для следующих эфиров | **Настройки комнаты… → Трансляция → Эфир** |
| Показ записи для одного эфира перед запуском | **Настройки эфира** → блок **Этот эфир** |
| Управление прошедшими эфирами | **Настройки комнаты… → Трансляция → Эфиры** |

Параметры блока **Этот эфир** применяются при запуске кнопкой **Начать эфир** в этом же окне. Красная кнопка **Выйти в эфир** берёт значения из настроек комнаты.

## Как показать запись зрителям

1. Откройте **Настройки комнаты… → Трансляция → Эфир**.
2. Отметьте **Показывать запись после завершения эфира**. По умолчанию выключено.
3. Если нужно, отметьте **Разрешить скачивание записи**. По умолчанию выключено. Полностью исключить копирование воспроизводимого видео технически нельзя.
4. Укажите, сколько дней после окончания действует ссылка, поле **Ссылка на запись действует**. По умолчанию 5 дней, предел задаёт администратор, обычно 30.
5. Проведите эфир.
6. Отправьте зрителям ту же ссылку. После эфира они увидят кнопку **Смотреть запись**.

Настройки действуют для новых эфиров. У прошедшего эфира свои значения.

## Как изменить доступ после эфира

Откройте **Настройки комнаты… → Трансляция → Эфиры**. Показаны пять последних эфиров, кнопка **Показать все** откроет остальные.

| Элемент | Что делает |
|---|---|
| **Копировать ссылку** | копирует ссылку этого эфира |
| **Запись и материалы** | открывает встречу в **Истории** |
| **показывать запись** | включает и выключает показ зрителям |
| **скачивание** | разрешает или запрещает скачивание |
| **срок** | меняет срок ссылки |
| **Закрыть доступ** | закрывает просмотр досрочно |
| **Открыть снова** | возвращает доступ |
| **Задать пароль**, **Сменить пароль**, **Убрать пароль** | меняет пароль только этого эфира |

Строка эфира показывает, например, «запись готова», «запись доступна по ссылке до…», «срок ссылки истёк», «доступ закрыт», «· с паролем».

## Какая ссылка что покажет

| Ссылка | Во время эфира | После эфира |
|---|---|---|
| Ссылка этого эфира | прямой эфир | запись этого эфира, если показ разрешён |
| Постоянная ссылка комнаты | ожидание или текущий эфир | последний эфир по его правилам |

Каждый новый эфир получает свою ссылку. Ссылки прошлых эфиров продолжают вести на свои записи.

## Пароль и запись

Пароль зрителя, с которым шёл эфир, действует и для его записи. Кнопка **Смотреть запись** сначала спросит пароль.

Смена пароля в списке **Эфиры** сразу отменяет всё выданное раньше, включая ссылки на файл и докачку. Поле **Пароль зрителя** в настройках комнаты меняет пароль идущего и следующих эфиров, прошедшие оно не меняет.

## Срок ссылки и срок хранения

Это разные сроки. Когда истекает срок ссылки, зрители теряют доступ, а файл остаётся в **Истории**. Файл хранится по [сроку хранения видео](Сроки-хранения-материалов), по умолчанию 30 дней. Если файл удалён раньше, зрители увидят «Запись удалена и больше недоступна.»

## Что получится

После окончания эфира файл закрывается, затем запись появляется в **Истории** и на странице зрителя. Страница зрителя в это время показывает «Запись готовится — обычно несколько минут. Страница обновится сама.»

Запись для зрителей раздаёт основной сервер, не CDN. Для очень большой аудитории выложите её на площадку.

## Если не получается

| Что видно | Почему | Что сделать |
|---|---|---|
| «Запись эфира невозможна: на томе записей меньше N ГБ свободного места…» | мало места | освободите место или сообщите администратору |
| «Запись эфира невозможна: каталог записей недоступен для записи…» | нет доступа к каталогу | сообщите администратору |
| «Запись эфира невозможна: достигнут предел объёма видеозаписей» | достигнута квота | удалите старые записи или увеличьте квоту |
| Зритель видит только «Эфир завершён» | показ записи не разрешён | включите **показывать запись** в списке **Эфиры** |
| «Запись готовится дольше обычного» | файл не готов больше 30 минут | проверьте запись в **Истории** и службу эфира |
| «Запись этого эфира не удалось сохранить.» | эфир прерван, файл не сохранился | [Диагностика трансляций](Диагностика-трансляций) |
| Эфир оборвался, запись остановилась: «На диске сервера заканчивается место» | сервер заранее закрыл файл | освободите место |
