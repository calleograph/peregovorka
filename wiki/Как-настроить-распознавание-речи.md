# Как настроить распознавание речи

*Для кого: администратор сервера.*

## Зачем это нужно

Служба `asr` превращает речь участников в стенограмму. Она работает на вашем сервере и подключается к встрече как участник. Модель — GigaAM v3 e2e RNNT. Звонок от неё не зависит: если служба не готова, разговор идёт, а реплик нет.

Языковая модель для протоколов настраивается отдельно: [Как настроить языковые модели](Как-настроить-языковые-модели).

## Когда пригодится

- В панели «Транскрипция» нет реплик.
- Служба `asr` отмечена красным в **Обзор → Обзор**.
- Реплики появляются с заметной задержкой или дробятся.
- Сервер в закрытой сети и модель не скачать.

## Что потребуется

- Роль администратора для раздела в браузере.
- `sudo` для команд.
- Файлы модели в `DATA_ROOT/models/gigaam`: `v3_e2e_rnnt.ckpt` и `v3_e2e_rnnt_tokenizer.model`. Установщик скачивает их сам.

Сколько встреч распознаёт один сервер, эта страница не утверждает: см. [Производительность и масштабирование](Производительность-и-масштабирование).

## Где найти

**Администрирование → Интеграции → Распознавание речи (ASR)**: активная модель, состояние, устройство, рабочая задержка, тест, параметры деления речи.

## Как это сделать

### Проверить службу

Операции только читают данные. Кроме теста модели, они не нагружают сервер.

1. Откройте раздел и посмотрите **Состояние** и **Активная модель**.
2. Нажмите **Протестировать модель**. Тест использует встроенный файл WAV и показывает скорость и качество.
3. В терминале: `sudo scripts/logs.sh asr --tail 200`.

Во время встреч тест блокируется, чтобы не мешать распознаванию.

### Подготовить модель ⚠

**Назначение.** Скачать файлы, если их нет, и исправить права на них.

```bash
cd /opt/peregovorka
sudo scripts/models.sh
sudo scripts/ctl.sh restart asr
```

**Последствия.** Команда работает только внутри `DATA_ROOT/models`. Загрузка продолжается после обрыва. Уже готовая модель заново не качается. Перезапуск `asr` приостанавливает стенограмму идущих встреч.

Источник — `GIGAAM_MODEL_BASE_URL`. Если нужен прокси, задайте `HTTPS_PROXY` и `NO_PROXY` для команды.

### Подготовить модель в закрытой сети ⚠

1. На другом компьютере скачайте оба файла.
2. Перенесите их на сервер в один каталог.
3. Выполните:

   ```bash
   sudo scripts/models.sh --from-dir /путь/к/gigaam
   sudo scripts/ctl.sh restart asr
   ```

Размер файла проверяется, а страница HTML вместо файла отвергается и сохраняется как `*.failed`. Контрольные суммы сверяются, только если заданы `GIGAAM_CKPT_SHA256` и `GIGAAM_TOKENIZER_SHA256` в `.env`.

У `models.sh` есть параметры `--env`, `--model`, `--from-dir`, `--skip-full`.

### Выбрать модель

Если установлено несколько моделей, нажмите **Сделать активной** у нужной. Перезапуск не нужен: прежняя модель работает, пока новая загружается. **Сравнить установленные модели** показывает скорость и точность, для этого нужны минимум две модели. Изменение пишется в журнал аудита.

### Настроить деление речи на реплики

В разделе есть форма **Параметры деления речи (VAD)**. Изменения действуют на новых участников без перезапуска службы. Пустое поле берёт значение из `.env`.

| Поле | Что меняет |
| --- | --- |
| **Пауза, после которой реплика считается законченной** | главный параметр задержки: меньше — быстрее, но фразы дробятся. По умолчанию 700 мс |
| **Минимальная длина речи** | короче отбрасывается как шум. По умолчанию 250 мс |
| **Запас вокруг речи (до и после)** | защищает начало и конец слов. По умолчанию 200 мс |
| **Максимальная длина одной реплики** | длинная речь режется на части, не больше 25 с. По умолчанию 20 с |
| **Порог вероятности речи** | выше — меньше ложных срабатываний, но тихая речь теряется. По умолчанию 0,5 |

### Подобрать число потоков ⚠

**Назначение.** Снизить задержку и не отнимать процессор у звонков.

**Условия.** Выбирайте время без встреч. Тест загружает вторую копию модели, нужно примерно 1–2 ГБ памяти сверх рабочей.

1. Подготовьте запись настоящей русской речи на 5–15 секунд.
2. Сравните варианты. Рабочая служба не останавливается.

   ```bash
   sudo scripts/asr-bench.sh --wav /путь/речь.wav --threads 2,4
   ```

3. Запишите лучшее значение в `.env`: `ASR_CPU_THREADS`, при необходимости `ASR_INTEROP_THREADS`.
4. Примените: `sudo scripts/ctl.sh restart asr`.

`ASR_CPU_THREADS × ASR_MAX_CONCURRENT_INFERENCE` не должно превышать число ядер. Значение `0` занимает все ядра и подходит только выделенному серверу. Мастер для общего сервера ставит половину ядер.

Выбирайте по задержке, а не по загрузке процессора. Параметр `--synthetic` проверяет только работоспособность.

### Использовать видеокарту ⚠

Задайте `ASR_DEVICE=cuda` и `ASR_TORCH_INDEX_URL` с индексом CUDA, установите NVIDIA Container Toolkit и пересоберите образ: `sudo scripts/rebuild.sh asr`. `preflight.sh` откажет, если среда NVIDIA не найдена. На настоящем оборудовании этот путь не подтверждён.

## Что получится

- В разделе модель активна, состояние без ошибок.
- `/api/v1/health/ready` показывает готовность `asr`.
- На пробной встрече реплики появляются в панели «Транскрипция».

## Если не получается

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| `FileNotFoundError` на `.ckpt` | нет файла модели | `sudo scripts/models.sh` |
| `PermissionError` на `/models/...` | контейнер не читает файлы | `sudo scripts/models.sh`, права исправятся внутри каталога моделей |
| Файл `*.failed` | вместо модели пришла страница прокси или обрывок | проверьте доступ к адресу, повторите |
| Служба красная 1–2 минуты после запуска | модель загружается | подождите |
| Реплик нет, служба зелёная | транскрибация в комнате остановлена или полное сквозное шифрование | [Запись и транскрибация в комнате](Запись-и-транскрибация-в-комнате) |
| Задержка растёт | мало потоков или очередь | подберите потоки, смотрите **Рабочая задержка распознавания** |

Подробнее — [Диагностика](Диагностика#нет-стенограммы).
