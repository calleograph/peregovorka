Peregovorka для Linux

Видеовстречи, чаты и материалы вашей организации в отдельном окне. Версия @VERSION@ для Ubuntu 22.04 и 24.04, Debian 12 и 13 (x86_64 и ARM64). Обновления приходят штатно: apt update и apt upgrade или «Обновление программ».

Установка одной командой

curl -fsSL https://calleograph.github.io/peregovorka-apt/install.sh | sudo sh

Сценарий проверит систему, скачает ключ репозитория и сверит его отпечаток, подключит репозиторий и установит приложение. Запуск — «Peregovorka» в меню приложений или команда peregovorka.

Или: скачать пакет

Скачайте @DEB_NAME@ и установите — репозиторий для обновлений подключится сам:

sudo apt install ./@DEB_NAME@

Вручную, с проверкой отпечатка ключа

curl -fsSLo /tmp/peregovorka.gpg https://calleograph.github.io/peregovorka-apt/peregovorka-archive-keyring.gpg
gpg --show-keys /tmp/peregovorka.gpg      # отпечаток должен быть @FINGERPRINT_SPACED@
sudo install -m 0644 /tmp/peregovorka.gpg /usr/share/keyrings/peregovorka-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/peregovorka.sources <<EOF
Types: deb
URIs: https://calleograph.github.io/peregovorka-apt
Suites: stable
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /usr/share/keyrings/peregovorka-archive-keyring.gpg
EOF
sudo apt update && sudo apt install peregovorka

Отпечаток ключа репозитория: @FINGERPRINT_SPACED@

Обновление, удаление

Обновитьsudo apt update && sudo apt upgrade или «Обновление программ». Работающее приложение сообщит, что нужен перезапуск.
Удалить приложениеsudo apt remove peregovorka — репозиторий остаётся, поставить снова можно командой sudo apt install peregovorka.
Удалить с репозиториемsudo apt purge peregovorka — убирает и источник APT, и ключ.
Вернуть прежнюю версиюsudo apt install peregovorka=X.Y.Z --allow-downgrades
Ваши данные~/.config/Peregovorka — пакет их не удаляет.

Администраторам

Корпоративные политики (серверы, разрешённые домены, автозапуск) — /etc/peregovorka/policy.json; автоматические обновления через unattended-upgrades — по выбору администратора; не подключать репозиторий при установке пакета — PEREGOVORKA_REPO=off в /etc/default/peregovorka. Подробно — руководство по Linux.

Подпись репозитория проверяется APT при каждом обновлении. Если apt update сообщает об ошибке подписи — не отключайте проверку, а сообщите администратору: см. раздел «Диагностика» руководства.
