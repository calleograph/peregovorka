# Peregovorka для Windows — история изменений

Версии клиента независимы от версий сервера (совместимость — по протоколу приложения). Нужен сервер Peregovorka 0.37.0 или новее.

## 1.0.0 — первый выпуск

### Новые возможности
- Приложение для Windows 10/11: вход в организацию, все разделы Peregovorka — встречи, чаты, история, материалы, доска, администрирование.
- Несколько организаций одновременно: у каждой свой вход, чаты и уведомления; встреча в одной не прерывается при работе в другой.
- Вход сохраняется между запусками и после перезагрузки Windows — без хранения пароля.
- Работа в трее, автозапуск, уведомления Windows с переходом к нужной переписке или встрече, «Не беспокоить», скрытие текста.
- Ссылки на встречи открываются в приложении.
- Показ экрана или окна с выбором и индикатором «Идёт показ экрана · Остановить».
- Раздел «Диагностика» с отчётом для службы поддержки (без паролей и переписки).

### Для администраторов
- Установщики EXE (для пользователя без прав администратора или для всех) и MSI (тихая установка, преднастройка организаций и политик).
- Групповые политики (ADMX): организации, запрет сторонних серверов, домены, автозапуск, обновления, уведомления, прокси.
- Обновления только подписанные ключом издателя; при установке из MSI версию меняет администратор.
