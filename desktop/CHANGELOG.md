# Peregovorka для Windows — история изменений

Версии клиента независимы от версий сервера (совместимость — по протоколу приложения). Нужен сервер Peregovorka 0.37.0 или новее.

## 1.2.0

### Новые возможности
- **Новое оформление «Стекло»:** светлый воздушный интерфейс с мягкими волнами и полупрозрачными панелями — и в окнах организаций, и в самой оболочке приложения (приветствие, настройки, вкладки организаций). Выбрать другую тему можно в «Личный кабинет → Оформление» или кнопкой «Тема» вверху справа; режим «как в Windows» работает по-прежнему.
- Слева — панель разделов: «Переговорки», «История», «Чаты» и «Администрирование»; список переговорок переключается между плиткой и списком, есть поиск и фильтры. Оформление и разделы те же, что в браузере (нужен сервер Peregovorka 0.39.1 или новее; с более ранним сервером приложение работает по-прежнему).

## 1.1.2

### Улучшения
- **Автозапуск при новой установке включён: приложение стартует вместе с Windows свёрнутым в системный трей** — уведомления из подключённых организаций приходят сразу после входа в Windows, окно само не открывается, камера и микрофон не включаются. Это значение по умолчанию только для нового профиля: у тех, кто уже пользуется приложением (в том числе сознательно отключил автозапуск), настройка не меняется. Отключить или выбрать запуск с открытым окном можно в «Настройки → Общие». Если автозапуск задан политикой организации, действует он.
- В журнале приложения фиксируются сбои загрузки картинок страницы (значки комнат, аватарки): код ответа и путь без параметров — это помогает администратору разобраться, если значок не отображается.

### Исправления
- Окно чатов и общая доска: кнопка закрытия — в правом верхнем углу окна (изменение интерфейса сервера Peregovorka 0.38.1, доступно после его обновления).
- Диктовка в чатах: смена звуковых устройств в Windows больше не обрывает запись (то же — в интерфейсе сервера 0.38.1).

## 1.1.0

### Исправления
- **После установки вместо мастера подключения было пустое окно с надписью «not found».** Приложение не находило собственные файлы окна на Windows. Теперь при первом запуске сразу открывается приветствие и мастер подключения — в том числе без интернета.
- Если окно приложения всё же не отрисуется, показывается сообщение с кнопками «Повторить», «Папка журналов» и «Выйти» — пустого окна без управления больше не бывает.

### Новые возможности
- Мастер подключения по шагам: «Добро пожаловать в Peregovorka» → адрес сервера («Проверить подключение», «Продолжить», «Назад») → вход учётной записью организации.
- Обновление новым установщиком поверх установленной версии: «Проверить обновления» → номер версии и что нового → «Скачать обновление» → «Установить обновление»; приложение закрывается, обновляется и запускается снова — организации, вход и настройки сохраняются. Уведомление «Доступна новая версия Peregovorka», если ничего не делать самому.
- «Настройки → Общие → Оформление»: как в Windows, светлое или тёмное.

### Улучшения
- Загрузка обновления повторяется после обрыва связи, перед загрузкой проверяется свободное место; если установить автоматически нельзя — кнопка «Скачать установщик вручную».
- «Диагностика» показывает, в порядке ли файлы программы и защищён ли сохранённый вход.

### Для администраторов
- Установщик EXE не ставится поверх корпоративной установки MSI (код выхода 2) — двух копий программы не бывает.
- Корпоративное зеркало обновлений (политика `UpdateUrl`) может хранить установщик рядом с манифестом, в том числе корпоративный канал сервера Peregovorka 0.38.0.
- Подписанные корпоративные сборки EXE/MSI с настройками организации — сервер Peregovorka 0.38.0, docs/DESKTOP_SIGNING.md.

## 1.0.0 — первый выпуск

### Новые возможности
- Приложение для Windows 10/11: вход в организацию, все разделы Peregovorka — встречи, чаты, история, материалы, доска, администрирование.
- Несколько организаций одновременно: у каждой свой вход, чаты и уведомления; встреча в одной не прерывается при работе в другой.
- Вход сохраняется между запусками и после перезагрузки Windows — без хранения пароля.
- Работа в трее, автозапуск, уведомления Windows с переходом к нужной переписке или встрече, «Не беспокоить», скрытие текста.
- Ссылки на встречи открываются в приложении.
- Показ экрана или окна с выбором и индикатором «Идёт показ экрана · Остановить».
- Раздел «Диагностика» с отчётом для службы поддержки (без паролей и переписки).

### Для администраторов
- Установщики EXE (для пользователя без прав администратора или для всех) и MSI (тихая установка, преднастройка организаций и политик).
- Групповые политики (ADMX): организации, запрет сторонних серверов, домены, автозапуск, обновления, уведомления, прокси.
- Обновления только подписанные ключом издателя; при установке из MSI версию меняет администратор.
