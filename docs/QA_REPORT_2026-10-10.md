# Отчёт о проверках: ночь 9–10 октября 2026 (версии 0.8.6 – 0.8.10)

Разделение: **реально** (запущено в браузере/на сервере, наблюдался результат) · **тестом** (автотест в репозитории) · **кодом** (чтение кода/конфигурации) · **не удалось**.

## Стенд
Настоящий `livekit-server` 1.13.7 (локально), backend со стендовыми заменами (каталог пользователей, Redis в памяти, SQLite; реплики стенограммы подсовываются вместо ASR, LLM — заглушка на HTTP), dev-сервер frontend, до трёх браузеров Edge с поддельными камерой и микрофоном. Сценарии лежат в `tests/live/` (README рядом). Всё на одной машине (localhost): сетевые задержки, NAT, реальные динамики и реальные окна запроса разрешений не проверялись.

| Журнал backend | за прогоны только шум Windows (`_ProactorBasePipeTransport`), приложение ошибок и предупреждений не писало |

## Проверено тестом / кодом
Frontend: 231 тест, `tsc` (production и тесты), сборка, охранные тесты (порядок хуков комнаты, список событий). Backend: новые тесты ролей, аватарок, путей, прав завершения встречи; наборы доступа/гостей/стенограмм (49 тестов), ролей (18), комнаты/SIP/руки/временные комнаты (55 тестов, после правки правила «завершить для всех»). Аудит безопасности этапа 1 — `docs/SECURITY_AUDIT.md`. CI для 0.8.9 — полностью зелёный, страница релиза опубликована.

## Не удалось проверить
Draw.io/доска (в dev нет `/drawio`), запись аудио (нужен ASR-мост), ASR и реальная стенограмма, Firefox и Safari, реальные окна запроса разрешений, обновление через updater на реальном сервере, нагрузка >3 участников, реальная сеть, настоящий SMTP, Bitrix24 и публичный API (не выпускались; работа над API — в отложенном stash).

## Рекомендуется проверить на реальном сервере
1. Ввод в чат сразу после входа в комнату, пока доска только предзагружается (фокус; защита — `inert`).
2. Живая встреча на 3+ человека с реальной стенограммой: задержка «речь → текст».
3. Поведение при обновлении 0.8.5 → 0.8.10 (0.8.5 не использовать).
4. Окна запроса разрешений в Яндекс.Браузере/Chrome: положение стрелки-подсказки.
5. Правило «завершить для всех» в ваших комнатах с руководителями (теперь только руководитель/администратор).
