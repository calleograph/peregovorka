# Приложение Peregovorka для Android

Предварительная версия (0.1.x). Исходники — `mobile/android/`, выпуски — на странице релизов GitHub с тегами `android-vX.Y.Z`.
Версия приложения своя, она не совпадает с версией сервера.

## Что умеет

| Область | Состояние |
| --- | --- |
| Добавление серверов, переключение, переименование, удаление | работает; проверка адреса и совместимости |
| Вход | страницей самого сервера в приложении (домен, TOTP, CAPTCHA, SSO — как в браузере); после входа устройство запоминается («доверенное устройство», срок задаёт администратор) |
| Главная: предстоящие встречи, переговорные | работает |
| Конференция: звук, видео, камера, рука, чат, участники, чужая демонстрация экрана | работает на LiveKit Android SDK |
| Звук при свёрнутом приложении и блокировке экрана | служба переднего плана (тип «микрофон») |
| Календарь, чаты, история, личный кабинет, администрирование | страницы сервера внутри приложения (не отдельные мобильные экраны); собственная навигация сайта внутри приложения скрыта, разделы переключает приложение; нужен сервер 0.49.6+ (на более старых работает со своей навигацией сайта) |
| Уведомления о встречах и сообщениях | **нет** (см. «Ограничения») |
| Демонстрация своего экрана, гостевой вход по ссылке | **нет** (гостевая ссылка открывается в браузере) |
| iPhone / iPad | **нет**, версия для iOS не начата |

## Установка

1. Скачайте `Peregovorka-<версия>-android.apk` со страницы выпуска, сверьте SHA-256 из `SHA256SUMS.txt`.
2. Разрешите установку из этого источника (Настройки → Приложения → Особый доступ → Установка неизвестных приложений).
3. Откройте приложение, нажмите «Добавить сервер», введите адрес вашей Peregovorka вида `https://meeting.example.org`.

Файл с `debugkey` в имени подписан временным ключом сборки: он годится для проверки, но следующая сборка с другим ключом не установится поверх — сначала удалите прежнюю. Выпуск с постоянным ключом организации — см. «Сборка».

## Экранная клавиатура и «Назад»

- При появлении клавиатуры содержимое сжимается до свободной области (`imePadding`), нижняя панель разделов скрывается, поле ввода остаётся над клавиатурой. Для страниц сайта то же делает уменьшение области WebView, а в самом сайте (мобильный браузер) — `interactive-widget=resizes-content` в метатеге viewport.
- Кнопка «Назад» в конференции не сворачивает приложение: закрывает открытую панель (чат, участники), затем спрашивает «Выйти из конференции?». Свернуть — жест «Домой»; звук продолжает служба переднего плана, камера выключается и возвращается при возврате.
- Если приложение ушло с переднего плана неожиданно, в журнале устройства (`adb logcat -s PGLIFE`) остаются строки `onStop/onDestroy finishing=… configChange=… call=…`: они показывают, завершилась ли Activity, сменилась ли конфигурация или это обычное сворачивание.

## Безопасность

- Только HTTPS. Недоверенный сертификат система отвергает, обхода «принять любой» нет. Корпоративные центры сертификации, установленные на устройстве (в том числе через MDM), принимаются.
- Пароль приложение не видит и не хранит. Сессия и токен доверенного устройства шифруются ключом Android Keystore (AES-GCM; ключ запись → сервер входит в AAD, секреты разных организаций не читаются друг другом). В облачные копии Android эти данные не попадают.
- Страницы сервера во встроенном окне открываются только с адреса выбранного сервера, чужие ссылки уходят во внешний браузер.
- Ссылка `peregovorka://open?url=…` не несёт команд: из неё берутся сервер и путь из белого списка.
- Выход отзывает токен доверенного устройства на сервере (`/api/v1/desktop/forget`) и стирает локальные секреты. Администратор может отозвать доступ на сервере.

## Ограничения Android, о которых нужно знать

- Камера в фоне недоступна: при сворачивании приложение выключает камеру и возвращает при возврате; звук продолжается.
- Уведомления о встречах и сообщениях требуют сервиса доставки (FCM — сторонний сервис Google, требует проекта Firebase и ключа организации). Пока не сделаны: приложение ничего не отправляет в сторонние сервисы.
- Сквозное шифрование (E2EE) комнат включено в клиенте, но совместимость с ключом веб-клиента на устройстве не проверялась: если в такой комнате вместо видео чёрные плитки, сообщите.

## Сборка

Нужны JDK 21 и Android SDK (платформа 37, build-tools 37). Из каталога `mobile/android`:

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug      # тесты и линт
./gradlew :app:assembleDebug                         # APK для проверки
./gradlew :app:assembleRelease                       # APK; подписан отладочным ключом, если ключ организации не задан
./gradlew :app:bundleRelease                         # AAB для Google Play (нужен ключ)
```

Ключ организации не хранится в Git. Укажите его в окружении (`PEREGOVORKA_KEYSTORE`, `PEREGOVORKA_KEYSTORE_PASSWORD`, `PEREGOVORKA_KEY_ALIAS`, `PEREGOVORKA_KEY_PASSWORD`) или в локальном файле `mobile/android/signing.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`; файл в `.gitignore`). Создание ключа: `keytool -genkeypair -v -keystore peregovorka.jks -alias peregovorka -keyalg RSA -keysize 3072 -validity 10000`. **Сохраните файл ключа и пароли в надёжном месте**: потеряв ключ, обновить приложение у пользователей поверх уже нельзя.

В CI (`.github/workflows/android.yml`) ключ берётся из секретов репозитория `ANDROID_KEYSTORE_B64` (base64 файла `.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Выпуск — тег `android-vX.Y.Z`.

## Устройство

Kotlin, Jetpack Compose, LiveKit Android SDK (официальная библиотека LiveKit), OkHttp. Протокол с сервером — тот же REST API, что у веб-клиента и клиента для Windows (`/api/v1/desktop/info`, `/trust`, `/resume` для сведений о сервере и доверенного устройства). Сервер не менялся ради приложения.
Версии библиотек закреплены в `mobile/android/gradle/libs.versions.toml`. Репозиторий JitPack разрешён только для одной группы (`com.github.davidliu`, переключение динамика/Bluetooth — зависимость LiveKit).

| Проверка | Как |
| --- | --- |
| Разбор адресов и ссылок, клиент API (совместимость сервера, ошибки, обновление сессии по токену, отзыв токена, выход) | автоматические тесты на JVM (`./gradlew :app:testDebugUnitTest`) |
| Keystore (шифрование секретов, изоляция серверов), холодный запуск интерфейса | автоматические тесты на эмуляторе Android 14 в CI |
| Сборка APK, R8, линт | CI |
| Экранная клавиатура (экран добавления сервера, окно входа с паролем, страница чатов в WebView), вход в конференцию с системными запросами разрешений, отказ в разрешениях, камера и микрофон, поворот экрана, «Назад», уход в фон и возврат, подключение к настоящему LiveKit | автоматические тесты на эмуляторах Android 10, 14 и 16 в CI (`KeyboardTest`, `JoinFlowTest`); страница чатов в этих тестах — копия по структуре, а не настоящий сайт |
| Звонок с реальной камерой и микрофоном, Bluetooth-гарнитура, смена сети, блокировка экрана, входящий вызов, батарея | **не проверено**: нужен реальный телефон |
| Вход с доменной учётной записью, TOTP, CAPTCHA в приложении | **не проверено**: страница входа — та же, что проверена в браузере, но в приложении на устройстве не запускалась |
| Работа против настоящего сервера Peregovorka | **не проверено** |
