# Приёмочные испытания приложения Windows на настоящих компьютерах

Эти проверки выполняет человек на реальных Windows 10 22H2 и Windows 11 23H2/24H2 (чистая установка или типовой образ организации). Автоматические
испытания (CI на виртуальной Windows Server 2025, Linux-стенд) их не заменяют: там нет домена, настоящих устройств, нескольких мониторов и SmartScreen.
Результат каждой строки — «пройдено / не пройдено / не применимо» с номером сборки, версией Windows, масштабом экрана и снимком при ошибке.
Отчёт «Диагностика → Сохранить отчёт» прикладывается к каждой ошибке (в нём нет паролей, токенов и переписки).

## Стенд

* Сервер Peregovorka с действующим сертификатом HTTPS организации и вход через AD (и локальная учётная запись для проверки).
* Компьютеры: Windows 11 (ноутбук 150 % и внешний монитор 100 %), Windows 10 (100 %), компьютер в домене под групповой политикой.
* Устройства: встроенная камера, USB-камера, USB-гарнитура, Bluetooth-гарнитура, второй монитор.
* Outlook (классический или новый) с надстройкой Peregovorka.

## 1. Установка и первый запуск

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 1.1 | Скачать EXE, проверить SHA-256 (`Get-FileHash`) и подпись (`Get-AuthenticodeSignature`) | совпадает с `SHA256SUMS.txt`; Valid (для тестовой — подпись цела, издатель не доверен) |
| 1.2 | Запуск EXE: окно SmartScreen | подписанная УЦ — издатель указан; тестовая — «Неизвестный издатель» (ожидаемо) |
| 1.3 | Установка EXE для пользователя без прав администратора | без UAC, ярлыки в «Пуске» и на рабочем столе |
| 1.4 | Первый запуск | **«Добро пожаловать в Peregovorka»**, не пустое окно и не `not found` |
| 1.5 | Первый запуск без сети (Wi-Fi выключен) | мастер открыт, «Проверить подключение» — понятная ошибка, «Настройки» открываются |
| 1.6 | Адрес с опечаткой / `http://` / сервер с недоверенным сертификатом | «Сервер не найден» / «нужен https» / «Сертификат не доверен» + кем выдан; окно остаётся в мастере |
| 1.7 | Длинное название организации и длинный адрес | без обрезки кнопок и горизонтальной прокрутки |
| 1.8 | Чистая установка MSI (`msiexec /i … /qn`) с `SERVERS=…` | организация уже есть, добавление по политике |
| 1.9 | EXE поверх установленного MSI | отказ с объяснением, вторая копия не ставится |

## 2. Вход и организации

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 2.1 | Вход доменной учётной записью (логин, `ДОМЕН\логин`, `логин@домен`) | вход, интерфейс сервера |
| 2.2 | Вход с 2FA (TOTP) | код запрашивается, вход |
| 2.3 | Перезапуск приложения и перезагрузка Windows | вход без пароля (сохранённый вход) |
| 2.4 | Смена пароля в AD / отключение учётной записи | при следующем запуске — форма входа, не мастер |
| 2.5 | Вторая организация (другой сервер) | отдельный вход, переключение без перезагрузки, встреча в первой не прерывается |
| 2.6 | Удаление организации | выход, данные этой организации стёрты, другая работает |

## 3. Встречи, устройства, показ

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 3.1 | Встроенная и USB-камера, переключение во встрече | изображение, переключение без перезахода |
| 3.2 | USB-гарнитура, Bluetooth-гарнитура (подключить во время встречи, отключить) | звук идёт в выбранное устройство, после отключения — на устройство по умолчанию |
| 3.3 | Запрет камеры/микрофона в «Конфиденциальность Windows» | понятная подсказка, в «Диагностике» — «запрещено в параметрах» |
| 3.4 | Показ экрана, показ окна, «Звук компьютера» | собеседники видят и слышат; индикатор «Остановить» поверх окон |
| 3.5 | Два монитора с разным масштабом: перенос окна, показ второго экрана | окно не «улетает», текст чёткий, правильный экран |
| 3.6 | Сворачивание в трей во время встречи | встреча продолжается, индикатор встречи |

## 4. Трей, уведомления, автозапуск, ссылки

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 4.1 | Новое сообщение при свёрнутом окне | уведомление Windows; нажатие открывает нужный чат нужной организации |
| 4.2 | «Не беспокоить» (приложения) и «Фокусировка» Windows | уведомления не показываются, непрочитанные копятся |
| 4.3 | Автозапуск «свёрнутым в трей», перезагрузка | значок в трее, окно не открыто, уведомления приходят |
| 4.4 | Меню трея: Открыть, Чаты, Проверить обновления, Выйти | действия выполняются; «Выйти» во время встречи спрашивает |
| 4.5 | Приглашение из Outlook (ссылка `https://…/meet/…` и `peregovorka://`) | открывается встреча в приложении (не в браузере) |

## 5. Обновление и удаление

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 5.1 | Предыдущая версия → «Проверить обновления» | номер и список изменений, «Скачать обновление» |
| 5.2 | Загрузка, разрыв сети во время загрузки | повтор, понятная ошибка, «Скачать установщик вручную» |
| 5.3 | «Установить обновление» | приложение закрывается, обновляется и запускается снова; организации, входы, настройки на месте |
| 5.4 | «Установить» во время встречи | недоступно до конца встречи |
| 5.5 | Установка «для всех пользователей» обычным пользователем | запрос UAC или понятная ошибка, программа не повреждена |
| 5.6 | Обновление MSI новым MSI (GPO/SCCM) | одна запись в «Программах и компонентах», политики сохранены |
| 5.7 | Удаление EXE (с вопросом о данных) и MSI | программа, автозапуск, `peregovorka://` удалены; данные — по выбору |

## 6. Интерфейс

На каждом экране приложения (приветствие, сервер, ошибки, настройки — все вкладки, диагностика, выбор экрана, индикатор) при масштабе 100, 125, 150,
175, 200 %, в светлой и тёмной теме Windows, при окне 800×520 и развёрнутом: ровные отступы, одна высота кнопок и полей, нет обрезанного текста
и горизонтальной прокрутки, фокус клавиатуры виден, всё доступно с клавиатуры (Tab, Enter, Esc).

## 7. Корпоративная подпись (стенд организации)

| № | Проверка | Ожидаемо |
| --- | --- | --- |
| 7.1 | Агент на узле домена (`Enroll`, `Install`), перезагрузка узла | узел «на связи» в разделе администрирования |
| 7.2 | Сертификат AD CS по шаблону Code Signing, «Проверить» | назначение, цепочка доверена, пробная подпись выполнена |
| 7.3 | Корпоративный выпуск, установка на компьютере сотрудника после GPO с «Доверенными издателями» | `Valid`, SmartScreen показывает издателя организации |
| 7.4 | Замена сертификата (тот же издатель), обновление ранее установленного клиента | обновление принимается |
