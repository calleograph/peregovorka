# Надстройка Outlook: конференция Peregovorka в приглашении

Организатор создаёт встречу в календаре Outlook, нажимает **«Добавить конференцию»** (группа «Peregovorka» на ленте окна встречи), и в приглашение автоматически попадают ссылка и краткая инструкция. Участники получают обычное приглашение Outlook и подключаются по ссылке; страница ссылки до начала показывает название, время и обратный отсчёт, а за N минут до начала открывает вход.

Интеграция выключена по умолчанию: «Администрирование → Доступ и каталог (LDAP) → Надстройка Outlook» (рядом с «Правкой профиля», CAPTCHA и двухфакторной защитой).

## Что нужно

* Публичный адрес Peregovorka **по HTTPS** с действующим сертификатом (Outlook не загружает надстройки по HTTP). Задаётся в настройке «Публичный адрес Peregovorka для надстройки» (пусто — берётся публичный адрес приложения).
* Outlook с поддержкой Mailbox 1.3 и функции «поставщик онлайн-встреч»: Outlook в браузере, новый Outlook для Windows, классический Outlook для Windows и Mac с подпиской Microsoft 365 ([описание функции Microsoft](https://learn.microsoft.com/en-us/office/dev/add-ins/outlook/online-meeting)). **Важно:** кнопка поставщика онлайн-встреч появляется в окне встречи только у надстроек, установленных **администратором** (Microsoft 365 admin center или Exchange), а не пользователем.
* Почтовая инфраструктура: Microsoft 365 / Exchange Online или локальный Exchange 2016+ (надстройки Office Exchange поддерживает при доступе клиентов к адресу Peregovorka). Microsoft Graph не нужен: ссылка создаётся собственным API Peregovorka.

## Установка (администратор Microsoft 365)

1. В Peregovorka включите интеграцию, задайте публичный HTTPS-адрес, при необходимости — группы, которым разрешено создавать конференции, время входа и срок хранения завершённых комнат. Сохраните.
2. Нажмите «Скачать манифест надстройки» (или откройте `https://<сервер>/api/v1/outlook/manifest.xml`).
3. Microsoft 365 admin center → **Settings → Integrated apps → Upload custom apps** (Office Add-in) → загрузите файл манифеста → выберите пользователей или группы → подтвердите. Распространение занимает до 24 часов.

## Установка (локальный Exchange)

Exchange admin center → **Organization → Add-ins → Add from file** (или командлет `New-App -FileData ([System.IO.File]::ReadAllBytes("manifest.xml")) -OrganizationApp`), затем включите для нужных пользователей. Клиентам Outlook должен быть доступен адрес Peregovorka по HTTPS.

## Как работает

1. Первое нажатие: открывается маленькое окно входа Peregovorka (страница `/outlook/auth.html` на вашем сервере — те же пароль, двухфакторная защита и CAPTCHA, что и в браузере). После входа надстройка получает токен (срок задаётся настройкой «Срок действия входа», по умолчанию 7 суток; токен годится только для методов `/api/v1/outlook/*`).
2. Надстройка отправляет название, начало, окончание и признак серии. Ключом события служит случайная строка, сохранённая в пользовательских свойствах встречи: **повторное нажатие, несохранённый черновик и удалённая из текста ссылка** возвращают ту же комнату вместо дубля, а блок со ссылкой в теле встречи заменяется, а не дублируется.
3. Создаётся временная запланированная комната `ol-<код>` (код 20 знаков). Создатель — руководитель комнаты; войти по ссылке может любой вошедший сотрудник (и гости, если включено «Пускать гостей…»).
4. **Окно входа:** до `начало − N минут` по ссылке `/m/<код>` показываются название, дата, время в часовом поясе читателя и обратный отсчёт; вход в комнату сервер не пускает (код `too_early`). Когда время пришло, страница сама открывает комнату — сначала проверка камеры и микрофона.
5. Время хранится в UTC; часовой пояс показывается по браузеру участника.
6. После встречи комната закрывается автоматически (идущая встреча — по общим правилам временных комнат, пустая — через «Держать комнату открытой после планового окончания»). Завершённые комнаты без встреч удаляются через «Хранить завершённые комнаты без встреч»; комнаты со встречами остаются вместе с материалами.

## Перенос, изменение и серии

* **Перенос времени и смена названия:** организатор снова нажимает «Добавить конференцию» в изменённой встрече — время и название обновляются, ссылка остаётся прежней. Если комната была закрыта или отменена, а встреча ещё впереди, она возвращается в работу. Идущую встречу перенос не прерывает.
* **Повторяющиеся события:** для серии создаётся одна постоянная ссылка без календарных ограничений (вход открыт всегда, комната живёт до двух лет или до закрытия владельцем); расписание ведёт календарь Outlook.
* **Отмена:** надстройка получает отмену только от самого сервера (владелец или администратор закрывает комнату в Peregovorka); Outlook не сообщает надстройке об удалении встречи. Отменённая встреча по ссылке показывает «Встреча отменена».

## Ограничения и что не проверено

* Не проверено в настоящем Outlook и Exchange (нужен тенант Microsoft 365 или Exchange): манифест прошёл официальный валидатор `office-addin-manifest`, а команда надстройки и окно входа выполнены в настоящем браузере с имитацией Office.js на настоящем сервере.
* Автоматическая синхронизация при изменении времени без нажатия кнопки (события `OnAppointmentSend`, Smart Alerts) и обработка отмены/удаления встречи не реализованы: требуют Mailbox 1.12 и событийной активации, которые нельзя проверить без настоящего Outlook.
* Мобильные клиенты Outlook не поддержаны (манифест только для настольных и браузерных клиентов).
* Кнопки «Join/Chat» в карточке встречи Outlook доступны только надстройкам из Microsoft Marketplace; ссылка работает как обычная.
