# Плотность интерфейса: правила и проверка

Правила, по которым выровнены экраны «Вход в комнату», «Переговорки», «История» и страница входа (0.8.4).

## Вход в комнату (pre-join)
* Помещается на одном экране без вертикальной прокрутки страницы: 1920×1080, 1600×900, **1366×768** — в том числе в худшем случае (камера с превью, комната с паролем).
* Два столбца: слева описание, «Перед входом» (карточки рядом: микрофон / стенограмма), предупреждение о записи; справа проверка оборудования карточками 2×2 (разрешения · микрофон · камера · динамики).
* Нижняя панель (пароль, «Войти в переговорку», «Назад к списку») закреплена внутри карточки и видна всегда; если содержимого больше, прокручивается только средняя часть карточки.
* Уже 860 px — один столбец; уже 520 px — карточки в колонку, кнопки на всю ширину.

## Список комнат
* «Плитка» — основной вид; название в два ряда с подсказкой, ровные высоты.
* «Компактно» — CSS Grid из одинаковых карточек: 1 колонка (<640 px), 2 (640+), 3 (1000+), 4 (1720+). В карточке: название, статус/число участников, короткий технический id, лимит, кнопки ссылок (сотрудникам / гостям — зелёная и красная, с подсказками), «⋯» (то же меню, что по правой кнопке), «Войти».

## История встреч
* Участники — построчно, только ФИО, первые четыре (организатор и руководители — первыми и без должностей), остальные — «+ N участников». Полный список — подсказкой при наведении.
* Отдельная колонка «Кол-во». Высота строки не растёт вместе со встречей (максимум пять строк в ячейке).
* До 760 px таблица становится карточками.

## Страница входа
Фон — спокойная сетка из линий и точек (Canvas, без библиотек), реагирует на курсор (узлы расступаются), через несколько секунд после последнего движения затихает и перестаёт рисоваться. Не рисуется после входа в приложение, при `prefers-reduced-motion` — один статичный кадр, на слабых устройствах реже сетка и меньше кадров, во вкладке в фоне не работает.

## Как проверять
Стенд `scripts`-независимый: снимки и замеры (прокрутка страницы, видимость кнопки, число колонок и высоты карточек компактного вида, высота строк истории) делались через Edge DevTools на тестовых данных (14 комнат; встречи на 1, 2, 3, 10, 34, 130 участников; длинные ФИО и названия). Снимки «до / после» — `docs/img/ux/`.
