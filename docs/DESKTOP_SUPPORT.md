# Peregovorka для Windows — служба поддержки

## С чего начать

Попросите отчёт: **Настройки → Диагностика → Сохранить отчёт** или `Peregovorka.exe --diagnostics=<файл>` (см. [DESKTOP_ADMIN.md](DESKTOP_ADMIN.md)).
В отчёте: версии клиента/Electron/Chromium, Windows, мониторы и масштаб, вид установки (`exe`/`msi`), политики (какие поля заданы), для каждой организации —
адрес, состояние, код ошибки, версия сервера, сохранён ли вход, состояние канала событий, идёт ли встреча; разрешения камеры/микрофона Windows,
число устройств, память процессов, время запуска, состояние обновлений и последние строки журнала (секреты замаскированы).

## Подключение к серверу

| Сообщение | Код | Что делать |
| --- | --- | --- |
| Сервер не найден | `ERR_NAME_NOT_RESOLVED` | Адрес неверен или имя не разрешается вне корпоративной сети — VPN, DNS. |
| Сервер недоступен | `ERR_CONNECTION_REFUSED/RESET/CLOSED` | Сервер не принимает подключения: работает ли он, нет ли блокировки межсетевым экраном. |
| Сервер не отвечает | `ERR_TIMED_OUT` | Сеть, VPN, прокси. |
| Сертификат не доверен | `ERR_CERT_AUTHORITY_INVALID` | Корневой сертификат внутреннего центра не установлен в Windows. Приложение показывает, кем выдан сертификат — сверьте. Установить сертификат в «Доверенные корневые центры сертификации» (лучше групповой политикой). Отключить проверку нельзя. |
| Сертификат выдан на другое имя | `ERR_CERT_COMMON_NAME_INVALID` | Пользователь ввёл не тот адрес (например, IP вместо имени) или сертификат сервера не содержит имени. |
| Срок действия сертификата истёк | `ERR_CERT_DATE_INVALID` | Проверить дату на компьютере; иначе — сертификат сервера. |
| Ошибка прокси-сервера | `ERR_PROXY_*`, `ERR_TUNNEL_CONNECTION_FAILED` | **Настройки → Сеть** (или политика): «как в Windows», PAC, ручной прокси. |
| Это не сервер Peregovorka / версия сервера слишком старая | `not_peregovorka`, `server_too_old` | Адрес — не тот или сервер старше 0.37.0. |
| Не поддерживается требуемая версия API | `server_too_new`, `client_too_old` | Обновить приложение. |

После временного сбоя приложение переподключается само с нарастающей паузой (2 с … 5 мин) и не засыпает сообщениями; «Повторить сейчас» — без ожидания.
Недоступность одной организации не влияет на остальные.

## Вход

* Каждый запуск просит пароль: на сервере выключено «Приложение Windows помнит вход» (0 дней) или прошёл срок; в отчёте `saved_sign_in: false`;
  в журнале `org.trust_refused` с кодом. `trust_storage: unavailable` — защищённое хранилище Windows недоступно (редкий случай — профиль без DPAPI).
* «Сохранённый вход больше не действует»: выход, смена пароля (в том числе в AD), отключение учётной записи, завершение сеанса в «Активных устройствах».
  Это ожидаемо — войти заново.
* «Достигнут предел сеансов»: страница входа предложит завершить один из сеансов; приложение занимает один сеанс на организацию.

## Встречи, камера, микрофон, показ экрана

* Камера/микрофон «запрещено в параметрах конфиденциальности Windows» (отчёт: `permissions`) — «Параметры → Конфиденциальность → Камера/Микрофон →
  Разрешить классическим приложениям доступ».
* Микрофон не открывается (с 1.4.0): раздел `audio` отчёта — коды WASAPI (`wasapi`: HRESULT и расшифровка), последние строки журнала звука движка
  (`%APPDATA%\Peregovorka\logs\chromium-audio.log`), защитные программы (`security_products`) и журнал доступа Windows к микрофону (`microphone_use`).
  Отказ «Захват звука не запустился» при свежем `lastStart` у Edge и без него у приложения и при Kaspersky в `security_products` — признак блокировки
  защитной программой (KES: «Предотвращение вторжений», группа доверия приложения). Методика сравнения с Edge — [DESKTOP_MIC_DIAGNOSTICS.md](DESKTOP_MIC_DIAGNOSTICS.md).
* Устройства: число микрофонов, динамиков и камер — в отчёте; выбор и проверка — на экране перед входом во встречу, как в браузере.
* Показ экрана: окно выбора приложения (экран или окно); звук компьютера — только при показе всего экрана (ограничение Windows). Пустой список окон —
  у приложений нет видимых окон; защищённые окна (DRM) показываются чёрными.
* Встреча идёт при свёрнутом окне — поверх окон индикатор (микрофон включён/выключен), из него можно открыть окно или покинуть встречу.
* WebRTC/LiveKit — тот же движок Chromium, что и в браузере; проблемы связи сверяйте с веб-версией (страница «Диагностика» встречи сервера).

## Уведомления не приходят

Проверьте **Настройки → Уведомления** (включены, «Не беспокоить» выключен), уведомления приложения в «Параметры → Система → Уведомления», режим
фокусировки Windows, политику `Notifications`. В отчёте `notifications_supported` должно быть `true`. Уведомление показывается, когда страницу организации
не видно (окно свёрнуто, в трее или открыта другая организация); на видимой странице — всплывающее сообщение внутри неё.

## Картинка из чата не доходит до других участников

1. Попросите отправителя повторить: с 1.4.1 под файлом должна появиться отметка «✓ загружено» (сервер принял файл целиком; размер и SHA-256 совпали). Нет отметки — сообщение не отправляется, есть причина и «Повторить».
2. «Настройки → Диагностика → Сохранить отчёт», в `main.log` строки `page.attachment`: `op` — `upload`/`open`/`discard`, `result` — код ответа или сетевая ошибка (`net::ERR_…`), путь без параметров. 201 при загрузке и отсутствие ошибок открытия у получателя означают, что дело не в передаче.
3. Администратор: «Диагностика клиентов» → события `chat_upload_failed` (отправитель: причина `empty`, `unreadable`, `size_mismatch`, `hash_mismatch`, код HTTP) и `chat_attachment_failed` (получатель).
4. `empty`/`unreadable` — буфер обмена отдал пустой или недоступный файл; `size_mismatch`/`hash_mismatch` — тело запроса изменили по дороге (прокси, защитная программа); 4xx/5xx — ответ сервера или прокси (лимит размера, тип файла, недоступно хранилище вложений).

Причина исходной жалобы на настоящем Windows не установлена; методика живой проверки — `tests/live/desktop_chat_images.py` (Linux, настоящий Electron).

## Журналы

`%APPDATA%\Peregovorka\logs\main.log` (+ `.1` … `.4`): события запуска, подключений, сохранённого входа, уведомлений, загрузок, обновлений. Токены,
cookie, пароли и параметры ссылок с ключами маскируются; текст сообщений не пишется. Папка открывается кнопкой **Папка журналов** в «Диагностике».

## Обновления

«Управляется администратором» — установка из MSI. «В этой сборке не настроен ключ проверки обновлений» — тестовая сборка, обновлять установщиком.
«Подпись обновления не прошла проверку — обновление отклонено» — манифест не подписан ключом издателя (подмена канала или повреждение): ничего не установлено.
