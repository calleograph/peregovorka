# Аудит интерфейса и админки (2026-10-06)

Метод: реальный браузер (Chrome, Playwright) против локального стенда — backend с подставным AD/Redis и SQLite, frontend через Vite;
плюс разбор кода. LiveKit, ASR, SMB и настоящий AD в стенде **отсутствуют**, поэтому живая комната (звук, камера, трансляция экрана,
реплики в реальном времени) вживую **не проверялась**.

## Проверено вживую — работает
| Область | Результат |
| --- | --- |
| Вход | неверный пароль — общее сообщение; после 3 неудач — блокировка с понятным текстом (без обращения к AD); отключённый админом пользователь — отказ с причиной |
| Права | обычный пользователь не видит «Администрирование», `/admin` перенаправляет на главную; видит только доступные комнаты |
| Комнаты (админ) | создание с выбором групп AD через поиск, список, состояния |
| Хранилище | валидация: SMB без сервера, каталог вне тома — отказ при сохранении; проверка записи |
| Обезличивание / LLM | `http://` без разрешения — отказ; токен сохраняется, после — только «задан»; недоступный сервис — понятная ошибка проверки |
| Экран, часовой пояс | сохранение; неверный пояс — отказ |
| Пользователи | отключение: сессия прекращается сразу, повторный вход невозможен |
| Аудит | действия админа записаны (создание комнаты, настройки, отключение пользователя) |
| Система | состояние PostgreSQL/Redis/LiveKit/ASR/AD |
| История, вход в комнату без LiveKit | понятное русское сообщение, участник снимается со встречи |
| Мобильная ширина | шапка и вкладки переносятся |

## Найдено и исправлено в ходе аудита
1. Поле «Технический идентификатор»: регулярное выражение `pattern` недопустимо в современных браузерах — валидация формы не работала.
2. Форма настроек могла перезаписать введённое значение прежними (общий экземпляр компонента между вкладками) — добавлены ключи.
3. Ошибки валидации настроек показывались с дублем имени поля; каталог хранилища проверялся только при «Проверить», теперь — при сохранении и до записи в БД.
4. Ошибка подключения к комнате показывала английский текст SDK; при сбое подключения участник оставался «в комнате» — теперь русское сообщение и автоматический выход.
5. Сообщение о блокировке входа дублировало «Повторите».
6. Шапка на узком экране выходила за границы.
7. Нет favicon (404 на каждой загрузке); предупреждения React Router в консоли.
8. «Общие настройки» (часовой пояс) были на вкладке пользователей — перенесены в «Система».
9. Нет выбора микрофона/камеры/динамиков во встрече — добавлена панель «Устройства».
10. Закрытие вкладки не снимало участника со встречи сразу — добавлен keepalive-выход; истёкшая сессия теперь возвращает на экран входа; исключение отрисовки не оставляет пустую страницу.

## Открыто (не критично, зафиксировано)
- Живая комната (микрофон → транскрипция, трансляция экрана, кнопка записи) — проверка требует LiveKit/ASR; выполнить на тестовом стенде.
- История и аудит: нет фильтров по комнате/дате и постраничной навигации в истории (последние 30 встреч).
- Нет предпрослушивания микрофона и индикатора уровня до входа в комнату.
- В живой комнате нет поиска по транскрипту.
- Вкладки админки не управляются стрелками клавиатуры (доступность — частично).
- Мобильная раскладка самой комнаты не проверялась.
- Вкладка «Система» раз в 15 с делает LDAP-проверку сервисной учётки.
