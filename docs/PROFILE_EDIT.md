# Правка профиля пользователем

В «Личном кабинете» пользователь может изменить разрешённые администратором поля карточки (по умолчанию — должность, подразделение и телефон; ФИО и e-mail по умолчанию закрыты: по ним узнают людей в списках и письмах). Настройка: «Администрирование → Правка профиля».

**Правка пользователя сильнее данных каталога.** Значение, которое человек изменил сам, не перезаписывается ни входом, ни «Обновить данные из Active Directory», ни фоновым обновлением с портала Bitrix24. Для каждого поля видны: итоговое значение, источник («Каталог», «Портал», «изменено вами»), значение каталога рядом и дата правки. Кнопка **«Восстановить из LDAP»** снимает правку: поле снова считается по обычным приоритетам источников (если ни каталог, ни портал значения не знают, поле очищается).

* Правки и восстановление записываются в журнал аудита (`profile.edit` со старым и новым значением, `profile.restore`).
* Правка действует там, где показывается карточка пользователя (плитки, карточки участников, личный кабинет).
* У локальной учётной записи каталога нет: «Восстановить из LDAP» недоступно, поля можно править так же.
* ФИО в уже открытой сессии и в идущей встрече обновится при следующем входе в комнату.

Устройство: значения пользователя хранятся в `users.profile_sources.local`, даты — в `manual_at`; после любой синхронизации вызывается `apply_manual` (`backend/app/profiles/manual.py`).
