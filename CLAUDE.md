# Peregovorka — правила для ассистентов

- Приоритеты: надёжность → работающая функциональность → скорость → безопасность → новые возможности.
- Не называть проверенным то, что не запускалось. В отчётах разделять: реально проверено / автоматический тест / code review / не проверено.
- Изменения страницы комнаты — только с живой проверкой в браузере (`tests/live/`).
- В репозиторий не попадают частные данные конфигурации (домены, IP, ключи, DN каталога) — см. [docs/PRIVACY_OF_CONFIG.md](docs/PRIVACY_OF_CONFIG.md).
- Историю git не переписывать без явного согласия владельца.

## Документация и выпуск

**CHANGELOG — для пользователя. HISTORY — для разработчика. README — витрина продукта.**
Перед каждым выпуском — чек-лист из [docs/VERSIONING.md](docs/VERSIONING.md) (навык `.claude/skills/release`): VERSION → CHANGELOG пользовательским языком → HISTORY → PROJECT → README → docs → CI → release.
