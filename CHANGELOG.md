# Changelog

Здесь — только заметные изменения для пользователя и администратора, без деталей рефакторинга и без копии `git log`. Подробный технический журнал — [HISTORY.md](HISTORY.md).
Теги и релизы GitHub — начиная с 0.1.4; описания более ранних версий составлены ретроспективно. Версия задаётся одним файлом [`VERSION`](VERSION); как выпускать новую — [docs/VERSIONING.md](docs/VERSIONING.md). Накопленное между выпусками пишется в «Unreleased».

## Unreleased

## 0.1.4 (2026-10-07)
- Общая доска для схем и диаграмм (draw.io, развёрнут внутри системы): рисуют все участники, схема сохраняется со встречей и доступна в истории, выгрузка PNG, SVG, PDF и `.drawio`.
- Чат комнаты: ссылки открываются в новой вкладке, история хранится вместе со встречей; чат и схема с доски передаются языковой модели при формировании протокола.
- Гостевой доступ по ссылке без учётной записи: проверка микрофона, динамиков и камеры перед входом, отзыв и перевыпуск ссылки, включение для каждой комнаты отдельно.
- Пока идёт встреча, разделы системы открываются в новой вкладке — звонок не прерывается.
- Единое версионирование: версия в интерфейсе, на странице «Обновления и версии» и в GitHub-релизах берётся из одного файла и показывается вместе с commit (например, `0.1.4 · 6123022`); в «Обновления и версии» видно, что изменилось в новой версии.
- Исправление отдельных ошибок.

## 0.1.3 (2026-10-07)
- Руководители комнат: выключение микрофонов у всех участников или у одного, назначение групп и людей в настройках комнаты.
- Обновление проекта из веб-интерфейса одной кнопкой с окном хода обновления; таблица версий компонентов «установлено / актуально в интернете».
- Распознавание речи: компактная модель GGUF Q5_K_M входит в образ и переключается из админки без перезапуска.
- Исправления по итогам обновления на реальном сервере: пути резервных копий, проверка LiveKit и TLS, ручная пересборка `scripts/rebuild.sh`.
- Новая главная страница проекта на GitHub с описанием и снимками интерфейса.
- Исправление отдельных ошибок.

## 0.1.2 (2026-10-07)
- Журнал событий с фильтрами, бесконечной лентой, выгрузкой за 24 часа и 30 дней и автоматической очисткой.
- Несколько API для языковой модели и обезличивания, выбор профиля для каждой комнаты; обезличивание можно отключить — протоколы создаются и без него.
- Показ экрана участника с масштабом колесом мыши; новая палитра и типографика, круглые кнопки управления.
- Устойчивое подключение при сетевых сбоях, понятная работа с занятым микрофоном, настройки шумоподавления.
- Защита входа: блокировка после серии неверных паролей, проверка логина.
- Исправление отдельных ошибок.

## 0.1.1 (2026-10-06)
- Выбор модели распознавания речи в админке (Full и Q5_K_M), тест и сравнение моделей по скорости и качеству.
- Штатное обновление `scripts/update.sh` с резервной копией базы, проверками и откатом `scripts/rollback.sh`.
- Правила доступа к завершённым встречам, формирование протоколов и резюме по подтверждённой инструкции, экспорт в Word, PDF, Markdown и текст.
- Диагностика входа в комнату и работы медиа, проверка совместимых версий LiveKit.
- Исправление отдельных ошибок.

## 0.1.0 (2026-10-06)
- Первый выпуск: вход доменной учётной записью (AD), комнаты на LiveKit, голос, видео и показ экрана.
- Транскрибация речи каждого участника отдельно (GigaAM), история встреч, запись аудио.
- Протоколы и краткие резюме через языковую модель с обезличиванием, выгрузка в локальную папку или SMB.
- Администрирование: комнаты, права, пользователи, хранилища, настройки.
- Установка мастером `scripts/setup.sh` одной командой.
