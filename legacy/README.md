# legacy/

Прежний проект — PHP-сервис «Корпоративный AI-чат с доменной авторизацией» (`legacy/php/`). VoiceMeet создан на его основе,
но на другом стеке (Python/FastAPI, React, LiveKit).

Всё нужное уже перенесено: LDAPS-вход, шифрование секретов, защита от перебора, сессии, клиент DocClean/generic-обезличивателя,
LLM-адаптеры, состав админки. Новый код от `legacy/php` **не зависит** (остались лишь комментарии о происхождении).

Каталог можно удалить целиком. Прежде проверьте `legacy/php/var/` — там рабочие данные старого проекта (SQLite, ключ шифрования);
они исключены из Git и в новый проект не переносились. История и описание старого проекта сохранены в
`docs/legacy/HISTORY.before-rebuild.md` и `docs/legacy/PROJECT.before-rebuild.md`.
