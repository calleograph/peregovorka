# 🎙 Peregovorka

### Локальная голосовая переговорка с транскрибацией, протоколами и общей доской

Видео- и аудиовстречи для корпоративной сети: вход доменной учётной записью, распознавание речи каждого участника, чат, общая доска для схем, гостевой доступ по ссылке
и протоколы встреч по вашей инструкции. Данные остаются на вашем сервере.

## Возможности

- **Голос, видео и показ экрана** в браузере; чужой экран можно приближать колесом мыши.
- **Стенограмма «кто что сказал»:** речь каждого участника распознаётся отдельно, на русском языке, без интернета.
- **Протоколы и резюме** по инструкции пользователя с помощью языковой модели; обезличивание текста — по желанию, для всей системы или для комнаты.
- **Общая доска** для схем и диаграмм (на основе draw.io): рисуют все участники, схема сохраняется со встречей; выгрузка PNG, SVG, PDF и `.drawio`.
- **Чат комнаты:** ссылки, копирование, история, файлы и картинки (кнопка, перетаскивание, Ctrl+V); чат и схема учитываются при составлении протокола.
- **Гостевой доступ по ссылке** без учётной записи — включается для каждой комнаты отдельно, ссылку можно отозвать.
- **Руководители комнат работают самостоятельно:** «Настройки комнаты», доступ и гостевая ссылка, режим «презентация» с «дать слово», запись и транскрибация, управление участниками.
- **История встреч, запись, выгрузка** в общие хранилища (каталог или SMB-ресурс, настраиваются один раз); права доступа по группам Active Directory.
- **Администрирование:** комнаты, пользователи, журнал событий, состояние системы, обновление проекта из веб-интерфейса.

## Требования

Сервер с Linux (Ubuntu 24.04 или совместимый), Docker и Docker Compose v2; от 4 vCPU, 8 ГБ RAM, 20 ГБ диска. Для работы в браузере нужен **HTTPS**.
Участникам — в офисе, снаружи или через VPN — нужны **443/tcp** (HTTPS), а также **UDP- и TCP-порты звонков** (`LIVEKIT_UDP_PORT`, `LIVEKIT_TCP_PORT` из `.env`) прямо до сервера;
остальные порты наружу не открываются. Подробности и особенности VPN (в том числе MTU) — в [docs/INTERNALS.md](docs/INTERNALS.md#сеть-что-должно-быть-доступно-участникам).

## Установка

```bash
git clone --depth 1 https://github.com/leonheard/peregovorka.git /var/www/projects/peregovorka \
  && cd /var/www/projects/peregovorka \
  && scripts/setup.sh --profile shared-host
```

Мастер задаёт вопросы, подбирает свободные порты, создаёт `.env`, проверяет сервер и показывает план. Подробное руководство — [docs/INSTALL_AND_UPDATE.md](docs/INSTALL_AND_UPDATE.md).

## Обновление

```bash
./scripts/update.sh      # или кнопка «Обновить проект» в Администрировании → Обновления и версии
```

Версия проекта показана в интерфейсе (например, `0.1.4 · 6123022`); что изменилось от версии к версии — в [CHANGELOG.md](CHANGELOG.md).
