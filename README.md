## Что такое Peregovorka

Peregovorka — система видеовстреч, которую организация разворачивает на своём сервере. Сотрудники входят доменной учётной записью и проводят встречи в браузере или приложении. Система распознаёт речь каждого участника, а после встречи готовит протокол, резюме и карту разговора.

Записи, стенограммы, распознавание речи и обезличивание работают на вашем сервере. Разработчик проекта не получает ваших данных и не участвует в работе сервера. Наружу уходит только то, что вы подключили сами. Например, текст в языковую модель: всегда без паролей и ключей, а при обезличивании ещё и без имён, контактов и реквизитов.

## Какие задачи решает

- Внутренние совещания без передачи звука и записей посторонним сервисам.
- Протокол вместо ручного конспекта: решения, задачи «кто, что, срок», открытые вопросы.
- Встречи с внешними участниками по гостевой ссылке.
- Трансляции для зрителей по ссылке и параллельно на внешних площадках.
- Единое место для материалов встреч с правами и сроками хранения.
- Переписка сотрудников внутри организации.

## Основные возможности

| Возможность | Что входит |
| --- | --- |
| **Видеовстречи** | голос, видео, показ экрана, общая доска, своя раскладка у каждого участника |
| **Стенограмма** | речь каждого участника распознаётся отдельно, на русском языке, на вашем сервере |
| **Протоколы и резюме** | языковая модель по API: облачная, корпоративный шлюз или своя; у пунктов есть реплика-источник |
| **Обезличивание** | до отправки в модель участники становятся «Иван И.» или «Участник 2», контакты и реквизиты заменяются, пароли и ключи убираются всегда |
| **Карта разговора** | темы на шкале времени, кто сколько говорил, переход к реплике |
| **Запись** | общая аудиозапись и видеозапись MP4, по кнопке или автоматически |
| **Трансляции** | зрители смотрят по ссылке без входа, 1080p и 2K, вопросы ведущему, RUTUBE, VK Видео, YouTube, Twitch, запись эфира, пароли и отзыв ссылок, панель диагностики |
| **Низкая задержка эфира** | около 3 секунд в замере на одном тестовом сервере, без учёта вашей сети. Safari, iPhone и узлы CDN смотрят обычный поток |
| **Свои узлы CDN** | отдельный сервер подключается из администрирования по SSH и сам настраивается, зрители получают эфир с него |
| **Файловые хранилища** | локальный диск, сетевые папки SMB, внешние тома; перенос данных с проверкой копий |
| **Корпоративные чаты** | переписка, файлы, диктовка |
| **Outlook и Exchange** | встречи из календаря, надстройка Outlook |
| **Active Directory, Bitrix24, SIP** | вход доменной учётной записью, доступ по группам, профили, звонки через АТС |
| **API** | публичный API, события (webhooks), OpenAPI |
| **Свой вид** | название, логотип, цвета и документы организации настраиваются в браузере |

Полный перечень: [Возможности](https://github.com/calleograph/peregovorka/wiki/Возможности). Когда система не подойдёт: [Когда продукт не подходит](https://github.com/calleograph/peregovorka/wiki/Когда-продукт-не-подходит).

## Чем отличаются веб и приложения

Все клиенты подключаются к одному серверу организации. Учётная запись, комнаты и материалы у них общие. Браузер и приложения на компьютере показывают один интерфейс сервера, поэтому новые функции приходят вместе с обновлением сервера.

| | Браузер | Windows и Linux | Android |
| --- | --- | --- | --- |
| Установка | не нужна | EXE, MSI, пакет APT | файл APK, предварительная версия |
| Встреча, чат, показ экрана | да | да | да |
| Доска, стенограмма в комнате | да | да | нет |
| Управление записью, эфиром, участниками | да | да | нет |
| Системные уведомления, трей, автозапуск | нет | да | нет |
| Несколько организаций | вкладки браузера | да | да |
| Вход сохраняется | пока действует сеанс | да, пароль не хранится | да |

Основная проверка идёт в актуальных Chrome и Edge. Гостям и зрителям хватает браузера. Версии для iPhone и iPad нет. Подробно: [Веб-версия и приложения](https://github.com/calleograph/peregovorka/wiki/Веб-версия-и-приложения).

## Как развернуть свой сервер

Коротко ниже. Подробное руководство для тех, кто делает это впервые: [docs/INSTALL_GUIDE.md](docs/INSTALL_GUIDE.md).

**1. Подготовка.** Нужен сервер с Ubuntu или Debian, права `sudo`, доступ сервера в интернет на время установки, имя в DNS и сертификат для рабочей эксплуатации. Если на сервере уже работают другие приложения, используйте [установку на общий сервер](https://github.com/calleograph/peregovorka/wiki/Установка-на-общий-сервер).

**2. Установка.** Команды скачивают установщик и запускают его:

```bash
wget -O install.sh https://raw.githubusercontent.com/calleograph/peregovorka/main/install.sh
chmod +x install.sh
sudo ./install.sh --host meet.example.org
```

Установщик сам поставит Docker и остальное, соберёт и запустит службы, проверит их и покажет адрес, логин и первичный пароль. Обычно это занимает 10–30 минут.

**3. Первоначальная настройка.** Откройте адрес в браузере, войдите как `admin` и задайте новый пароль. Мастер проведёт через каталог, сертификаты, группы администраторов, хранилище и почту. Каждый шаг можно пропустить. Языковая модель, запись и трансляции включаются в разделе **Администрирование**.

**4. Подключение.** Замените самоподписанный сертификат на доверенный и откройте порты звонков: 443/tcp, `LIVEKIT_UDP_PORT`/udp и `LIVEKIT_TCP_PORT`/tcp. Страница идёт через HTTPS, а звук и видео идут напрямую на сервер. Сообщите сотрудникам адрес вида `https://meet.example.org`.

**5. Проверка.**

```bash
cd /opt/peregovorka
sudo ./scripts/status.sh
sudo ./scripts/smoke-test.sh
```

Ожидаемый результат: `Все сервисы работают` и `Smoke test: PASS`. Затем проведите пробную встречу с двух устройств: участники слышат друг друга, в панели «Транскрипция» появляются реплики.

## Требования к серверу

| Параметр | Что нужно |
| --- | --- |
| Система | установщик принимает Ubuntu от 22.04, рекомендуется 24.04, и Debian от 12; x86_64 |
| Порог установщика | 4 vCPU, 8 ГБ памяти, 30 ГБ свободного места |
| Сеть | имя в DNS и HTTPS; 443/tcp и порты звонков UDP и TCP напрямую на сервер |
| На запись и эфир | дополнительно процессор и память; образ службы около 3,8 ГБ; локальный диск: эфир 1080p около 2,2 ГБ в час и столько же на копию |

Порог установщика не является рабочей конфигурацией: система целиком на нём не испытывалась, запись и эфир в него не входят. Подтверждённой вместимости всей системы пока нет, сквозного нагрузочного испытания не проводилось. Что измерялось и в каких условиях: [Производительность и масштабирование](https://github.com/calleograph/peregovorka/wiki/Производительность-и-масштабирование), [Что проверено](https://github.com/calleograph/peregovorka/wiki/Границы-проверки). Расчёт под вашу нагрузку: [Системные требования](https://github.com/calleograph/peregovorka/wiki/Системные-требования). Какие испытания нужны: [Матрица нагрузочных испытаний](https://github.com/calleograph/peregovorka/wiki/Матрица-нагрузочных-испытаний).
